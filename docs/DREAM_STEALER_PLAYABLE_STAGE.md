# 0.106 窃梦家5：当前念头与自己承担的动作

完整晋升配方与仪式细节未核，采用原渠道独立成品和导师实际G准备，不宣称原著无仪式。第三部217–219章的明确表现是偷当前待执行的动作念头，施术者自己立即做对应动作，目标之后可找回决定；偷喷吐念头并不同时偷到吐息能力。序列4免除对应动作、延迟呈现和寄生均不下放。

本段原创实践有本人已同意的坐下测试、原空桌与目标原木圆片的伸手测试、没有自我思想的原机械演示。偷取成功就实际坐下或伸手，不能存成以后消费的动作卡；伸手不会让目标原片隔空变成玩家物品。明确结束包括当前念头恢复、普通起身/缩手与原片真实归还。无自我思想者只可普通核实，没有可偷念头。

战斗只对眼前普通人的一个实际当前动作决定尝试窃取，玩家以自己的原身体和原装备完成它；目标这一槽暂时落空，之后重新决定。既有动作盘概率不因窃取而降级，未知未来整轮不提前读出。原普通对手没有非凡能力，观察不送能力池。原盗火人暂借、来源及恢复历史保留。

梦境与理想窃取有名称依据，具体新晋操作未核，本段不伪造任意远程入梦、永久改人格或偷梦库存。距离、当前决定的G表示、判定、费用和现场恢复时段均为原创游戏化。

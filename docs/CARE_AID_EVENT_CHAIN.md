# 普通医疗援助委托候选 V1

2026-09-13｜8B已确认“完成普通委托换处置”；本文件新增具体任务、难度与失败结果为游戏适配候选。不是原著医疗事件，不是每周目免费福利，不代表已实现。

## 委托：清点退回的物资签条

诊疗点有一批普通物资退回签条，需要核对同袋签条是否重复。只比较图记和编号，不要求文盲角色突然识字，不要求伤者搬重物，不涉及医疗知识、病人隐私或非凡物品。

可用任务必须来自本诊疗点已登记的一批真实工作需求 `aidBatchId`。普通人已知诊疗点、有未处置普通重伤、现金不足60、信用暂停且本批工作尚未交付时，在休养之后可遇到`CARE-WORK-OFFER`。不凭空为每次受伤无限刷新同一批工作；后续批次只能由已写的补货/退货事件产生，不设通用每局领取次数。

## 节点与固定回退文本

### CARE-WORK-OFFER｜用一次帮忙换处置

“诊疗点有一批退回的物资签条需要核对。你可以坐着比较图记和编号。完成这件事，可以换一次普通伤口处置；旧欠款仍要另还。”

0AP、NONE，来源是刚才的休养，不再扣第二次AP。

- `accept`“接下核对”：绑定本批次与玩家，建立已知调查目标。明示一次调查行动，失败可再花一次行动复核；现在不治疗、不发现金。
- `decline`“暂不接下”：不改变伤势/欠款；结束本卡，本周不自动重复邀请。任务仍由诊疗点保有，可被真实后续事件使用，不为玩家冻结整个世界。

接受以后即便获得现金或恢复信用，既定交换仍有效；邀请资格不反过来取消已承诺任务。没有可用批次时不弹此卡；普通现金医疗、合法赊账仍沿原规则，不制造不存在的任务来保证每次都能换治疗。

### CARE-WORK-CHECK｜核对签条

玩家在调查中主动选该目标，花1AP；基础行动回执记录本任务，不再叠加通用调查现金/知识奖励或抽另一张无关随机卡。这里只代替该调查的目标结果，不阻止真正必达后果。

“签条分放在两只浅盒里。你要找出哪些指向同一袋物资，把重复的条目留在一边。”

前提：本人健康与精神均>0、未处置重伤仍存在、批次可用、诊疗点及交付对象可用。否则在花AP前返回可知原因，或按下文失效处理；不收取一次注定无法提交的调查。

执行感知普通d100，难度12；基准15成功率56%。不用知识来确认识字能力，不附额外伤害或污染。

| 四档 | 真实结果 | 后续 |
|---|---|---|
| 大成功 | 重复签条已分清，摆放亦整齐 | 批次已交付；与成功同等报酬，不多给治疗次数 |
| 成功 | 重复签条核对清楚 | 批次已交付 |
| 失败 | 遗留一处重复，尚未达到交换要求 | 进入可主动复核状态，不治疗、不罚钱 |
| 大失败 | 两盒对应关系混淆，需重新排好 | 同样进入复核，不用生活小委托制造意外死亡 |

### CARE-WORK-CORRECT｜按标记复核

只在上一步失败后出现为调查目标；“对方把容易混淆的几张签条单独标出。你可以按标记再核对一遍。”花1AP，NONE，满足相同合法前提后确定完成。不是无限失败轮盘；实际代价是多占一次行动。玩家也可以在该目标详情选择取消（0AP、无奖励），退出不等于完成。

### CARE-WORK-REDEEM｜兑现普通处置

完成或复核完成的同次结果中，先提交唯一批次交付，再兑现对当前普通重伤的一次普通医疗处置。不是可以出售/囤积的现金券，不替别人治伤，不清旧债。

“签条已经核对完毕。诊疗点按约替你处理了普通伤口，但恢复还需要休养。”接7B：之后至少一次休养，健康≥80%才痊愈；工作调查本身不算那次休养，也不加基础回血。处置不额外花AP，完成结果页不二次扣费。

## 中断与重试

- 正在打开的事件期间世界不偷偷推进；交付与兑现同次提交，重试复用原结果，不重复处置。
- 玩家在交付前已通过别的途径处置/治好这份重伤：取消未完成交换，说明“不再需要这项处置”，不送未来免费治疗。提交前检查，不先花AP再撤销。
- 批次已被真实事件收回/另人完成、诊疗点不可用、迁居失去接触：未交付者取消，保留先前已花行动和原因，不伤害/收费，不偷偷替换提供者。旧任务已支付的AP不回滚。
- 玩家死亡：终止本任务，遵守终局；晋升后普通人版本不继续发卡，未交付任务取消并保留记录，非凡医疗需相应序列内容。
- 再次受重伤不把旧交付清成未完成。只能在有新的真实任务批次时再建立交换，不能重新转同一签条赚治疗。

## 纸面核对

成功路线：原休养触发邀请→下一次调查花1AP完成/处置→以后休养。失败路线多一次复核调查。所有分支都有结束或明确可主动进行的目标；无隐藏AP扣费、无新增灵性、无免费现金。56%包含大成功5%，失败44%包含大失败5%；复核确定完成只在客观前提仍成立时有效。

任务批次首次入场候选：普通诊疗点被核实可达时登记一批未交付退货签条；以后没有自动按周再生。本初始游戏适配需随诊疗点内容发布，不把所有NPC或所有医疗点都赋予本任务。后续更多普通委托模板仍待制作。

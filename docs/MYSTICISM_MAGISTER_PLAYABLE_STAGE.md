# 0.101 秘术导师5：联系原物、醒后复核与有限仿制

阅读者至博学者的原观察、分析、样本与掌握保留。完整晋升配方和仪式明细未核，仍采用塞缪尔有来源的独立G成品药与准备；不声称原著无需仪式，不赠预装秘术库。

## 三段原创实践

诺亚自愿借出自己的原布巾，玩家借实际联系物与已有方法开展有限仪式。目标在40米外已约定的原房休息，玩家身体保持原书房。结束梦境不会自动归还布巾，梦中说法也不等于现实真相：醒后另花行动沿普通路当面核实，再亲手归还原布。普通方法可记录同一件事的口述并复核。

仿制须已有实际学会的FLASH样本知识。付费取得并消耗真实封装G灵材，再花灵性尝试做一个微弱一次性闪光签；失败损失原料，成功保独立原件与固定效力，随后在原净空试间实测消耗。完成这一课后，可每真实周另花成本制作一件战前准备物；没有材料便没有产物。教学让塔莉娅本人核对普通来源/出口/材料清单，不把一次示范写成她永久学会超凡能力。

## 战斗与边界

罗文是原工院持自己普通短棍的成年人，双方2米、原出口可退。继承的有限FLASH仍需旧样本真实学会并支付成本；R只消费一件实际已制作、仍在玩家处的原闪光签，用其制作时确定的效力。不在战斗凭空制物，不因未命中适用来源而吞掉原物，也不把课中仪式变成瞬发强制拉梦。实际伤势与死亡仍由共同战斗结算。

以上人物、40米路线、材料包、物品、价格与能力数值均G。原文第三部52章支持以目标遗留物进行秘密仪式入梦，千海里是艾德雯娜的具体案例；53章强调已有相关知识和真实材料的仿制仍可能失败；220章有模拟圣光实战。它们不证明初晋全知、无材料制造、全球任意目标施法或肉身传送。半神预言与自我封印个案不作为本阶默认技能。

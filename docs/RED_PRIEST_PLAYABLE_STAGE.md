# 0.209.0 红祭司：北大陆战争与原件传承

## 阶段范围

本阶段在猎人序列1的原活结局上接续一条有限序列0路线。四方实际委托、三大战区、有限原军团与国库、原材料取得和战后救援属于同一个连续周目。正常准备路线已实际完成晋升与救援收束，保存验证和发布输入恢复已完成，远端检查以实际提交为准；不会据此宣称完整1.0。

## 原文与本作剧情

原文明确红祭司的成神仪式是本人掀起一场席卷大陆的战争并取得足够胜利。正常已融合一份征服者特性的角色，还需要另两份原特性与红祭司唯一性，最终共三份序列1。完整辅助材料、普通初晋红祭司的新能力范围、代价与操作细则未在本次文本中得到完整定义。

本作采用第五纪1353年的独立未来战争剧情。弗萨克、鲁恩、因蒂斯和费内波特都有各自既存国库、军团、守备、居民与决策。灰脊北关、晨河东桥、白石转运地、青岸河埠、东南粮仓地与南灯港路，分别横跨北东、西南、东南运输地带。它们是战略抽象中的六处关键目标，并不代表大陆只有六个小房间。

玩家先取得三方实际委托，再另行签发发动命令、执行首次跨境行军与会战。五处独立胜利、三个实际交战并控制的战区、四方受到的真实影响和停战记录共同构成本作达成规则。五胜、三战区及路线周数是游戏实现，不是原文给定的数字。战争会损耗原军团、后备、补给和国库，并改变原控制、设施和居民迁离状态；停战或保护撤离可以提前结束战争，不会假记完成仪式。

## 原活档与材料守恒

起点为征服者原795条命令的完整活结局：第200周、第五纪1353年4月21日，健康80、精神100、灵性120、现金536便士、3行动，两处轻伤。原23项技能中6项为0，旧30名互助成员仍在家中，前五人精力为7、7、7、7、8。旧罗南死亡、奥伦投降及原物状态继续保留。

三份原特性来自原三瓶：第1、2瓶曾真实服药失败，第3瓶已经融合于本人。失败并不意味着回收物已经在库存中，必须经过原处置记录调查、到场核验、净化和交接；原普通药液与历史开支不返还。唯一性有独立的铁冠保管链与同一原件身份。调查和运输费用不是购买或生成神位。

调配只消耗实际交接的原件和有限辅助物料。服药失败按真实健康、精神、污染与封存条件决定死亡或可追查残余，不保证安全停留序列1，不自动使用其他复起能力。成功后同三份特性和唯一性全部登记为本人已融合，旅行只改变同一本体内原件的当前位置，已耗药液历史保持原状。

## 玩家流程

1. 阅读当前危机与原材料要求；旧轻伤可以按正常生活档休养。
2. 亲自查明两份失败原特性与唯一性，沿城市道路取得原件。
3. 协商实际委托，决定是否发动战争；在大陆原路线推进会战、巩固、有限整补或保护撤离。
4. 核对真实战果与停战，沿原运输路线回到城市；处理实际伤势，再决定是否调配和服药。
5. 若成功且仍活着，返回原军团驻地参加一宗运输侧线救援。

原本职业工资仍按实际每周一次结算，普通生活费和旧约还款照常支付。军团国库不是个人余额；独立军务劳务消耗实际行动并从原国库支出。跨周不会免费恢复伤势或灵性。

战时可以选择“沿原路回总部整备”。本人和同一批原军团实际返程，沿既有路程耗周，军费、补给和个人生活欠款继续结算；抵达总部后才能重新工作筹款。回程本身不发工资、不恢复军团、不重置已经发生的战争与伤亡。它与“保护撤离并结束本场战争”是不同选择，后者会真正结束本场战争。

停战或保护撤离后，本人也可以沿原路步行回总部，实际路程、生活费与旧还款照常结算。原军团留在实际驻地；本人回总部后可以正常工作，再按原路线支付旅费返回同一驻地。界面会列出这项返程，费用不足时显示真实原因。

## 战前筹划与原失败分支

首次旧规则续行至983条命令时，四次会战均失败，玩家依公开人员不足提示执行了真实保护撤离，活着停留序列1。原伤亡、净化与委托失败、费用、随机序列和停战结果全部保留。这条失败线不是完成红祭司路线的证明。

独立筹划分支从同一原周目第918条命令后的真实活状态开始，此时三方委托已经取得，但发动命令尚未签发。它不是从第974条继续，也不撤销旧分支的战果。玩家在宣战前明确采用战前筹划；旧存档缺少这项选择时继续原规则。

每个目标只用一组清楚的选择：实地侦察、额外补给、常规／协同／护持部署。侦察耗一周、每方原国库120和每军1份补给；额外补给在本次开战时实际消耗每军6份。协同要求三支原军各至少1000人且士气至少60。护持准备另耗一周及每方国库60，实际降低本次胜败伤亡与居民迁离。所有周维持费和生活费继续发生。

侦察、额外补给、协同／护持分别提供本作有效能力修正8、12、20／18。护持对应每军胜／败现员损失120／450，普通为180／600；护持居民迁离30／60，普通为60／100。修正和损耗是公开游戏平衡参数，不是原著固定数值。准备绑定当前原守军和未执行会战，不重复叠加，换目标、退出或已交战后不能沿用。界面显示当时实际胜率、可用原资源、直接费用和风险；准备不抽随机，不保证胜利。

实际路线结果与保存验收分别记录，不以数学估算冒充实际完成率。

已经封存的筹划路线确实取得五处胜利、覆盖三个战区，并在第九次真实停战谈判成功后结束战争。其两次未准备服药均以5%成功率失败。随后从第1137条原活状态继续，第三瓶实际完成下述稳定准备，68%检定掷出90，仍然失败；第1222条命令后的角色活着停留序列1。失败成本、治疗、污染恢复与原随机都保留。这不是红祭司晋升成功的证据。

该次原件状态“无法取得”表示原身份与失败去向账仍在，但位置、保管人和污染状态已不能核实，当前没有可用回收路径；不表示唯一性或特性凭空消灭。现有规则仅在本人存活、失败程度允许、检定不超过80且原封容器仍可识别时留下可追查残余。新玩家体验另从同一第918条真实战前活截点，使用同一随机种子、从第一瓶就按公开策略准备的独立完整路线验证，旧失败线不回滚。

这条独立路线实际执行919至1051共133条新命令，重新经历六次会战中的一次失败和九次停战谈判。第1034条命令的首瓶在真实稳定准备后，以68%检定掷42成功，角色于第341周晋升序列0。它与两次旧5%失败、后来68%掷90失败的1222条路线分别封存，不能拼接成同一条无失败履历。

## 战后稳定准备

战争达成并真实结束后，三方原委托、三支尚存原军、本人和同一瓶原成药及四件原材料共同构成准备条件。玩家实际支付120便士、2行动、12灵性、8精神并度过一周，生活财务照常结算。准备为该瓶下一次服用提供35点有效能力修正；当前原角色充分准备后的公开成功率为68%，仍可失败。

每瓶只准备一次，不叠加、不转移。实际离开调配处或原件、委托、军团条件失效，会永久作废这次准备；回到原地不能复活旧加值。实际服药消耗准备，失败后的伤势、药液与费用不会返还。休养、合法工作和正常跨周仍可用于取得真实资源。

## 成神后的有限任务

六名成员来自原鲁恩军团，三名伤员来自已有战争伤亡。玩家可尝试同袍战旌形成一次搬运协同，或以赤焰界限限制一处实际火场，再沿原侧线转运伤员。实际行动点、精神、灵性、抵抗、伤亡与火损都会保留；普通撤离和交接始终按实际状态开放。

两项技能与定量效果属于本作有限原创。它们不提供无限军队、必胜战争、任意复活或来自神器与天使之王的额外能力。任务中的一次协同成功也不等于所有伤员已经救出，救出者原伤不自动消失。

新任务入口可选择准备后的有限救援规则，两项神级技巧各有25点本作有效能力修正；按当前原属性，协同和控火分别为74%与62%。这不提高普通搬运判定，不增加原军人数或行动点。进入仍实际耗1行动和2份原补给，常规撤离与交接保留；实际结果以新路线完成后的记录为准。

1051条路线尾声中，同袍战旌以74%掷23实际成功；搬运以34%掷99大失败。最终救出1名仍带原伤的伤员，另2名留在有遮蔽的原救护站；6人原分队中1人死亡、5人返回。玩家随后普通撤离并真实交接，活着停留序列0、第353周，健康70、精神80、灵性112，1处未处理重伤、伤势风险2、现金0、行动0，真实欠款94便士。协同掌握8，未施展的控火掌握0。没有为了补成功次数重抽尾声。

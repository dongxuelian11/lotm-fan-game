# 0.177.0 阶段版验收报告

验收日期：2026-10-14。本版是现有内容的源码阶段发布，尚非完整1.0。22条途径已有有限9→3内容，其中14条接至有限序列2；余下8条序列2及全部序列1/0暂停开发。

## 已完成的检查

- 在独立干净发布目录用锁文件实际执行 npm ci，安装183个包。主工程与发布目录的完整严格类型检查均通过，包含全部测试类型；没有放宽检查配置。
- 修复前全量基线执行967个文件：18,668个断言通过、534失败、25未完成。保留该结果，不将它视为发布版通过结果。
- 修复后复验全部失败、未完成、修改及公共显示受影响范围：488个文件、8,608个断言通过，包含全部296个界面测试文件和额外历史回执回归。其余495个测试文件内容未变，保留基线的11,348个通过断言。当前共983个文件，比基线新增16个回归文件。这是两轮证据组合，不是最终源码上全983文件重新执行一遍；各文件只计一次。
- 干净发布目录从交付输入包恢复60个历史输入相关测试及其辅助模块所需的298个原文件，核对全部字节哈希后，60个文件、466个断言通过。首次仅恢复直接引用时出现缺少旧依赖的错误，已补齐恢复范围并完整重验。
- 主工程与干净发布目录生产构建均通过，1210个模块。发布目录48项烟测和17项恢复工具测试通过。
- 本阶段原有585条公开命令与54个命名、50个唯一SQLite保存转换验证保留；未为了获得成功结局重抽种子或覆盖原失败存档。

## 修复内容

本次修复了玩家界面残留开发标签、部分配方和确认页面未经过显示转换、固定敌人显示名，以及自定义角色姓名可能被文案转换误改的问题。底层存档、回执指纹、随机结算和战斗数值保持原规则。

测试更新包括真实旧版本迁移结构、模拟对象类型、当前公开文案预期及历史输入路径。203份原始历史输入补入压缩交付，另外47处改读已有逐字相同输入；没有重新运行生成器代替历史证据。两个各40种子的循环拆为原80个独立案例，种子、操作和断言未改。三次记忆恢复的完整集成用例单独给予15秒预算，其余全局预算不变。

## 可复现命令与已知限制

安装、启动、完整测试及分组恢复命令见README与运行说明。历史输入共32个完整文件压缩包，清单逐包、逐原文件记录SHA256。完整展开约需3.9GB额外空间；启动游戏无需展开全部历史输入。

云环境中两份测试整文件出现worker意外退出，尚未认定具体根因，也未将中断计为通过：

- `npm run test:catastrophe-isolated`：原15个案例逐项独立进程，实际15/15通过。
- `npm run test:wisdom-angel-life-isolated`：原33个案例逐项独立进程，实际33/33通过。

两命令核对完整案例名单和每项退出码，漏项、失败或异常退出均返回非零。默认整文件执行的限制仍在；README提供排除这两文件后再执行专用命令的步骤。内存受限环境可按文件分批、单worker执行其余测试。本次重验使用每批最多5文件，较大的历史测试单独执行。

构建仍报告大分块警告：两个主要JavaScript块约4.79MB和11.20MB，分别约0.88MB和3.07MB gzip。构建通过不代表首次加载速度或桌面交互性能已经实测。

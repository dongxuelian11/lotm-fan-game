## 共同执行规则

ID为`ORIGIN-O01-START`至`ORIGIN-O10-START`；对应出身普通人角色创建完成后生成一次，第一主要行动前处理，0AP、0现金成本、NONE结算，不掷检定。卡内人物使用该出身已登记的支持/义务槽，首次实例化为稳定轻量角色ID；不赋予原著身份或组织权限。

每张选择ID为`.accept`与`.decline`。接下线索只写可调查的普通线索，拒绝不写；两项都记实际选择与该人物的关系近期原因，不增减属性/扮演/能力，也不变更职业资格。拒绝不会永久关闭途径成长。所有角色都必须看清后点选，不由性格代选。

下表“接下”统一结果文本为“你记下了这件事，可以在调查中核实。”加该线索名称；“婉拒”统一结果文本为“你没有接下这件事，对方知道了你的决定。”加本行关系原因。线索到下一次主要调查才消耗AP；首卡不暗中连开第二张卡。

## 首条线索怎样闭合

这些线索不是没有出口的任务占位。首次选择对应调查目标时使用普通人子节点 `ORIGIN-Oxx-VERIFY`，基础调查消耗1AP，结果直接记录纪事，不额外弹阻塞卡、不额外扣费，无战斗。第一周首卡以外不会自动增加AP。

每条一次有效核实后关闭该目标，不反复给奖励；全部只给下面的具体知识，无现金、属性或扮演奖励。这是本批原创固定事实，不由运行时模型推理补出。

## MARKET-CONTACT-01｜先问清交易规矩

普通人已拥有`lead.market.contact`后，可在调查目标选择“核实旧物中间人”。该调查花1AP，生成一次卡；固定正文：“中间人愿意说明固定货目与交易方式。这里不保证出售任何特定魔药材料。你可以核实这条渠道，也可以离开。”

- `.verify`“核实联系人”：NONE、无额外费用；本原创联系人确实拥有固定市场渠道，提交验证事实并永久全局开放黑市入口。不赠商品、能力、组织身份；库存只能取正式已制作池，缺货明确显示，不由模型补货。
- `.leave`“暂不建立渠道”：不开放，保留已知联系人线索以便以后主动核实；不自动重复排队。

联系人不是原著具名角色。本卡仅为普通人版本；非凡者未解锁市场时需要其当前序列变体，不能偷用普通人卡兜底。正式市场商品尚未齐全，开放入口不等于已完成市场内容。

## CARE-ACCESS-01｜街区诊疗告示

每个普通人初始已知线索列表可有一条来自住所公开告示的“核实普通诊疗点”，不显示原著人物或神秘信息。主动调查消耗1AP，以固定结果确认本原创诊疗点提供普通伤口处置，写`known.ordinary-care`；不治疗、不收费、不发能力。以后符合条件的休养可进入`LIFE-CARE-01`，医疗信用是否可用读取债务包。正常人也可先核实；同一地点不重复获得奖励。

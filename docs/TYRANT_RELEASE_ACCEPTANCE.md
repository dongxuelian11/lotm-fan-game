## 安装与复验

Node.js 24.15–24.x；桌面启动需要图形环境和Electron运行时。安装、严格类型与生产构建已在本次云环境完成；可见Electron窗口、Windows实机和安装包未验。

```sh
npm ci
npm run typecheck
npm run build
npm start
```

若事先跳过Electron下载，可先执行`npx --no-install install-electron`。浏览器开发使用`npm run dev:renderer`，其内存试玩不代替SQLite桌面存档。

本阶段聚焦测试依赖原193四包与新215十五包，使用专用19包组合清单：

npm test -- tests/domain/tyrant-natural.test.ts --maxWorkers=1 --no-file-parallelism

npm test -- tests/renderer/TyrantCapture.test.tsx --maxWorkers=1 --no-file-parallelism

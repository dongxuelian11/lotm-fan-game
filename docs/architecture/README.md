# 架构图

- [交互式运行时架构图](game-runtime-architecture.html)
- [可编辑 Archify 源文件](game-runtime.archify.json)

这张图表达重构目标，不宣称所有节点已经实现。当前已有 React 周仪表盘、公开合同、确定性随机、事件底座、浏览器内存试玩和 Electron/SQLite 原型；应用编排器、内部/公开状态拆分、版本化内容注册表与途径运行时仍属于下一阶段重构。

图的核心约束是：

1. 浏览器试玩与桌面版共用一套应用层和领域规则；
2. 途径复用周行动、事件、世界脉冲和存档，不另建第二套游戏循环；
3. Renderer 只读取公开投影；
4. RAG 只接收公开事实并生成可回退表现文本，不能反向裁决规则；
5. 事件与世界模拟在人物死亡、归属或关键条件变化后重验连续性依赖；
6. 多回合转盘与世界事件都在完整领域提交边界保存，不产生可回滚的动画中间档。

原著关键人物、轻量具名角色、主要组织聚合状态、事件模板/变体/实例和多周目槽位属于现有节点内部责任，不新增顶层依赖，因此本轮不重画拓扑。细节以技术架构与事件卡文档为准。

该图用于理解、讨论和重构导航，不是审批门禁，也不恢复旧架构哈希或回执流程。详细说明见 [游戏运行时与重构架构](../TECHNICAL_ARCHITECTURE.md)和[途径玩法与内容架构](../PATHWAY_GAMEPLAY_ARCHITECTURE.md)。

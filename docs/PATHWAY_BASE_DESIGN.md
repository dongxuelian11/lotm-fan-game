# 22条途径基础序列设计

2026-10-09状态同步：22条均已收齐完整候选，5条整包已确认、17条候选。新收11条以PATHWAY_DOCUMENT_INDEX链接的独立稿为正文；本文件旧表仅为基础/历史底稿，不能据其PENDING误报整条途径未设计。当前首份可玩版不接全部途径，见PLAYABLE_SLICE_PLAN。

本文件是所有途径和序列的第一入口：先登记原著序列名、继承关系和完成状态，再进入量化、机制与日常效果文件。它不替用户锁定尚未核验的名称、能力或数值。

## 当前生产顺序

22条候选已收齐，不重新派发旧待设计名单。先完成普通人首案可玩版，再核验占卜家9的真实配方、材料、资源和失败闭环；逐途径完整事件与模拟仍待制作。所有途径继续分开事件盘与战斗盘；内容字段PENDING不自动完成，已确认机制不重复询问。

## 每条序列的统一基础记录

新建或补全序列时，必须按下列字段登记：

| 字段 | 要求 |
|---|---|
| 途径/序列 | 标准途径名、序列号、序列名；未核验名称写 `CANON_AUDIT_PENDING` |
| 继承关系 | 明确继承哪些前序能力；不默认复制特殊机制 |
| 原著边界 | 来源定位、事实/受限推断/游戏适配标签 |
| 量化状态 | 指向[量化与配速](PATHWAY_QUANTITATIVE_DESIGN.md)的状态 |
| 机制状态 | 指向[战斗机制](PATHWAY_MECHANISMS.md)的状态 |
| 日常状态 | 指向[日常技能效果](PATHWAY_DAILY_EFFECTS.md)的状态 |
| 内容状态 | `PENDING`、`USER_CONFIRMED` 或 `PUBLISHED`，不得用代码存在替代确认 |

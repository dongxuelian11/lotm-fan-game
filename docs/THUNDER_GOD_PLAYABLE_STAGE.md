# 雷神有限可玩阶段（0.193.0）

本阶段接通水手途径序列2至序列1雷神，沿用水手至天灾八阶实际履历、22项原掌握及其零值。雷势引导与风雷护持从零开始，原小湾、水量、闸与轮具损耗、诺拉已消耗的精力保留。

## 当前玩法

- 实付指导、三项专业准备、五次实际劳动抵扣与独立成品魔药。准备时间从真实天灾晋升周计算；失败耗尽当瓶和当次准备，供应耗尽可付费申请下一周的新原瓶。
- 返回同一十二米小湾，向诺拉和技师芬恩取得当次许可。本人付费购得独立原靶与护片，沿实际路线放置、观察、使用和归还。两位成年人实际走出作用线后才可施术。
- 雷势引导只帮助随后一次独立的超自然放电检定，真实命中才磨损原靶并增加掌握。风雷护持只保护本人随后一次已声明的小规模练习冲击；释放冲击会磨损护片，失败仍可采用普通手柄收束。
- 遮挡、条件改变、过期或撤回许可会使窗口失效。普通停止、清罩、收回原物及步行离开始终依据实际现场条件处理；零行动收束后的正常周结仍然发生。
- 三案与反思后，可继续普通生活，或接触湾外干平台上的独立对手欧伦。成人先实际退场。实战只使用实际继承能力、原杆、有限新窗口和普通动作；旧海水不会自动复制到平台。

## 来源与实现边界

原著第四部83章的暴君牌明确列出天灾2、雷神1和暴君0，但没有在叙述中展示雷神完整主辅配方、晋升仪式或初晋能力参数。成品渠道、专业准备、场景、两项有限技巧及数值属于本作原创实现。

数十万恐惧服从的追随者、单独挑战另一位真神并存活的条件属于晋升暴君0。电流化、光速和星球级灾难描述也不能直接作为雷神1的常规能力。雷神怒吼巨锤的物品效果及古代双份序列1天使之王的表现不直接赋给新晋者。

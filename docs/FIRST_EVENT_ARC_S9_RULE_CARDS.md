## 1. 卡片解析规则

每个途径变体拥有三个独立节点：`EVT_S9_NIGHTSHIFT_<CODE>_A/B/C`。每个节点常态显示两个途径化普通选项；第三项`[H]`由当前事件的`passiveAbilityHooks[]`自动匹配并解锁。没有匹配时，第三项及其名称、能力来源、成本和结果完全不进入公开投影。

`[H]`不是“发动日常能力”按钮。能力在事件实例形成时已经被动完成`REVEAL/WARN/MODIFY/UNLOCK/GUARD`；玩家点击的是能力带来的新处置路线。被动匹配本身不消耗行动点和硬资源。选项如果要支付金钱、灵性、物品或进入战斗，仍必须单独明示。

所有A/B阻塞卡本身不再消耗主要行动。C卡只有明确写“进入战斗”的选项才打开转盘；其它选项使用普通判定。选择提交后原子结算，不能返回重新选择或重掷。

## 4. 路径差异验收

22条变体必须通过以下人工检查：

- 隐去途径名称后，仍能从公开矛盾、选择和代价判断它们不是同一张卡换皮；
- 每个节点在没有`[H]`时仍有两个成立的选择，不因能力条件未满足而卡死；
- 被动能力只揭示、警告、修正、解锁或保护，不替玩家自动选择；
- 每条途径至少有一项会延续到本弧之外的独立后果；
- 道德倾向由玩家选择，不由途径强制：刺客不必杀人、罪犯不必残虐、太阳也不能免费成为绝对正确；
- 所有路线最多优先保证一个C阶段主目标，不能出现途径专属完美解；
- 序列9变体不得调用序列8—0能力；发现越级时该节点直接标记`CANON_FIX_REQUIRED`。

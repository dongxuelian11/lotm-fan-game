# 核心循环与日常行动

`STATUS=PARTIALLY_LOCKED / SOURCE=D-CORE1..5,D-WORLDFEEDBACK0..6,D-ACTIONS1..2,D-WORK1..3,D-LEARN1,D-INVEST1,D-ACTING1,D-REST1,D-VISIT1,D-CITYTRAVEL*,D-ACTIONBUDGET1..3,D-RECOVERYVALUES1..3,D-RESOURCECAP1,D-ECON0..9,D-DEBT1..3`

## 周循环

1. 角色查看当前人物卷宗、世界日志、可见线索、资源和情境按钮。
2. 玩家选择本周可用的主要行动；行动真实消耗本周行动机会并进入结算。
3. 行动可能直接成功、触发普通判定、推进调查，或在调查内部触发战斗转盘。
4. 行动结算写入资源变化、能力掌握度、知识、扮演进度、线索、关系和事件日志。
5. 本周动态行动力用尽后按 `D-CORE5` 进入世界脉冲：职业与产业收入、生活费、债务、世界脉冲、NPC议程、事件和后续条件依次结算。
6. 玩家看到世界回应，再规划下一周；没有固定周数上限，死亡或明确终局条件才结束一局。

## 持续世界动态与行动反馈

`D-WORLDFEEDBACK0` 已锁定：每个被接受并结算完成的玩家行动都必须产生可见反馈，世界还要在周期推进中持续生成独立事件与 NPC/组织动向。它补强“行动后世界回应”的体验，但不把每次行动都改成阻塞事件卡，也不改变最后一个行动持久化后才执行完整周脉冲的既有顺序。

参考源码已确认存在行动日志、世界状态漂移、NPC 议程与被动事件四条反馈链；新项目必须按“行动结算并持久化 → 轻量反馈/候选反应 → 最后一次行动后的完整周脉冲”保持因果顺序。轻量反应是否每次运行、反馈显示位置、玩家知识过滤、因果标签、首版离屏模拟范围和延迟后果仍由 `D-WORLDFEEDBACK1..6` 决定。

## 固定与情境按钮

固定核心按钮保持少量、稳定、可理解。第一版已明确四个：

| 行动 | 主要职责 | 已锁定边界 |
|---|---|---|
| 工作 | 获取货币 | 职业工资与全部有效产业收益一起结算；常规收入按固定公式，不做无来源随机浮动 |
| 学习 | 获得非凡知识、增长知识属性 | 必须生成具体知识记录；知识数值不能代替配方、仪式、真名或秘密条目 |
| 调查 | 推动剧情和线索 | 可触发普通判定；只有真正进入战斗才切换战斗转盘；调查不是每次必然推进主线 |
| 休养 | 恢复当前健康、精神和灵性 | 只有一个休养按钮，一次同时恢复三项；恢复量按序列、生活档位、当前状态和事件动态计算 |

不设固定拜访按钮；社交通过调查、事件和满足条件后出现的情境按钮发生。第一版也不设置城市切换或地图按钮；城市切换属于未来地图版本，具体旅行规则保留在 `D-CITYTRAVEL*`，不在当前版本自行补完。序列能力、组织任务、地点、关系、线索和事件仍可产生额外情境按钮。

## 资源恢复和结果展示

- 行动按钮点击前显示角色能够合理预期的趋势；已知硬成本显示精确值，未知副作用不提前泄露。
- 结算后准确记录健康、精神、灵性及其他变化、来源和最终值。
- 资源恢复嵌入有生活含义的行动；一个休养按钮同时恢复健康、精神和灵性，但不设无条件统一的“每周自动回血”。
- 休养恢复量按序列/位格与生活档位查基础表，再应用当前状态修正，最后由明确事件覆盖或追加并记录来源；恢复超过上限直接封顶，负值先回到0再进入正值区间。
- 每周行动机会从基准3次开始，再由序列能力、秘偶、职业、状态、生活档位等明确来源按整数共同修正，最低1次；未用行动不结转，额外行动仅限当周。最后一次主动行动持久化后自动进入世界脉冲。
- 生活档位对恢复、普通疾病、卫生、治安和社会场景的影响必须通过具体事件与 NPC 反应体现，不能只显示一个“身份可信度”数值。

## 经济和产业

- 金钱是普通生活、调查准备和非凡成长的共同资源；稀缺商品还受渠道、知识、身份、真假和风险限制，有钱不保证买到。
- 内部统一使用便士整数：1苏勒=12便士，1金镑=240便士；界面再组合显示三种面额。
- 工作一次结算职业工资与所有有效产业收益；每个来源每周最多结算一次。
- 产业是具体命名资产，可同时拥有多项；每项有类型、地点、规模1—5和状态。规模收益倍率为 `1 / 2 / 4 / 7 / 11`，常规收益按类型基础净周收益直接计算。
- 产业通过满足条件的购买、投资、继承、合作或剧情事件取得；常规升级在面板直接付费升一级。
- 生活档位为赤贫、贫困、普通、体面、奢华；贝克兰德基准城区个人周费用为30、120、300、600、6000便士，再乘城市/城区消费系数。
- 生活费包含住房、基础饮食、衣物维护和普通市内交通；医疗、情报、贿赂、额外社交、非凡材料和剧情消费另算。
- 资金不足、搬迁、债务、产业风险和黑市后果都必须事件化。债务首版只维护总额和固定周还款，借款费用一次性计入，不滚动复利。
- 黑市支持查看、购买、出售和上架；每三个月有一次含珍稀物品的拍卖会，具体竞价规则仍未定。

## 扮演进度

符合当前魔药扮演原则的行动才产生扮演进度；调查在同等契合度和风险下基础收益更高。扮演进度与能力掌握度、魔药消化度是不同成长轴，不能按比例自动转换。

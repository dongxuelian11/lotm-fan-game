# 核心循环与日常行动

2026-10-09首份试玩的普通学习/首案入口/空目标处理见ORDINARY_LIFE_EVENT_PACK末节。无有效学习或调查目标时只查看并返回，不接受行动意图、不扣AP；有目标才选择并直接提交。后续通用调查奖励表未制作，不在首版用随机现金/材料占位。生活审核12题已答；当前新增受托方案待整体确认。

2026-09-13补齐候选见[基础生活与恢复](LIFE_AND_RECOVERY.md)：工作/产业每周一次入账、生活账单、AP修正时点和普通人休养治疗。新增取舍未获用户确认前，不把候选当作旧规则已无冲突；实现时须明确采用哪一候选包。最小账单/医疗/康复内容见[普通人生活事件](ORDINARY_LIFE_EVENT_PACK.md)。

## 周循环

1. 角色查看当前人物卷宗、世界日志、可见线索、资源和情境按钮。
2. 玩家选择本周可用的主要行动；行动真实消耗本周行动机会并进入结算。
3. 行动可能直接成功、触发普通判定、推进调查，或在调查内部触发战斗转盘。
4. 行动结算写入资源变化、能力掌握度、知识、扮演进度、线索、关系和事件日志。
5. 本周动态行动力用尽后，先处理该行动产生以及本批已经排队的阻塞事件；全部解决后立即进入世界脉冲，依次结算产业收入（工资不重发）、生活费、债务、世界状态、NPC议程、计划事件和后续条件，并推进一周。
6. 玩家看到世界回应，再规划下一周；没有强制周数或现实小时上限。死亡、其它不可逆终局，或首次完成序列0晋升并结清即时后果时进入周目结算。序列4只进入中盘转折事件，不结束周目。

四个固定行动采用直接提交：点击工作、学习、调查或休养即发送意图，不再插入“再想想／确认安排”二次确认。界面仍应在按钮附近展示玩家能够合理预期的成本与趋势，提交后的精确变化进入结果条、事件卡和纪事。

周目结算不是自由生成的故事结尾。系统先从已提交事实生成结构化本局摘要，再输出成长、求生、调查、关系、非凡代价和世界影响等多轴评价；评价必须列出支持它的关键选择/后果引用。小模型只可在这些固定事实和评价标签上润色，失败时回退审核文本，不能改写结局、遗漏死亡或新增因果。

领域状态内部仍以周脉冲作为基础周期，但玩家主要时间显示使用原著同期日历/事件锚点，而不是只显示“第N周”。第一版日历零点为第五纪1349年6月28日；每次周脉冲从该零点换算公开日期。玩家未介入的原著事件按时间线形成新闻和世界脉冲；玩家与原著人物或关键条件产生可追溯交互后，当前周目可以进入分歧时间线，后续调度必须重新校验人物存活、组织状态与事件前置。

## 持续世界动态与行动反馈

每个被接受并结算完成的玩家行动都必须产生可见反馈，世界还要在周期推进中持续生成独立事件与 NPC/组织动向。它补强“行动后世界回应”的体验，但不把每次行动都改成阻塞事件卡，也不改变最后一个行动持久化后才执行完整周脉冲的既有顺序。

参考游戏源码中可观察到“有限行动用尽后自动推进时间 → 周期结算经济/世界/NPC → 到期连环事件优先 → 一次弹出一张选择卡 → 选择结果写入时间日志”的反馈链。本项目把其月制节拍转译为周制，并采用以下顺序与范围：

1. 行动结算并持久化后执行轻量反应，立即显示紧凑结果条并把同一结果写入纪事。
2. 轻量反应只更新与本行动因果相关的候选后果、观察和必要世界状态，不提前执行整周经济、全部 NPC 议程或完整周脉冲。
3. 行动束结束后执行完整周脉冲，模拟区域/主要组织聚合状态、手工设计的原著关键人物议程，以及其他具名轻量角色的必要状态。
4. 世界真相、角色获得的观察和玩家公开投影分离；界面只显示已确认、传闻/推测，不显示暂时不可见事实。
5. 可知因果明确标注，不可知因果只显示迹象或传闻；即时、延迟、潜伏后果均保存真实原因与可见条件，允许以后揭露。
6. 到期链阶段在本次事件候选中优先于普通卡，但不能抢占已经打开的阻塞卡；它进入最小待处理队列并在前卡结束后显示。
7. 普通事件池使用情境资格、冷却、重复衰减和事件荒保护；普通人每周1—2张、非凡者2—3张是已确认的试玩密度目标，不是硬上限。事件荒保护只能使用合格内容，不能凭空创造卡；负担偏高时减少新随机卡，不删除已经到期的链阶段或必达后果。具体调度参数见事件卡系统第8节候选。
8. 一条多阶段链保存稳定事件 ID、阶段、最早触发周、参与者 ID、必要载荷和失效策略；完成后写入生涯纪事，不能只删掉运行中标记。

### 已确认的主流程补充

主界面显示第五纪年月日与当前原著事件阶段，隐藏周序号，内部仍按周脉冲推进。学习列出3个当前已知且可核验的主题或材料来源，玩家选择1个；成功写入知识记录并增加知识属性，失败记录尝试。调查列出3个当前已知目标或线索，玩家选择1个，可推进线索、事件或战斗但不保证成功。它们不改变四个固定行动、事件卡弹出密度或“调查可触发战斗”的边界。

定向学习可指向一个明确的非知识核心能力训练项目，完成多周项目并通过判定后固定`+1`；具体可训练属性、项目、周数、费用和难度仍待内容设计。

调查行动先展示最多3个已知目标，玩家选择1个后立即进入当前上下文事件池；无事件时使用通用调查结算，无目标时返回“暂无可核验线索”的行动反馈，不再二次确认。通用结算采用多种预设段落文案，允许按序列变体；每次最多1项主要数值奖励，可带极少量次要奖励，总价值受明确上限约束；多条奖励轴同时满足时按调查目标与当前上下文的固定优先级表取第一个满足项。主要奖励按上下文从知识、线索推进、少量现金或普通材料中选一类，不直接给扮演、序列或非凡能力掌握度；每项奖励有明确来源，不得凭空创造世界事实。具体句子、奖励值和优先级表内容仍待批量生成。

事件卡是周循环的主要内容承载，而不是额外任务系统。工作、学习、调查和休养都先完成各自基础结算，再从普通人或当前精确序列的事件包中抽取模板，并装载当前途径的独立内容变体；同一时刻仍只打开一张阻塞卡。晋升后不再抽取旧序列的问题卡；长期生活与关系因果若继续存在，必须变成当前序列尺度的新事件。普通人阶段保留高密度日常事件，成为非凡者后事件候选目标配比调整为约70%非凡相关、30%普通生活与社会后果，宇宙级恐怖只进入少数明确高峰。

## 固定与情境按钮

固定核心按钮保持少量、稳定、可理解。第一版已明确四个：

| 行动 | 主要职责 | 已锁定边界 |
|---|---|---|
| 工作 | 获取货币 | 工作只结算职业工资，产业统一周末结算；事件可以通过身份实践、责任或处世方式推进扮演 |
| 学习 | 获得非凡知识、增长知识属性 | 必须生成具体知识记录；对扮演原则的有效理解可以通过事件推进扮演与消化 |
| 调查 | 推动剧情和线索 | 可触发普通判定或战斗；同等契合与风险下通常提供较高扮演收益 |
| 休养 | 恢复当前健康、精神和灵性 | 恢复三项状态；反思、自我控制和处理能力副作用的事件可以推进扮演或消化 |

学历按出身给默认四档，可信时可在出身/职业步骤选择至多一个带明确代价的条件替代档。学历提升不是普通经验条：玩家必须支付费用、持续多周推进长期进修项目，并在里程碑事件后升档；普通学习只能推进项目，不能立即升级。具体档位加值、周数、费用、学校和事件仍待设计。

贫民/劳工出身第一周显示一条出身专属线索或熟人传闻并开放早期事件资格；玩家仍须调查或经历事件才取得入口。黑市经联系人验证后可最早开放；地下组织另需信任或引荐，接触不等于加入；魔药只提供线索或取得机会，必须经过世界事件、材料条件与玩家选择获得。不设固定拜访或加入组织按钮；正式加入只能由事件卡提出，并由玩家明确选择，拒绝不能封死途径成长。社交通过调查、事件和满足条件后出现的情境按钮发生。

首版不制作可行走地图或旅行路线，但允许轻量主动迁居。玩家当前居住地开局固定为贝克兰德；只有已经通过调查、关系或事件解锁且拥有审核事件池的目的地，才在地点抽屉出现“迁居”情境行动。发起迁居消耗一次剩余主要行动机会并展示旅费、到达日期和可预见影响，随后打开迁居事件卡；处理卡片本身不再次扣行动。结算成功后切换当前城市与主要事件池。序列能力、组织任务、地点、关系、线索和事件仍可产生其他情境按钮。

组织关系不与途径身份绑定。每条途径都必须至少保留一条无需正式加入任何组织也能继续取得关键配方、材料、仪式条件和晋升机会的合法路线；组织可以降低代价、改变风险或提供不同事件，但不能成为唯一通行证。

## 资源恢复和结果展示

- 行动按钮点击前显示角色能够合理预期的趋势；已知硬成本显示精确值，未知副作用不提前泄露。
- 结算后准确记录健康、精神、灵性及其他变化、来源和最终值。
- 资源恢复嵌入有生活含义的行动；一个休养按钮同时恢复健康、精神和灵性，但不设无条件统一的“每周自动回血”。
- 休养恢复量按序列/位格与生活档位查基础表，再应用当前状态修正，最后由明确事件覆盖或追加并记录来源；恢复超过上限直接封顶，负值先回到0再进入正值区间。
- 每周行动机会从基准3次开始，再由序列能力、秘偶、职业、状态、生活档位等明确来源按整数共同修正，最低1次；未用行动不结转，额外行动仅限当周。最后一次主动行动持久化后自动进入世界脉冲。
- 生活档位对恢复、普通疾病、卫生、治安和社会场景的影响必须通过具体事件与 NPC 反应体现，不能只显示一个“身份可信度”数值。

## 经济和产业

- 金钱是普通生活、调查准备和非凡成长的共同资源；稀缺商品还受渠道、知识、身份、真假和风险限制，有钱不保证买到。
- 内部统一使用便士整数：1苏勒=12便士，1金镑=240便士；界面再组合显示三种面额。
- 工作只结算职业工资；产业统一周末结算；每个来源每周最多结算一次（生活审核5B）。
- 产业是具体命名资产，可同时拥有多项；每项有类型、地点、规模1—5和状态。规模收益倍率为 `1 / 2 / 4 / 7 / 11`，常规收益按类型基础净周收益直接计算。
- 产业通过满足条件的购买、投资、继承、合作或剧情事件取得；常规升级在面板直接付费升一级。
- 产业只提供被动周期收益、风险事件和少量直接升级，不扩张成员工、库存、订单或生产线管理。
- 生活档位为赤贫、贫困、普通、体面、奢华；贝克兰德基准城区个人周费用为30、120、300、600、6000便士，再乘城市/城区消费系数。
- 生活费包含住房、基础饮食、衣物维护和普通市内交通；医疗、情报、贿赂、额外社交、非凡材料和剧情消费另算。
- 资金不足、搬迁、债务、产业风险和黑市后果都必须事件化。债务首版只维护总额和固定周还款，借款费用一次性计入，不滚动复利。
- 正常职业收入的平衡目标是维持赤贫、贫困或普通生活，而不是让玩家在不工作时也能稳定支付全部普通开销；压力来自工作与调查/非凡成长争夺行动。玩家主动选择生活档位，系统每周自动扣费；不足时提供借债、变卖、降档或承担后果的事件选择。债务可以逐步导致催收、关系恶化和资产损失，但不直接结束周目。
- 已开放市场的浏览、普通购买、出售和上架不消耗主要行动；只有接头、抢购、交付、争夺或其他事件明确声明时才消耗行动或触发阻塞卡。
- 黑市支持查看、固定价格购买、固定价格出售和上架；每三个月有一次含珍稀物品的拍卖会，采用固定拍卖槽位。首版不引入动态NPC竞价，也不做商品级资格或来源校验。首次联系人验证是入口门槛；成功后永久全局开放，按固定价格直接交易且不再受地点或事件影响。入口明确显示“联系人已验证/黑市已全局开放”，不重复阻塞验证。库存和季度拍卖槽位只来自作者审核固定池，并按日期或季度确定性刷新。具体联系人、商品池、金额、挂牌期限、手续费与事件文本仍待后续设计。

## 扮演进度

符合当前魔药扮演原则的行动才产生扮演进度；工作、学习、调查和休养都可能通过事件产生有效实践，调查只是在同等契合度和风险下基础收益更高。按钮本身不自动给进度，必须由事件模板记录本次行为、理解、风险、新意与后果。

扮演进度显示明确数值或明确进展，魔药消化只显示可解释阶段和最近原因。两者与能力掌握度是不同成长轴，不能按比例自动转换。机械重复的低风险行为收益递减；RAG/小模型生成不同文案不会把同一机械行为伪装成新的扮演证据。

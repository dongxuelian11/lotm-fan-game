# 序列9事件模板包

最后更新：2026-09-02

状态：`CONTENT_ARCHITECTURE_CANDIDATE_V1 / 18_SEQUENCE_TEMPLATES_DEFINED / FIRST_TEMPLATE_3_PATHWAY_CANDIDATES / OTHER_19_BLOCKED_BY_PATHWAY_DESIGN / CONTENT_EXPANSION_PAUSED / NOT_PLAYTESTED`

本文件只设计序列9的事件内容层。它不覆盖普通人事件，也不允许序列8—0继续抽取这些事件。22条途径可以复用同一个序列9结构模板，但玩家实际看到的卡必须是当前途径的独立内容变体。

## 1. 内容计数

事件模板和玩家可见内容必须分开统计：

- `SequenceEventTemplate`只是一种冲突结构，不算22条途径已经各有一张卡；
- `PathwayEventVariant`才是某条途径可以实际进入候选池的规则内容；
- `NarrativeVariant`只是同一规则结果的审核文案变化，不增加玩法卡数量；
- 三阶段事件弧按3个事件节点计数，每个途径变体也必须分别拥有3个节点；
- 某条途径没有独立变体时，该模板对该途径就是`NOT_AVAILABLE`，不能回退到全途径通用成品卡。

因此“18个序列9模板”只表示结构容量。若18个模板全部覆盖22条途径，最多形成396个途径规则变体；这不是首版必须一次完成的硬配额，也不能通过自动换名宣称完成。

## 2. 序列9的问题尺度

序列9角色刚获得一种明确但有限的非凡身份。事件应让玩家发现能力改变了解题方式，却仍然受到金钱、职业、证据、伤势、灵性、社会身份和组织追查约束。

序列9事件可以处理：

- 一个人、一户家庭、一个工作场所或一条街区范围的异常；
- 一件低层危险物、一名同层或略高威胁、少量普通敌人；
- 初次使用能力留下的暴露、误判、污染或人际后果；
- 配方、材料、黑市、导师和组织接触，但不自动赠送晋升条件或组织资格；
- 日常工作、学习、调查和休养中被动触发的能力效果。

序列9事件不应处理：

- 城市级灾难、半神公开行动、天使与神灵权柄冲突；
- 直接改变历史、命运、世界规则或大规模组织格局；
- 玩家尚未拥有的后续序列能力；
- 只因玩家已是非凡者就自动知道秘密、获得配方或免除生活压力。

## 3. 第一批18个结构模板

每个模板都先绑定序列9尺度，再按途径写独立事实、选择和后果。四个主要行动只是触发入口，不把能力变成新按钮。

| 模板ID | 主要入口 | 结构冲突 | 途径变体必须改写什么 |
|---|---|---|---|
| `S9-WORK-01_CONCEALED_HAZARD` | 工作／调查 | 日常剥削或事故掩盖低层非凡危害 | 玩家为何注意到、如何取证、如何处置、为谁承担代价 |
| `S9-WORK-02_ABILITY_AT_WORK` | 工作 | 能力可以提高工作结果，但使用会暴露异常 | 能力被动如何触发、玩家是否掩饰、雇主和同事如何理解结果 |
| `S9-WORK-03_UNFAIR_ORDER` | 工作 | 上级要求玩家完成一项危险或不公命令 | 途径如何识别风险、拒绝／曲解／执行方式、职业与扮演后果 |
| `S9-WORK-04_MISSING_PAY` | 工作 | 工资、工伤或材料账目被人操纵 | 途径特有的证据入口、谈判方式和追责路径 |
| `S9-LEARN-01_WRONG_MANUSCRIPT` | 学习 | 资料大部分正确，但混入一段危险错误 | 途径如何发现错误、保留哪些知识、失败时形成何种误解 |
| `S9-LEARN-02_MENTOR_TEST` | 学习／关系 | 一名知识提供者用含糊任务试探玩家 | 试探内容、回应方式、关系和知识门槛必须贴合途径身份 |
| `S9-LEARN-03_PRACTICE_BACKFIRE` | 学习 | 一次低风险练习产生真实但可控的反噬 | 该途径具体失控方式、恢复手段、暴露与掌握度证据 |
| `S9-INVEST-01_MISSING_WITNESS` | 调查 | 关键证人因恐惧、利益或异常影响失联 | 发现、接近、保护或利用证人的方式及其伦理后果 |
| `S9-INVEST-02_FALSE_CLUE` | 调查 | 一条很像答案的线索实际上由人刻意布置 | 途径为何容易相信／识破、如何验证、误判会伤害谁 |
| `S9-INVEST-03_NIGHT_TAIL` | 调查 | 玩家需要在有限时间内跟踪一次秘密交接 | 追踪能力、失手方式、是否接触交易者和暴露结果 |
| `S9-INVEST-04_UNREGISTERED_OBJECT` | 调查／黑市 | 一件未登记低层非凡物正在造成局部后果 | 识别、隔离、交易、上报或利用的途径路线与专属代价 |
| `S9-REST-01_DELAYED_COST` | 休养 | 此前能力使用或战斗后果在安全时才显现 | 身体、精神、灵性或污染中哪一项恶化，以及途径特有恢复选择 |
| `S9-REST-02_INTRUSIVE_VISITOR` | 休养／关系 | 有人因玩家近期异常表现登门试探或求助 | 来访者掌握的证据、玩家如何遮掩／合作、关系后果 |
| `S9-REST-03_DREAM_OR_RESIDUE` | 休养 | 睡眠、物品或住处残留一条不完整异常信息 | 信息以何种途径形式出现、能否验证、错误解释的代价 |
| `S9-MARKET-01_COUNTERFEIT_MATERIAL` | 黑市／学习 | 关键材料或知识被掺假，但卖方也未必知道真相 | 途径鉴别方式、退货／跟踪／利用选择和经济后果 |
| `S9-MARKET-02_BID_AND_DEBT` | 黑市／拍卖 | 有用物品可得，但价格、人情债和来源风险互相冲突 | 该途径真正需要什么、可接受何种债、竞争者为何注意玩家 |
| `S9-SOCIAL-01_FACTION_CONTACT` | 关系／任意行动 | 组织或独立非凡者提出有限合作 | 接触理由、合作内容、拒绝后果；绝不自动入会或绑定途径 |
| `S9-CONFLICT-01_PEER_THREAT` | 调查／事件后果 | 一名同层对手或受控危险把局势推入对抗 | 战前信息、是否触发转盘、逃脱／谈判入口及胜负后因果 |

这18个模板覆盖四项主要行动、经济、关系和战斗入口，但不是内容上限。新增模板必须回答“它提供了哪种此前没有的选择结构”，不能只替换地点、NPC姓名或异常物外观。

## 4. 22条途径变体的最低差异合同

一个模板面向某条途径发布前，必须同时满足：

1. 独立`pathwayVariantId`与事件ID，不与其它途径共用成品规则记录；
2. 至少一个只属于该途径身份的公开切入，而不只是结算时增加数值；
3. 两到三个符合该途径思考方式的普通选择，不能所有途径都复制同一组选项；
4. 能力条件满足时才出现的隐藏选项；不满足时完全不存在；
5. 至少一项途径独有的失败、代价或不可兼得结果；
6. 至少一项可用于消化或扮演判断的行为证据，但不因点击正确答案自动增加进度；
7. 独立的后续计划事件、关系变化、暴露、污染、知识或资源后果；
8. 明确列出本序列不能使用的后续能力，防止越级。

如果只做到“同样三项普通选择＋一个专属隐藏按钮”，该变体判定为`REJECTED_RENAME_ONLY`。

## 6. 内容生产顺序

事件内容扩展暂停，先完成22条途径设计。恢复后按以下顺序继续：

1. 完成除占卜家、观众、猎人外的19条途径序列9—0设计；
2. 用完成后的能力、扮演、战斗和日常边界重写对应19条事件变体；
3. 再制作`ABILITY_AT_WORK`、`WRONG_MANUSCRIPT`、`MISSING_WITNESS`和`DELAYED_COST`；
4. 每完成一个模板，检查22条变体是否真的改变选择与后果；
5. 序列9内容通过审查后，再建立新的序列8模板包，绝不向上复制本包。

小模型与RAG可以帮助生成每个已经定稿变体的审核文案，但不能填写本文件中尚未设计的选项、规则、能力效果或后果。

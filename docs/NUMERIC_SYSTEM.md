# 底层数值与判定

2026-10-09本轮采用方案：普通人初始化灵性15/15仅为静态容量，无主动消费；首份可玩版整体确认后方实施，不表述成此前逐项已确认。普通学习难度/空目标规则见ORDINARY_LIFE_EVENT_PACK末节；旧物数值见ORDINARY_RISK_EVENTS第7节且不进首案试玩抽取。

本文件只记录已经确认的公共骨架；具体能力数值、魔药增量、恢复表数值、污染事件内容和许多难度仍保持显式 `PENDING`，由后续设计和试玩补齐。

## 面板

### 四项核心能力

| 字段 | 范围 | 作用 |
|---|---:|---|
| 体魄 | 0—500 | 身体承受、恢复、近身行动和相关能力条件 |
| 感知 | 0—500 | 观察、灵视、危险感知、目标识别和相关能力条件 |
| 意志 | 0—500 | 精神承载、抗性、维持和相关能力条件 |
| 知识 | 0—500 | 学习、理解、研究和信息分析；不等于已知具体秘密 |

普通人通常为10—20，开局基准为15，再由出身、职业、学历、特质和缺陷确定性修正（年龄按生活审核1A不额外加减属性）；普通训练通常软上限20，极少数专业训练可到25。出身修正形状为主`+2`、次`+1`、短板`-1`、中性`0`；职业修正形状为主`+2`、次`+1`、其余`0`，工资与一次性初始资金使用低/中/高三档。学历是独立的四档类别：无正式学历、基础教育、中等/职业教育、高等教育；无正式学历不自动等于文盲，也不使用0—500。每档按表给予固定开局知识加值，并在成功学习时给予固定额外知识，不使用百分比、不增加非凡能力掌握度、不自动授予秘密。具体档位加值、学习增益、逐出身默认/条件替代、进修周数与费用仍待后续设计。定向学习可通过多周训练项目使一个非知识核心能力固定`+1`；训练目标、周期、费用和难度仍待内容设计。序列1是500端点，序列0的权柄和神性不继续塞进这条刻度。

不设统一“交际/魅力”、幸运、灵巧、全局声望或体力属性。社交结果由身份、关系、性格/缺陷、具体技能、信息和情境共同决定。

### 三项当前状态

2026-09-13普通人初始化核对：`src/shared/contracts.ts`的`R2_FIXTURE_DEFAULTS`使用健康100/100、精神100/100、灵性15/15、污染0；它是原型临时值，不是来源或玩家确认。正式设计候选采用健康/精神100、灵性15/15、污染0、无伤起步；灵性15为游戏适配的静态容量，不授予灵视或主动能力，也不由四属性自动派生。用户尚未确认该灵性起点。没有真实消费来源时保持未消耗，不为了让资源条有用编造能力；首次服药后的上限变化读取对应序列包，不能直接重置为满值。

- 健康：常态上限100；明确来源可使当前值低于0，负值表示透支。
- 精神：常态上限100，与灵性分开；明确来源可使当前值低于0，负值表示透支。
- 灵性：当前值/上限，常态上限0—500；明确来源可使当前值低于0，负值表示透支，不抬高上限。

这些状态不是能力属性；低值会影响战势、行动和后果，穿过0时按各自明确的 `onZero` 规则处理。负值下限由来源的绝对 `overdraftFloor` 字段声明；首次穿过0触发一次，战斗读取负值按0处理，特殊能力必须显式声明例外。

## 普通情境判定

只有行动确实可争取且后果重要时才进入判定。权限、前置条件、免疫、位阶否定或客观不可能必须在判定前拦截；无风险的日常事项直接成功。

基础公式：

```text
rawChance = 50% + 2% × (effectiveAbility - difficulty)
chance = clamp(5%, 95%, rawChance)
```

`effectiveAbility` 由相关核心能力、具体技能、工具、准备、情报、状态和情境修正组成。所有修正先按来源合并，再与难度比较。相等为50%，高5点为60%，低5点为40%。

普通判定使用1—100整数：1—5为大成功，96—100为大失败；6—95再与最终成功率比较，得到普通成功或普通失败。四档解决质量不是“收益/代价”四档。

熟练度不提供跨能力的通用百分比或有效能力值加成。它只能按每项能力自己的规则改变控制、消耗、风险、持续、高级用法或其他已声明效果；序列和位格决定能力本质上限。

## 解决质量与实际后果分离

一次判定只掷一次 d100。骰子确定 `resolutionTier`，实际结果由有来源的 `consequences[]` 独立结算。

- 大成功可能更完整、更快或更深入，也可能因接触更深而引来注视。
- 大失败可能偏离目标、误导或升级，也可能意外避开更深污染。
- 同一次行动可以同时完成目标、暴露身份、获得危险知识或损害关系。
- 反转必须能追溯到神秘联系、位阶、污染、封印物副作用、人物动机或既有隐患，不能用“随机猎奇”冒充克苏鲁未知。

## 污染

污染独立于精神状态，第一版使用玩家始终可见的0—100污染主值。后台仍可记录来源、性质和事件，供因果结算与追溯使用；污染可能损伤健康、精神或灵性，但精神下降不是污染本身。污染主要在明确阈值触发来源明确的事件、症状和后果，不把每1点污染自动改成全局判定、战斗或行动力百分比。公共阈值带固定为0—24、25—49、50—74、75—100；污染进入新的阈值带时检查一次事件，离开阈值带不反向触发，也不由周脉冲重复刷同一进入事件。

## 资源归零与透支

- 任何可能使健康、精神或灵性穿过归零线的来源必须声明完整 `onZero`，否则内容校验失败、拒绝载入。
- 需要判定的 `onZero` 复用大成功、成功、失败、大失败四档；后果已唯一确定时不强制判定。
- 归零难度由具体来源声明，可以是固定值或读取权威字段的确定性公式；不能由系统按损失量猜测，也不能由 AI 临时生成。
- 同一来源同时清空多项资源时只进行一次联合 `onZero`，统一映射全部后果。
- 资源低于0时继续保留来源声明的透支值；来源没有声明透支下限就不能继续降低。
- 同一资源首次从正数穿过0只触发一次 `onZero`；后续继续变负只更新当前值，不重复触发同一来源的归零规则。
- 战斗状态分档和战势比例读取负值时按0处理；能力或封印物需要例外时必须由自身数据显式声明。
- 来源的绝对 `overdraftFloor` 必须写入内容数据并进入结算日志；字段缺失或非法时内容校验失败。
- 恢复超过健康、精神或灵性当前上限时直接封顶，溢出丢弃；休养处理负值时先回到0，剩余恢复量才进入正值区间。
- 非战斗归零不自动套用战斗生存转盘；健康归零的战斗特殊规则见 [战斗与转盘](COMBAT_ROULETTE.md)。

# 封印物系统与资料库边界

## 第一版范围

项目建立封印物全量目录资料库，但第一版只为12件封印物编写完整设计。

- 全量目录只承担经来源核验的索引与元数据：名称/别名、来源等级、所属世界时期或组织、已知状态、审计标记和内容状态。
- 目录索引不等于可获得、可装备或已实现的游戏物品；没有完整规格的条目必须保持 `CATALOGUE_ONLY` 或 `PENDING`。
- 12件完整条目必须逐件填写效果、可触及条件、持有/使用代价、负面或污染风险、消耗/充能、战斗转盘权重与命中效果、普通情境用途和来源说明。
- 12件完整条目优先覆盖不同用途、风险和获取渠道，先做原著资料库核验，再逐件设计；至少覆盖战斗、调查、经济中的一类玩法。
- 封印物是独立于途径能力的额外能力来源；只要当前可携带、装备或立即取用，就自动进入战斗能力盘，玩家不能战前删格子配牌。
- 封印物效果不能绕过胜负盘、生存盘、死亡封存或公开投影边界；强力效果与副作用分开结算。

## 原著与实现边界

- 全量目录不得把未核验的社区列表、原文、私有语料或无来源素材写成事实。
- 原著名称、效果和来源必须逐项核验；无法确认的条目只保留待审元数据，不进入可玩池。
- 首版12件的具体名单、来源等级、数值、事件入口和获得方式仍待后续分批设计；本文件不自行补完。
- RAG/小模型只能帮助检索候选和改写玩家已知描述，不能生成封印物效果、概率、代价、奖励、惩罚或存档变化。

## 与战斗和经济的连接

封印物可以由调查、事件、黑市、季度拍卖或其他已审核渠道获得；渠道与价格必须由对应内容定义声明，不能因进入目录而自动赠送。完整条目完成后才能参与能力盘模拟和玩家验收。

12件完整规格统一记录：原著身份或来源、获取与可触及条件、能力效果与限制、持有或使用代价、负面或污染风险、消耗或充能、战斗转盘贡献、普通情境用途与可见范围。完整规格必须有可追溯原著来源，无法核验的效果或代价只能留在目录索引。未完成条目只显示名称，名称主要按知识档位与已知来源状态在固定索引中逐步揭示；玩家无法获得、装备、购买或使用，暂作背景。

12件拥有完整规格的封印物每件至少配置一条作者审核的获取渠道；渠道可以很晚、很稀有或附严格条件，但不能由运行时AI凭空生成。具体名单、渠道、价格、概率和事件仍待逐件内容审查。

### 药物、血食与再生

- 药剂只从已持有、未过期、预先授权的成品进入盘。命中使用时扣一次批次数量，空瓶不留可再次使用模板。主攻攻击药取普通预算；稳定药替代自保，暂抵消目标一次身体伤势惩罚到回合结算；干扰药成功使目标下一次身体贡献×0.75至回合末。相同药效覆盖不相乘。解毒只除一项确属适应证的毒，不兼治神性污染、精神操纵、灵魂死亡。
- 日常生产事件必须给一份输入包→一份成品、有效期、禁忌与失败废料。加工不产金币，买方按已写订单/市场需求收购。非凡特性与晋升配方从不通过普通药剂香水自动获得。高位加强改变疗效与适用范围，不能反复靠“批次强化”翻倍数量。
- 血食沿用物品库存和事件后果，不加饥饿条。开战前记录血食是否满足已写身体需要、血源可用与是否有毒；缺血的具体身体状态来自事件，不能无定义直接扣灵性。战斗爪击没有自动抽血回血；敌方失去的生命不是新血包物品。
- 再生自保命中武装一次稳定：至回合结算抵消一次轻伤身体惩罚，M500可以重伤；不降低伤势等级，不重置伤者再败的死亡递增。永久身体修复走休养事件。太阳、腐蚀心脏、生命剥夺等不可用生理再生统统解除。
- 腐蚀爪M400起对明确`SKIN_SCALE_ARMOR`目标主攻贡献×1.25；石墙、无形领域、盔甲是否带该标签由物品定义，不用文字猜。对抗成功可令目标下一次该类防护贡献×0.75，**替代**本次主攻贡献；普通增势与破甲二选一。
- 驯兽战斗控制只对真实动物：q成功令其下一次针对本体的敌对普通贡献为0，持续本回合。不会一命中就永久转阵营。长期驯服必须事件交互；超凡且智慧对象在低序列不属于普通驯兽默认对象。

### 召唤：真个体、真期限、不是复制术

**选择理由。** 召唤大师呼来能独立行动的存在，压成一段本体动画会丢掉核心身份。候选采用独立次数与真实能力盘，100%该对象自身贡献及伤势；不复制召唤者的盘，不给任意“最多两只”硬上限。低阶驯兽中的已随行自主动物同理；只作为一瞬配合且无自主战斗模板的对象才能用本体次攻预算，二者对同一实体不能同时领取。

每条契约对象记录：实体ID、实际位格与能力模板、当前所在/可到达性、立场、服务范围、到期条件、真实支付、召唤媒介、可被破坏的联系。普通名字不生成真实能力；未完成模板的对象不进正式盘。事件层动物、契约者和赋生对象共享玩家周行动点，只能承担已有代理槽，不能各自再领取工作工资、学习收益或同一事件奖励。

1. **新门**：序列3起，预备/控制命中可建立一次新联系。本场同一`gateInstance`只尝试一次新的未知回应，标记尝试后即不可重复刷陌生援兵；这是将来源“有间隔”落为遭遇级候选，不限制预存契约总数。重新进入同一未结遭遇仍认同一个门实例。
2. **回应盘**：在场景已授权响应池里转`同位格50 / 低一序列25 / 高一序列15 / 异常10`，再等权选实际可用实体；池缺某类，其权重转为“无人响应”，不强塞不存在角色。异常进入已写异常实体或无人响应，不允许小模型造外神。更强对象并非必然臣服，初次约束q，失败按模板拒绝/敌对/离开；低阶对象也要有实际来源。
3. **到场与期限**：新召成功的对象下个完整回合开始转自己的次数盘，默认服务两个完整回合后离场（游戏适配，非原著分钟换算）；首次到场回合之前不补行动。新门破坏前未到场则取消。到期离场不返还已支付物资也不刷新其伤势。
4. **已知契约**：使用`contracted-call`选池中的有效合同目标盘召来；已在场同ID移出池，不能从别的世界再复制一份。同意合作且条件满足直接履约，期限按合同；不同合同可同时在场，没有统一数量硬帽，但每次本体抽中只呼一名，实际角色必须可达并支付已写成本。
5. **到期/破约**：同一战斗不能靠“续约”无成本把临时回应变永久。已写长期合作对象可以正常履约；临时新门续约只能在战后事件商谈。解除召唤不自动抹掉对方留在现实的因果；契约有“返回”才离场。自主敌意改变、施法者失能、媒介断裂分别按合同结算，不都等于瞬间蒸发。
6. **天使与更高位**：通过真正的人物事件/大型准备可签更强对象，不硬削到本体U。天使/神灵响应与世界位置、屏障及同意有关，没有准备和模板就不出选项。原著的星界屏障例外须正文核验；不能用低级新门绕过世界隔绝无限呼神。
7. **快速转盘**：保留每实体独立记录与完整抽取，仅加速动画。同种普通无智能群可以内容聚合，具名智慧个体不能被吞成一份贡献。战斗入场后总阵营基础如何汇总、目标权重如何防“杂兵稀释”，交主对话与愚者/倒吊人/死神/母亲统一。

### 创生者、美神与月亮

- **赋生（序列2）**：对一个实际载体赋生，主槽只立即提供一次赋生攻击的普通主预算×1.25；预备可武装一个事先完成模板的自主对象，从下回合独立抽盘。一次载体只能用一种模式，已活动载体不重生第二个。永久赋生事件需要载体、持续来源与是否繁育定义；不能把钱、成品血或非凡特性递归赋生/收获。血中重生与普通再生同源强化，不因此降低日常血食与污染风险。
- **血中重生**：自保命中、事前有可用未污染自血锚，则武装一次`bloodReturn`到本场结束。第一次身体毁坏型死亡后果且灵魂连续/锚存活，消费锚与标记改为重伤，继承全部败北风险，下一回合仍按重伤行动；第二次死亡不再自动复归。高位生命剥夺、灵魂毁灭、归土断锚不适用。每场一次是候选平衡选择，不说原著只有一次。战后新的血锚须用休养准备，不由战斗伤口免费补满。
- **美（序列1）**：控制命中后数量/目睹目标盘→每人q。同位格成功使目标下一次主动伤害本体的普通贡献为0；低位目标且M400以上成功则失去本回合剩余主动敌对行动，但仍能被动防护并有自己的回合基础。到回合末失效，同名刷新不加层。遮蔽感知、非生命自动机关、同位格美/心智防护可反制；间接危险不一概停止。不是永久恋爱/组织归属控制。神灵高位的瞬间迟疑以q体现，不无条件覆盖超序列。
- **生命支配**：把驯兽的合法目标扩至植物/人/非凡生命；q成功改变下一次敌对动作的合法目标，使其不能选择本体，到回合末。不能控制其主动杀队友或交出全部存档资产；长期服从、人格后果由事件预写。与美同时命中同一个动作只用更强结果。
- **高位召唤**：预备/控制命中，可指向有真实联系的低位生命。无屏障且低位者仅凭本人拒绝，候选保留“不能拒绝被召”的强语义：直接到场，不再抽意志拒召；同位格/高位或受同位格封闭保护时q对抗屏障/对象。**强制到场不建立效忠、不赠独立友军轮盘**；敌人到场仍是敌人。无联系、未知身份不能凭名字抓遍世界。这一强召边界供统一总审。
- **月相权柄（序列0）**：进入终局后由合法月场子盘`绯红40/银月35/血月25`决定当前回合候选；与敌对同位格月场先q，失败维持原环境。绯红沿用月域×1.25；银月令目标区域本回合依赖绯红月联系的能力不可用（只按显式依赖，不封所有非凡）；血月把一个已有灵界通路变可达并令本次区域月域贡献×1.50，随后生成已写失控通路后果，不无限涌出随机怪物。全场同一时刻只有一个场景月相，新相覆盖但不清已提交结果，不能不同目标一边银月一边红月吃双倍。
- **灵性权柄**：稳定方案解除本回合一个明确可稳定的灵性紊乱；压制方案q成功令目标下一次`SPIRITUALITY_DEPENDENT`普通贡献×0.50，替代控制预算，并受AOE总削减限制。原著灵性成本与恢复干预暂仅登记事件用途；实际“提高几倍战斗消耗”保持全局缺口，不在这里发明魔力税体系。
- 序列0即时后果结清就结束周目；血月造成的长期结果进入结局记录，不开启强制无限周的末日养成。

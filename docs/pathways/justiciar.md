## 3. 战斗机制：公布、违规与执行

### 3.1 对抗和目标

只在控制/规则/权柄抵抗时转二元对抗盘，普通增减势不另加一次命中检定。

`Q=clamp(50+0.06×(自身意志-目标意志)+0.04×(本能力m-抵抗能力m)+8×(自身位格阶-目标位格阶)+条件修正,5,95)`，位格阶=9-序列。目标无专项防护时抵抗m=0，但意志仍读真实模板，未知不得当0。专项防护需标签严格匹配；条件修正只有下文列出的管辖+5、专门反制-15。二者可同时存在。精神刺穿普通贡献不使用心智免疫；威严与威慑使用 `MENTAL_INFLUENCE`，灵体刺穿/痛鞭使用 `SPIRIT_BODY_ATTACK`，律令使用 `ORDER_RULE`。

单体盘：按已公开可触及且满足标签的对象等权抽取一个；敌方攻击/控制只选敌方，自保以自己或指向自己的明确效果为目标。规则范围覆盖敌我，不能以阵营过滤规避。能力对象盘只列已观察的真实能力或公开规则，各等权，不预告目标秘密。

范围攻击/禁锢：N为同一区域合法目标数，无放回；数量盘为1/ceil(N/2)/N，权重50/35/15，重值合并，N=0移除。普通贡献按全局1/2/3/4+人数总预算1/1.4/1.65/1.8倍，4以上每人1.8/N；状态逐目标对抗，不因人数复制普通贡献。**广域律令本身是区域条件**，覆盖区域全部在场实体，没有命中数量抽样；其后鞭笞、禁锢等伤敌行为才转数量/目标盘。一个独立实体仍保留原有轮盘；审判者不产生分身或新行动者。

能力目标补充：enforcement、authority、spirit-piercing、pain-whip、discipline、deprivation、balance默认为单体敌方；self-discipline为自身；recognition为一名可见敌人；anomaly-stop/conceptual-balance为一个正在影响自身的效果；order-execution/world-order为一条已公开规则或声明区域；partition/edict/court为场景已存在区域。judgment-sword从序列3可在回合前选择单体或范围模式，范围只含本区域有混乱标签的敌方；world-judgment同样可选择范围，必须逐目标有已成立违规事实。两者范围模式均适用数量盘和总预算衰减，不追加额外独立轮盘；普通攻击不会因为称作“世界审判”就自动命中全世界。目标不足取实际N，不补生成敌人；同次不可重复命中一个实体。

### 3.2 威严、痛鞭、自律与惩戒

- authority：9—7控制槽直接削敌预算，持续仅本次胜势；对象须可受威严影响。4以后可选择升级威慑：放弃普通贡献，Q成功令目标下一次动作转为挣脱；那一次消耗掉后状态消失，同源不叠加。没有“恐惧条”。
- pain-whip控制用法：Q成功，目标下一次普通正向贡献×0.75并消耗状态；持续到目标下一回合结束。心智免疫不能代替灵体防护。事件中只可逼出目标已知的预写证言，错误记忆仍可能错误，不自动判罪。
- self-discipline：抵消下一次对自己生效的 `MENTAL_INFLUENCE` 或 `COERCIVE_CONFESSION`，先用反向Q对抗；成功取消该次效果，失败照常，尝试即消费。持续至下回合结束，重复刷新而不叠加。
- discipline预备：选本场实际攻击过自己或违反有效规则的对象，登记一个惩戒目标；最后一个标签被撤销则失效。对其主攻×1.25，至下回合结束，重复刷新；主攻仍只给普通贡献。道德、组织敌对或“邪恶”不能由模型补判。

规则落地先不掷对抗。每次匹配行为执行前，执行者可由预设策略选择“守法改用同槽合法基础动作”或“突破”；敌方使用其战术策略。守法必须在转盘前调整相应能力的可用用法，剩余子扇区正常归一，不赠送行动。若选突破，宣告者以Q检定：成功限制这一次匹配效果，并写一次 violation；失败原动作执行，不记违规成功，不销毁规则。没有宣告前的追溯处罚。

6级规则持续到本回合结束；5—0持续到宣告者下一回合结束。预备槽可续一条到相同边界，刷新不相加。宣告者死亡、被永久放逐或离开作用区域则其当前战斗规则失效；临时失声仅阻止新宣告，不抹除已成立规则。每条规则对自己和盟友同样有效；自身突破Q以原宣告时的防护快照对抗当前自身，不获得自动豁免。

**处罚**：一次行动即使触犯多条，只结算最早公布的一条；其他条不能重复鞭打。同一规则成功限制后，6级只限制并给可见违规标签；5及以上额外将该目标下一次己方惩戒/裁决贡献×1.25（消费后标签仍作事实保存，强化已用标记保留）。不能把一次随机抽中违法能力变成无上限自动攻击。违规没有自动伤势/死亡结果。

### 3.4 裁决、剥夺与广域律令

`verdict`菜单：处决/鞭笞分别用主攻/次攻普通预算；处决不等于系统命令死亡。禁锢替代自保普通贡献，Q成功令目标下一动作仅作挣脱，消耗该动作后解开；3级起若本次改范围禁锢则走AOE，不能同时处决。放逐在6—5只令目标远离，下一次近身攻击不可用；4起可将目标移出至其下一回合开始，Q成功才生效，不永久移除。解除可主动终止自己的禁锢，不返还已消耗动作。

`deprivation`：控制槽抽到→敌方目标盘→已观察能力盘→Q，成功暂时封住**一个能力ID的所有用法**直到宣告者下一回合结束。被剥夺扇区移除并实时归一；同ID刷新，不同ID可并存，但每次都需实际命中控制槽。序列3起可选一个已揭露能力族，Q减15，成功封住该族；不抹除序列/特性、被动肉身、已独立存在的灵魂/实体、已提交事件资产。未公开能力不能作为可选项目泄露。仅剩普通行动是允许的强结果；不会把行动次数自动改成0。

`edict`预备命中：以下四选一，作用至本回合结束，双方均受影响，后来的同类律令替换旧的，不叠乘。

| 菜单 | 本场明确效果 | 反制与副作用 |
|---|---|---|
| 神秘减弱、现实增强 | 带MYSTICAL的普通贡献×0.5，纯物理×1.25；神秘状态施加者Q减15 | 自己的灵体打击、禁令与剥夺也受影响；位格本身不降 |
| 神秘增强、现实减弱 | 神秘贡献×1.25，纯物理×0.5 | 也加强敌方法术；不是创造新能力 |
| 弹道迟缓 | 弹道普通贡献×0.5；爆炸已生成部分不倒流 | 近身、灵体、非弹道法术不受影响 |
| 禁止浮空、准许立足 | 本区域飞行高度优势清零，所有实体获得现有承载面上的站立资格 | 不能从虚空创造城市或跨越区域；已有跌落伤势不回滚 |

同等及更高位格的受影响者，可在自己下一次行动前用其现有反规则能力对抗；成功使该效果对自身本回合失效，仍消耗这次反制动作。区域律令没有凭空“永久全体沉默”。

### 3.5 混沌追猎、分区与平衡

`chaos-sense`只识别确定性 `RULE_DISTORTED / HOSTILE_INTRUSION / VIOLATION` 事实。战斗混乱目标最多只有一个“可审判”标签，不叠混沌条。`judgment-sword`对该目标贡献×1.5，忽略物理闪避，但不能无视灵体保护、位格对抗、已有替身与回合败者盘；无标签则普通预算。瞬间接近表现为解除本次近身不可达，不能穿越另一处封闭领域。

`partition`自保槽：选一个战斗区边界→与最强受影响对手Q→成功将所有既有参与者按原目标关系拆为互不跨区指向的交战组，到下回合结束；双方数量和轮盘全部保留。形成方法：当前互相指向者连为一组；无边目标附到己方最弱组；同值按实体ID稳定排序。3级只能阻止跨区普通攻击，2级起也阻止支援与新召唤跨区。已有召唤不解体，不合并倒吊人三位一体；强者可花一次行动破界Q或由门权柄突破。分区不允许产生没有敌人的强制胜负盘，独立无敌组等待/撤离由事件处理。

`balance`控制槽：选择同区一名对手→Q成功建立“临时平衡”。在它有效时，目标下一次能力的普通贡献预算使用审判者当前U及A/E，目标的基础战势在**本回合胜負盘前**取审判者的未平衡基础战势；特殊能力身份、掌握度、原次数、原位格抵抗和所有真实伤势保留。弱敌也会被抬高；不是无条件50%胜率。

持续：目标同/低位格，到本回合胜负结算后；高一阶，直到其下一次动作完成且仅保留本回合基础战势对齐；高两阶（2对0），只对其下一次普通贡献对齐，不保留整回合基础对齐。该瞬时用途明确保留“短暂抗衡神”的方向，效果仍有真实价值而非永久削成自身序列。每个目标同回合只受一次成功平衡，同源刷新无延长。0级概念平衡是另一能力，不能借2级实现。跨区平衡不成立；离区/破界立即解除。

**多人平衡扩展候选**：2级partition成功后，比较各组开局Base之和，将明显超出最弱组两倍的组中最强一名暂时排出到其下一回合开始；只排一个且不杀死，重复命中可再处理一个。保留全部实体，逐次消耗实际自保槽，不人为给对方召唤数量设上限。这一“两倍阈值”是核心总审项。

### 3.6 秩序之手与审判者

`order-execution`控制槽选择已公布规则或区域条件，只提供：撤除一条非根本规则、将其范围缩到当前交战区、把其到期提前到本回合末。Q成功生效；作用已结束则0。不得修改随机结果、能力拥有权、玩家输入、存档、既成死亡或晋升条件。“此处无需说话即可宣告”是序列1自用公开规则选项，需一次成功控制槽建立，至下回合结束；不能无条件常驻抗沉默。

`anomaly-stop`自保槽瞄准正影响自己的一个已公开异常（重定向、目标错置、规则扭曲），Q成功移除其**未执行部分**；不逆转已结算伤势、窃取或事件事实。若无异常，改用普通自保，不创建无意义标记。

`world-order`在战斗中同样仅选有限目录：撤除一个规则、建立本稿禁令、为一名公开目标豁免自己一条无差别律令。前两项成功Q生效，自己的豁免直接成立；均持续到下回合结束。序列0可在同一成功控制槽同时公布一条禁令并豁免一人，是明确高位增强。不能宣布“敌人不准赢”。世界永久规则只在序列0终局卡的预写世界变更项内选择，不作为可刷取战斗外挂。

`world-judgment`主攻：有已成立违规/扭曲事实的目标×2普通主攻预算；无则普通预算。无视纯闪避，保护替身、反规则、败者后果仍真实存在。同一目标同一行动只取最高审判/惩戒倍率，1.25、1.5、2不连乘。

`conceptual-balance`自保：预选“理智/疯狂”或“影响/抵抗”，对一个正在施加到自己的可公开状态Q；成功前者令本回合该状态的失控升级不执行，但污染值和下一回合风险仍在；后者令这一次控制结果取消。不是精神/健康恢复，不复活，不用来结算作者未定义的宇宙概念。

`court`预备：展开至下回合结束的神国。己方本稿ORDER_RULE对抗+10，敌方同类-10；以现存实体和区域为对象，不免费生产执法者。与另一个同位格领域重合时，只对争议范围Q一次决定谁覆盖该范围，失败者在未争议范围保持；本稿不裁定黑暗隐秘世界或门囚笼自动消失。领域中序列0世界法仍受有限目录约束，宣告者失能不等于神国消失，死亡/离场才终止本次战斗神国。

### 3.7 规则相遇与结束

确定顺序：原能力合法对象→已公布禁令→现有替身/反制→规则对抗→贡献/状态→胜负→败者后果。对同一个动作每一来源只进入一次，不允许“禁止反制禁止反制”的递归。不同律令同字段取高位格；同位格争议Q一次，胜者到该字段最早原定到期时有效，失败者不连环重投。太阳公证、黑皇帝扭曲、错误偷取、愚者嫁接需各自登记适配，本文只是优先级候选，不能改其已确认语义。

所有战斗记录离场清理，日常辖区/证言/契约只由事件结算写入。战斗禁令不自动变成整座城市永久法律；日常签约不自动让开战敌人“有罪”。结果日志只列本次规则、实际动作、是否突破、处罚与到期。

败者盘继承全局候选：健康、既有受伤次数和事件致命性先入全局伤势模型；本途径的处决/审判只影响明确败者修正，不绕过死亡风险。为便于总审的**局部算例基准**取轻伤/重伤/死亡=65/30/5；伤者再败每次从轻伤转10点到死亡，轻伤耗尽再转重伤；实际模型未定前不把此表发布为全局。处决命中且最后获胜时再转5点轻伤到死亡一次；同回合多次处决不重复移权。不存在自动复活保护。

## 7. 代表算例与文档自查

### 算例A：序列6基础与禁令

双方基础650、m=300、核心和伤势修正均0。法官主攻贡献 `65×1.3×0.65×0.86=47.2355`。对方未增减势，胜率为697.2355/1347.2355≈51.75%。没有另外加P=15个百分点。

同位格意志相同、双方相关m都300，禁令Q=50%。先抽控制建立NO_PROJECTILES；对手选择突破并失败，其本次枪击0，记录违规但序列6不额外加一次攻击。若对手守法改近战，则不存在违规处罚。三次行动内至少抽一次“控制或预备”入口（中性相同m近似38%）为 `1-0.62³=76.17%`，这是条件演示，不是实盘精确入口率；精确率需对非能力槽权重另行归一。

### 算例B：规则会约束自己

序列4先展开神秘减弱，随后抽到精神刺穿：同m=300次攻为 `125×1.9×0.35×0.86=71.4875`，实际35.74375。己方枪手纯物理贡献则×1.25。敌人仍可用其真实纯物理能力；只按标签，不按“谁是敌人”判断。

### 算例C：平衡保留力量但不偷删机制

序列2基础2300对序列1基础3100，原纯基础胜率42.59%。成功平衡保留该回合基础对齐时变为2300对2300；如果双方本回合最终贡献为+300、+600，则胜率2600/5500=47.27%，不是50%定胜负。目标仍持其原独立轮盘、特殊能力与位格。2对0差两阶Q在属性/掌握相同时为34%，成功只将神下一次普通贡献转为2级预算，不把神整场永久削弱。

### 算例D：范围与伤势

序列3、m500、审判之剑打中3个合法混乱敌人，单体主攻 `170×2.3×0.65=254.15`；总基础预算1.65倍=419.3475，混乱增强×1.5=629.02125，每人209.67375，不是每人完整381.225。人数增加不能继续线性复制伤害。局部后果演示基准65/30/5，伤者再败一次为55/30/15，再败两次45/30/25；本途径不引入独立死亡算法。

## 8. 交主对话统一审核的具体取舍

1. **限制力度**：禁令真正阻止一次违规效果，允许守法转合法动作；并列1/2/3/4条是否足够好玩。此上限可调整，不能伪称原著限制。
2. **平衡力度**：2级短时保留拉平战力，神级只覆盖一次普通贡献；多人“两倍阈值逐次排出一名”需与完整轮盘作联合验证，不先削倒吊人三体。
3. **跨途径优先级**：门囚笼100%在未被成功破除前照常；NO_ESCAPE与开门、NO_SUBSTITUTION与预设替身、剥夺与偷取、判庭与隐秘世界、律令与黑皇帝扭曲需要共享规则身份/公开标签；不可直接以本道定义覆盖他道。
4. **攻击归属**：精神刺穿与痛鞭按灵体攻击候选；若猎人“精神领域攻击免疫”确实包含灵体而非心智，必须由总审统一解释。本稿不会默默把既有免疫取消。
5. **强状态与贡献**：控制槽采用机制替代普通削势；高位审判倍率只取最高不连乘，避免一次禁令创造免费追击链。需玩家总审权衡。
6. **终局与仪式**：原页中文和材料数量、国家/大陆级仪式的精确达成条件仍待查证；事件接口和十张锚卡已具体，但不是可发行的全材料包。序列0五节点仅保留结构，不延长登神后的周目，也不要求新晋序列0先练满才结算。
7. **公共缺口**：战斗灵性成本、全局伤势确切参数、跨规则处理器以及材料经济仍待统一。本稿给出了接口和代表候选，未冒充其已完成。

## 3. 共用目标、对抗与资源

### 3.1 目标盘

单体攻击在当前可触及敌人中等权抽1个；实体分身各是合法目标，但不把衣服、武器、光甲算独立行动者。代挡先在实际需要保护且可触及的盟友中等权抽1个。本途径无主动创造的独立人格或生物：光剑、壁垒、银甲、水银分流皆为同一人的能力表现，共用一套次数盘。已有真实队友保持自己的独立轮盘，不由本途径复制或聚合掉。

范围技取场景已记录的最大可达人数N，N不受本途径任意“最多四人”限制。候选数量盘为 `K=1..N等权`；N=1不抽数量，N=0移除能力。每目标普通贡献倍率 `g(K)` 为1、0.70、0.55、`1.80/K`（K≥4）。实际缺员在抽盘前重建候选，不向幸存目标补发缺失预算。光之风暴在掌握300前，受波及友军也在合法池；300后可排除“已有安全撤离方向”的友军，不能隔墙识别未见友军。黄昏风暴继承相同规则。全场衰败事件的地域尺度不能变成战斗无限目标预算。

对抗在目标盘之后重新读取状态；目标离场、被囚笼隔绝、失能时重验，不追改已落盘的结果。本途径不能以“武器大师会使用所有武器”为由获得禁用封印物使用权。

### 3.2 实时对抗候选

```text
H = 0.70*自身相关核心 + 0.30*该能力M
R = 0.70*目标抗性核心 + 0.30*目标防护能力M
Q = clamp(50 + 8*(目标序列-自身序列) + 0.10*(H-R) + C, 5,95)
```

Q以百分数表示；d100≤Q成功。无对抗方的静物读取内容给定抗性，不能默认0。体魄主攻/缴械/裹缚对体魄；猎魔识别用感知对隐匿者意志；意图隐匿用意志对侦察者感知；破幻、灵界封堵、衰败、技巧剥离用意志对目标意志。能力实际为知识构造时，防御核心由其记录确定，不临场取目标最低属性。C仅来自已明示的一个最强优势与一个最强劣势，各范围−15..+15；猎魔标记+10与油剂识别+10不相加。

Q只适用于本稿声明的争夺。普通攻击直接贡献；物理不可触及者在合法性阶段排除；守护者的普通幻术免疫在合法性阶段生效，无须把免疫强行降为95%。神级欺瞒、概念改写不等同普通幻术，进入其本源能力合同。双方并非共用一条全途径成功率上限。

### 3.3 成本和持久性

- 武器动作成本是实际装备、弹药或身体条件；不另开耐力条。既有体魄优势只进入核心加权。
- 非凡战斗灵性消耗统一标 `GLOBAL_SPIRITUALITY_COST_PENDING`，不编造百分比。油剂件数、剑再凝时机和实际原甲损耗可以具体设计，但不替代灵性成本。
- 日常被动无额外硬成本，只揭示卡片中允许知道的事实。主动选项必须先显示材料/健康/精神等本稿明确代价；未定灵性成本的选项在制作阶段标待接入，不能按0成本发布。
- 战前只带入已持有武器、油剂、公开识别记录、保护约定、已有伤势与原物实际位置。战斗标记不由日常白送：识破、银甲规避、囚限、战斗黄昏都要战斗内建立。
- 所有临时状态随退出遭遇清除；已经发生的材料消耗、受伤、污染、衰老事实和关系变化保留。战后是否治疗实质衰老走事件，不凭战斗倍率重置使老人返青。

## 4. 核心机制：触发、维持、失败、反制

### 4.1 战士到武器大师：直接打击与有限抗性

`physique`是体魄表现及事件承重资格，不再加一遍战势。`weapon-training`让已持有武器进入主次攻；无武器时降为同槽徒手动作，普通贡献×0.80；8起格斗家取消徒手折减。对灵体不可触及这一限制仍在，直到真正有相应能力/器物。

格斗家的控制命中并通过Q后，目标下一次**依赖身体施力**的正向贡献×0.75，到本回合末失效；不能取消纯意念施法。失败无控制贡献。武器大师控制改为缴械窗口：Q成功压制一项手持武器下一次普通贡献至×0.50，随后恢复；不会自动夺走所有权，也不夺走用灵体持有的唯一性。`bodily-resistance`与`weapon-burden`只减内容声明可减的来源，绝不免疫读心、精神操纵、污染或神级封印物代价。负担抗性用于事件保护，战斗装备损耗由原物品规则裁定，不再叠一份胜势。

### 4.2 晨曦剑、甲与光之风暴

光甲自保抽中时可选固定姿态对应的普通减势，或建立一次防护：下一次指向自身的直接攻击普通贡献×0.60后清除，期限至下一回合末；不同时领减势。光甲破碎后，下次自保命中重凝；不是开场无限复生。

晨曦武器按普通主攻预算结算，允许触及对应合法灵体；光之风暴次攻用一份AOE预算和本能力候选倍率。33A及2026-09-08第64题A已确认：低序列保留失剑；序列4起允许同回合重新抽取凝剑，序列2起风暴不再导致失剑。不自动赠送凝剑行动，不把低阶整回合限制带到所有高序列。

晨曦破幻控制命中后按Q解除目标一项可净化幻象/阴影遮蔽，本轮至下一回合末不再由同一普通幻术重新遮蔽该目标；失败不减势。不揭露伪装者未公开姓名。普通敌人没有“邪恶所以加伤”判定；怪物身份和人类道德无关。

### 4.3 守护：立足换防御，代挡承担风险

选择全力守护时，第一次自保或预备命中建立 `guarding=true`，持续到下回合开始选择姿态时；继续选守护可维持，但必须本轮至少命中一次自保/预备，否则该轮结束消退。守护中每次可触及直接攻击作用于自己，普通正向贡献×0.15；同序列以下且本来以身体/能量直接破防的普通附带状态也随防御被阻挡。**不是所有超凡效果免疫**：精神直接作用、污染、内部寄生、灵魂替换、规则隔绝仍按原能力处理。

高一序列以上的直接攻击先按守护者Q对抗，成功按×0.15，失败仅按×0.60；显式无视防御的能力必须先走其穿透规则。守护建立没有即时减势；已建立后再中自保只按普通自保预算减势一次，不再叠×0.15。移动、离地、被强制搬离支点、主动攻击或失能立即结束全力守护；下一回合可重建。普通迎战下抽中“守护架势”只取得下一击×0.60的短防护，不临时享有全力守护。

代挡控制命中后，为目标盘选出的盟友建立到本回合末的一次代挡。下一次可触及单体攻击转向守护者，先重验攻击对守护者合法，再读取守护防御。一次攻击最多转移一次；不能在两个守护者间递归。AOE原来同时命中双方时，只承接盟友那份普通预算，与自身那份分别承受，不删除整场AOE。已提交的回合败者伤势、寿命损失、被囚笼封闭后的作用不可补挡；这与倒吊人的后果代罪保持不同。

守护没有回血或死亡降级。若仍输掉回合，守护者正常进入败者伤势/死亡盘；受伤继续守护后再次失败，死亡风险照常递增。保护成功不保证己方回合胜利，也不阻止敌方改打未覆盖对象、撤离或破坏地面。

### 4.4 猎魔：识别、准备与灵界壁垒

猎魔之眼控制命中，目标盘选择一个已在场对象，Q成功获得 `exposedWeakness(target)`；下一次自己命中该目标的武器攻击×1.25后消费，最长到下一回合末。只显示类型级弱点/污染/附身迹象，不自动确认有罪或读心。与白塔弱点作用于同一攻击时只取最高倍率。

油剂/圣膏/标记只在日常制作；战前已有的 `hunting-preparations` 资产必须登记效应类别。候选先开放净化、火焰、冻结三种载荷，雷电、衰败和驱逐作为同ID内容扩展入口，效应未写不自动装载。预授权一件油剂，第一次合法主攻消耗；净化对正确对象×1.25，火焰普通贡献×1.15，冻结放弃额外倍率并按Q使目标下一次身体攻击×0.75。错配仍消耗而无额外效果。各类不新开熟练条，不在同一刀叠三种油；多把真实武器可分别带油，仍由武器合法池等权抽取。

意图隐匿预备命中Q成功，使一个追踪者下一次“危险感知/预判”不能读取自己的下一击；不是隐身，更不是压掉已看到的攻击。神级预言和已建立灵性联系可按其原机制抵抗。猎魔克制深渊危险预知的Q修正+10，尚待深渊包统一认可。

灵界壁垒自保命中并有地面支点，建立到下一回合末的一次通行拦截；有对象试图跨越时现场Q对抗，成功令该次跨越失败，失败按原能力通行。已处于门囚笼的人不能从内部声称“我有壁垒所以囚笼失效”；同一出入口不能用多个壁垒无限重掷。

### 4.5 银骑士：空间刺击与水银身体

银色突刺主攻是普通主攻预算，并针对一项可穿透的外部实体护甲忽略其本次普通减伤；遇空间封锁/权柄守护先Q，成功穿透，失败仍按常规防御结算。不能攻击当前不在合法空间的对象，也不能取消已生效的门囚笼。内爆表现仍是攻击预算与败者后果，不直接杀死。

水银规避自保建立下一次物理攻击×0.25的一次状态，到下一回合末；灵魂、时间、污染与封印效果不受该物理折减。裹缚控制Q成功后，目标下一次身体类动作无普通贡献；控制者也占用身体，直到消费或本回合末不能获得全力守护。对气体、纯灵体、体量明显不可包覆者排除；不是一律“所有天使都能窒息”。借光隐藏预备Q成功解除一个普通视线锁定，下次行动/受到范围攻击/下一回合末失效；不获得额外盘，不按分散的水银滴数增加次数。

### 4.6 荣耀：衰败逼迫速决，囚限与退场

本途径只新增一个需要连续记忆的主要战斗值 `decayFactor`，初始1，UI用衰弱说明和具体倍率展示，不另做衰败槽/寿命条/荣耀条。控制抽中衰败，对一个目标Q成功后 `decayFactor=max(0.20,old*0.85)`；影响该目标后续普通正向贡献和普通自保减势，持续本场，已结算贡献不改。重复成功真实削弱，失败无效，不重复领取控制减势。序列1继承；序列0见下一节。对象必须有可衰败载体；纯抽象象征在序列2不合法。解除一个来源的衰败，恢复该来源施加前应有的因子，不能洗掉别的途径伤势。

衰败不是生命偷取；当因子达到0.20，后续该目标回合失败时，候选把可转移的轻伤权重最多25点移到死亡分支，只有内容声明具有生理寿命的目标生效。死亡总权重不超过100；轻伤不足取实际剩余，不从不存在的分支扣成负数。同一败者盘只调整一次。**这25点是新增候选，需要与公共败者盘总审**；基础权重未定，所以本稿不能给最终死亡率。死亡后照常检查可用保命，只有明确依赖剩余寿命的复活受黄昏克制；没有这种来源标签时不得一概判“所有复活无效”。

囚限预备命中Q成功，目标直到下一回合末的普通移动/灵界通行被阻断，但能攻击、施法、破坏围墙。目标自己的控制/预备槽若含解封能力，可在抽中时按Q反向破封；普通主攻也可用本次预算攻击囚限，其普通贡献放弃，Q成功解除。再次施放只刷新期限、不叠囚笼；本候选没有门囚笼的100%回合胜率，也不偷用其已确认例外。囚限本身不免费触发衰败，需另中控制。

`dusk-renewal`生存方向（第34题A已确认）：允许撤退、灵体完整、合法出路和真实代价等资格齐全，且没有敌方封锁时，不额外抽50%身体重组盘，成功退出重组；有封锁时才做对应实时对抗。保留重伤和事件后果，不立即满血回到原战斗；失败接公共死亡保命流程。具体代价尚需量化，原50%无阻拦失败率和对应算例退出活动方案。

### 4.7 神明之手与序列0

## 7. 十张精确序列锚卡

以下是原创可审查规则卡，不是原著事件复写。ID为 `tg.anchor.sN`，一局一次；10张属于本途径起步包，不宣称已填满全游戏117卡。人物均使用本卡具名槽位，不锁死原著关键人物，主角改变事件后更新后续事实。下列H为本卡相关核心当前值，D为表列绝对难度；统一成功率为clamp(50+2*(H-D),5,95)，掌握只决定选项资格、不通用加点。健康/精神数值最低0，本组不提供透支；若会首次降到0，健康触发“需要救援”阻塞分支、精神触发“自我动摇”阻塞分支；没有可用救援的风险战斗走公共生存盘，不能直接继续行动。

### 9.2 黎明骑士：先斩再爆，快速模式不丢结算

一对一，双方序列6，M=300，己方次数盘转到2，依次主攻与次攻；目标盘两次只有同一个合法敌人。主攻`65×1.7×0.65×0.86=61.7695`；次攻风暴K=1得`65×1.7×0.35×0.86×1.25=41.575625`，随后剑进入当轮失效。对方完成自己的盘后总增势为50，双方无其它减势。

双方有效值为753.345125与700，己方回合胜率51.8353%。此时才转胜负；败者再转伤势/死亡，不能把光之风暴动画当作敌人必死。快转只缩短两个能力盘及目标展示，不合成一次随机。

若同一风暴数量盘为K=3，各目标22.8666，总68.5998；这只能证明AOE总预算，不可把三名敌人的集体基础战势仍写成一个650来伪算群战胜率。多人队伍聚合方式由公共规则确定，未完成之前本包不补造团队胜率。

### 9.3 守护与代挡

序列5守护者当轮次数盘为3，第一下自保建立守护，第二下控制为盟友A建立代挡，第三下自保按普通预算削减敌方35.1。随后敌方117点单体攻击本来选中A，由代挡转到守护者，守护已成立故只保留17.55点普通贡献；代挡消耗。若敌人先于第一下自保攻击，不能享有该保护。若117点是明确绕过防护的规则伤害，先读原能力，不乘0.15。

即使最后守护者回合失败，也不因“挡住了很多”跳过自己的后果盘。一旦已经重伤，再败增大的死亡风险保留；没有额外“荣耀复活次数”。

### 9.4 猎魔识破对抗

自身序列4、感知300、猎魔之眼M300，目标序列5、抗性意志240、防护M200：H=300，R=228。有已核实怪物弱点给予C=10时，Q=50+8+7.2+10=75.2%。掷75成功，掷76失败（整数d100的有效命中概率75%；若全局要求精确小数盘，可用更细随机刻度，不能说整数75格实现75.2%）。成功只建立一次弱点标记，下一次命中目标的武器才×1.25；本次没有额外控制减势。

### 9.5 荣耀者持续衰败与神明之手

序列2、M500的目标主攻原预算478.4，四次成功衰败后因子`0.85^4=0.52200625`，后续该主攻为249.72779；前四次已经结算的攻击不重算。达到0.20下限需要10次成功，序列0的0.70因子需要5次；不是10次抽盘就必成功，囚限也不额外送衰败次数。若达下限后目标未输回合，不触发败者权重调整。

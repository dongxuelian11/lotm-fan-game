## 4. 结算接口：时间、目标、对抗

### 最少状态与两层接口

日常只保存真实媒介资产、镜面/镜口位置、带身份的镜实体联系、已提交的疫区/灾区事件与自我身体状态。战斗从开战事实快照取得它们；诅咒强度、潜伏标记、石化效果与灾变进度在战斗内生成。战争或现实疫区不会因战斗结束而消失；战斗临时标记也不能直接写成城市疫病。

本稿不加魅力属性、欢愉槽、痛苦条、疾病能量或灾难点。UI仅显示当前确实存在的效果及剩余时点：隐蔽、一次干扰、发病、镜替已备、镜身残损、石化、灾区阶段。灾区阶段是同一效果实例的枚举 `collapse / apocalypse / chaos`，不是每打一下加一层的通用资源。

统一用 `r` 指当前回合；`下一次`指目标下一次符合条件的尚未结算能力。所有一次标记最长保存至r+1回合末，除非下文更短；重复同ID不叠加，采用较强版本、较晚合法到期时点，不能复用旧媒介无限刷新。已承诺的动作先在生效时重验目标；状态不能回溯改变已提交结果。

### 目标与AOE候选

单体在可触及、满足媒介/感官/镜口条件的全体合法对象中等权抽1，不由玩家指定。常规有害能力只抽敌方；魅惑不自动把敌人改成友方。冰盾/镜替/镜身仅自己；原初500节点才可加入盟友。神话显形、无差别瘟疫、灾难区域先决定有害区域，再对其中所有可受影响者（含盟友、中立者；施术者无对应自护也在内）抽取。

全局AOE分布尚未确定，本稿用可替换候选：设已确定区域中合法对象数N，N=0则无目标；N>0时数量盘在 `1 / ceil(N/2) / N` 三结果按 `30/40/30` 抽，重合合并，再无放回等权抽对象。最大数就是N，来自场景，不新增人数硬上限；没有“城市只病三人”的上限。直接AOE的普通总贡献只是一份槽预算，命中k人均分，不能每人复制整份。持续疾病也是一个总减势预算按本次有效受害者分摊；控制效果须逐目标对抗，硬控制不以除以k假装连续数值，明确列为多人强度风险。

战斗AOE只处理现场行动者；城市、国家灾害由事件的地区节点与疏散事实结算，不创建百万个轮盘。原本就是独立队友/敌人的角色仍有自己的盘。本稿不会将AOE控制塞入普通预算谎称已经平衡。

### 专属对抗公式（候选，非全途径统一公式）

只在下述特殊效果写“对抗”时使用；普通槽不重复掷命中。`rank=9−序列`，普通人的rank=-1；来源与防御核心都取当前0—500属性。

`Q=clamp(50 + 8×(rank攻−rank防) + 0.08×(K攻−K防) + 场景修正, 5, 95)`。

`K攻=0.5×主属性+0.5×该能力掌握度`；`K防=0.5×防御属性+0.5×实际对应防护掌握度`。没有特殊防护，防御掌握部分取防御属性本身；NPC未填属性/能力数据则不是可用模板，不能当0。隐蔽/刺杀用感知对感知，教唆/魅惑用意志对意志，丝缚/疾病用感知对体质，诅咒/石化/灾变用意志对意志；gorgon300节点可用感知作为攻击属性。

镜封、灵体豁免、疾病物种范围、精神免疫和已声明的权柄否定先判合法性；不合法就0%，不套5%保底。必然成功的显式权柄也不被95%上限削弱。媒介不明只提供错误对象或无对象，不能提供盲猜真名检定。场景修正仅允许本稿明确的+5/+10/−10；同一来源不重复相加，来自同类多个资产只取最高。

## 5. 低中序列：刺杀、巫术与控制

### 刺客9与教唆者8

`shadow`预备命中且有阴影，进行一次隐蔽对抗；成功建立隐蔽，自己下次刺击贡献×1.50后消耗。上限一份、回合末消失；主动非隐蔽攻击、强光揭露或目标成功侦破提前清除。低序列隐蔽不是灵界潜行。body300使已重伤且暴露弱点目标也能触发同一×1.50，和隐蔽只取一次；不改变后果盘死亡权重，不把刀击直接写成死亡。

`instigation`控制命中需要目标能接收语言/信号、具有行为意图，以及开战快照或本场公开行为已给出可利用动摇。对抗成功时，**替代**普通控制贡献，使目标下次正向贡献×0.75；失败0。没有动摇仍可抽普通佯动，不现场读取心理秘密。m500的错误目标模式必须在抽盘前授权：成功后目标下一次单体攻击的目标盘加入其一名实际可攻击的盟友，各合法对象等权；若只剩本人或无合法盟友则回退×0.75。只影响一次目标倾向、不改变所属阵营、不命令自杀。拒绝、免疫与沟通中断清除标记。

### 女巫7：黑焰、冰霜与诅咒

黑焰为主攻普通预算，可触及已暴露灵体；不是猎人的火焰化身或压缩火球。冰霜次攻为普通贡献；冰盾是自保贡献，m500允许改为清除一条由物理接触/气流维持的传播边，二者择一。普通火源、无形攻击、绕行及同位格环境控制均能反制相应形态，不能用同一个“物理免疫”标签免疫一切巫术。

`curse`只有合法媒介时进入特殊控制目录。媒介分为：本场实际留下且仍有联系的血/发等（+5在m300解锁）；事件带所有者证据的真实遗留物（m0可用、默认+0）；本场完整倒影（m500解锁，+0）。知识记录、照片、知道姓名本身都不自动是有效媒介。媒介在进入对抗时消费其本次使用份额；失败同样消费；倒影属于短时联系，目标破镜/遮断后下一次使用必须重建。

成功施加一个绑定目标的“诅咒痛楚”：该目标下一次正向能力×0.60，替代本次控制贡献，最多一份；到r+1末失效。低位普通人可以被严重压制，但是否死亡仍走战斗败者后果。高序列可扩大触达/跨镜连接，**并不自动变成任意远程全知锁杀**。切断媒介仅阻止再施咒，已生效诅咒需净化、替身承接、目标权柄否定或自然到期解除。

### 镜替、镜子与反占卜

日常仪式可准备真实镜片资产；战斗预备 `mirror`把随身一份镜片置为“已备镜替”。7—4级自保抽中镜替且存在已备镜片，消费镜片，**替代**普通自保贡献，免除本体下一次可替代的普通定向有害效果；标记到r+1末失效，每份只用一次。刚抽到镜替却没备镜片，改普通冰盾；不能凭“女巫都会镜替”生成无限库存。镜替本身不是独立人物，不转盘。

镜替能挡物理、黑焰等明确目标攻击；不能消除已经发作疾病、区域灾难、直接命中共同灵体的效果、镜界封锁、全域净化或已经结算死亡。m200可承接被允许的普通媒介诅咒；高位封印/死亡/权柄效果须其内容明确支持替代，不能从名称猜。对手破坏已备镜片、封住镜面或改用范围/持续效果可反制。

序列3镜身为真实连接，可代替“随身镜片”充当自保镜替入口，但同回合用过的同一镜口处于破损，必须再中预备重建；序列1的0.199有限实现保留原镜及原物实际位置，不新增镜实交换或自动避开攻击；镜面缓冲仅处理本人下一次可见身体冲击。镜占卜、长期反占卜与追查镜口全部在事件中判定，不进入战斗准备谜题。

### 欢愉6：丝线、魅惑与自保

`threads`主攻是丝刃普通预算；控制模式必须能建立实体丝线接触，在目标盘后对抗。成功替代控制贡献，使目标下一次**需要身体动作**的正向能力×0.50（欢愉痉挛/束缚表现）；失败0。意念施法、无实体形态和已声明精神领域免疫分别按实际标签判断，不把身体痉挛统一当精神控制。丝线连接被切断或净化就失效；重复命中刷新但不叠减。

自保结茧替代本次普通贡献：本回合第一次普通物理有害贡献×0.50，回合结束若茧未破且仍存活，缓解“当场失血”标签；它不减少既有伤势等级或受伤后再败次数，不给第二条生命。事件中结茧可以稳定伤者等待救援；不是战斗内全额治疗。敌方火焰、切割或灵体打击各按实际效果作用。

`charm`不要求恋爱/性关系，也不改变玩家性取向。控制模式需可感受相应表现的有意识目标。成功替代控制贡献，目标下次对施术者的普通正向贡献×0.50，到本回合末；攻击其他目标不受影响。m300允许声线等非视觉表现，感官通道被阻断仍失效；m500之前本人主动打击该目标会解除，m500后允许维持到那一次行动。高阶版本可突破部分低位目标类别限制，但不默认魅惑神灵、机器与石头；0级权柄模式见后文。

## 6. 痛苦5与绝望4：疾病、瘟疫、镜迷宫、石化

### 疾病：曝露时点代替叠层条

疾病主攻模式为普通正向预算，以当次病理打击表现，结束即止；控制模式替代普通贡献，建立本场疫区与一次AOE感染检定。先数量盘、目标盘、逐目标对抗；成功保存来源、病型、`onset=该目标下一次行动结束后`和传播边，失败不感染。不能刚生成就吃掉目标已经完成的动作。

发作后按失力型（默认）或迟钝型（m300）工作：失力把本方本次**整份控制槽减势预算**缓存为回合末持续减势；在仍感染者之间均分，一名目标不会被同源多次叠加预算。迟钝型在每个感染者下次需要身体动作的正向贡献施加×0.75一次，不再领取持续减势。两病型互换要再次抽到控制并重新对抗，不能同时保持。反复抽中刷新既有疫区与感染候选，不生成新的同源疫区实例。

只要仍在未清除疫区且未切断传播路径，每回合末对本回合新进入者执行一次相同感染过程；这是同一疫区作用，不给新能力次数或重复主攻预算。离开疫区后持续到当前回合末，m500的来源延至下一回合末。战斗结束时清临时感染实例；只有开战事件已经声明可能留下后遗症时，才按战后事件转为持久疾病事实，不由战斗日志临时创造城市疫情。

序列5只处理适用有机身体的病型；4级升格瘟疫可另选“灵性衰竭/僵硬”类，必须目标有灵性/相应载体，允许登记某些亡灵而非“所有死人免疫”或“所有死人必病”。当前不额外扣灵性点数，衰竭只表现为同一减势或迟钝；精确资源流失等全局成本方案，不能双扣。

净化可移除一个可净化感染/疫区；通风、隔离、火焰、冰障仅在事件载明可截断该传播边时有效。治疗身体不自动清除超凡根源，杀死施术者不回溯清除已提交现实疫区。m200主动停止播散只撤销自己疫区的新感染，已发症状等自然到期或治疗，不能借“撤回”抹掉伤亡。

### 镜迷宫（mirror的4级模式）

控制命中，必须存在本场可用镜口、目标映像或可拉入联系；抽目标并对抗。成功替代贡献，把目标置于可解释的镜中子场景，仍保留目标独立次数与能力盘。这里不是门的永久放逐/100%囚笼：目标只能对可触及的镜中实体、已展示出口或能跨镜触及的本体行动；外部人物也不能无条件打到镜内。

每个镜迷宫实例持续到r+1末。困者每回合第一项本应无合法目标的攻击自动改为出口破解，对抗成功立即脱离，失败消费该次；主动具备镜界/空间解封能力可在对应槽再次尝试。施术者维持期间也必须通过镜口才能攻击，不能安全地拿不可触及者当任意靶子。重复命中同一目标只进行新的维持对抗，成功至多刷新到新的r+1末，不叠迷宫。镜口被摧毁、封印解除、施术者失能或到期则目标回到原区域合法落点；不可返回时由已声明的安全邻接位置承接，不落进墙体自动死亡。

### 石化与神话形态

`gorgon`控制需要可达视线/有效神话凝视；以目标盘抽1，成功替代贡献，使目标下一次实体动作贡献为0并消费一次石化标记。非实体法术仍可用；到r+1末失效；低位无反制且暴露完整形态者可被完全石化至回合末（目标至少低两阶、成功Q），当回合剩余身体行动停止，但不自动死亡。此强例外保留高阶威力。

2级完整形态允许以AOE数量盘选择实际暴露于凝视者逐个检定；完整显形默认会波及未获遮蔽的友方与见证者，不可偷偷只伤敌。相应污染事件只读取场景既定见证者后果。遮眼不是万能解：普通视觉链可断，神话投射、镜中投射要对应隐秘/镜屏障；高位净化、解咒、变形和摧毁载体有自己的反制入口。

自保槽的神话形态防护提供普通自保预算，不额外赠石化AOE；显形会成为场景公开事实。未完成同级防护能力表前，不把“所有同级都免疫神话形态”作为默认。

## 7. 不老3：共同意识与可反制复生

候选取舍：不老镜身不另给全套轮盘。原著所见是同一意识、两侧存在；游戏将其作为一个行动者的两个可攻击存在侧 `real / mirror`，一份次数盘、能力掌握、灵性和伤势历史。镜身能观察并成为能力发射侧，身体与镜口仍需实际连通；不凭空复制队友或事件收益。

本体在败者死亡分支时先查已有镜替能否承接（不可承接的死亡不会硬挡），再查共同灵体是否存在且镜侧未毁。镜侧有效则本次改为“实体侧毁损”：取消本体剩余动作，下一回合只能使用镜侧可行能力；在该回合结束后由镜身重建肉身，健康恢复至1、保持重伤与全部受伤再败记录；mirror-self500恢复至25。恢复不重转过去胜负、不洗污染、不重置灵性、不发成长奖励。

没有每场一次的武断总上限，但有真正的暴露窗口：重建期未完成时再破坏剩余镜侧，或以明确可穿双侧/共同灵体效果命中死亡，即真正死亡；已摧毁侧不会立刻自己生成第二个备份。重建成功后仍需 `mirror`预备槽修复两侧连接，未修复前只有一侧可存续，不触发下一次镜身救命。若主动躲在镜侧永久不返，按逃离/镜中滞留结算，不能一边“已脱战”一边输出疫区新预算。

日常不老阻止正常年龄衰退，不抹已受创伤、不治污染。外侧年龄/身体维护与玩家认同分开。长期重建镜锚、寻回被封镜身、复原外貌都走事件，不在瞬时战斗生成长篇身份谜题。

控制 `catastrophe`可针对已有不稳定防御、受损实体或相互依赖的能力连接对抗：成功替代控制贡献，令该连接下次正向效果×0.50并建立同一collapse实例，失败0。受损/不稳定来源必须是已经提交的状态或本场真实破坏，不可因高污染数字就直接宣布敌人失控。m300明确支点+5，日常预备资产只能提供一个支点，不直接送末日阶段。

### 混沌：保留条件，保留威力

`chaos`主攻抽中，必须当前真实存在apocalypse实例。抽取该实例内尚未稳定的合法目标，进行一次Q；成功时替代普通贡献，使目标当回合剩余普通能力与普通持续防护不再有效，并使其有效战势本回合固定为0.1TierBase（其它普通加减不能抬高）。这是0级权柄例外，远强于一次×0.75；不是普通攻击倍率。对抗失败0贡献，不消耗世界历史。

若目标有同位格明确稳定、隔绝、替代或终止权柄，先执行其对抗接口；若无合法apocalypse，不进入chaos项目，回退正常灾难主攻。成功后当前apocalypse实例被消费，不再作为第二次混沌燃料；混沌状态至回合末，下一回合必须重新制造失稳。败者仍走伤势和有效生存机制，不直接封存角色。两个普通倍率无法通过相乘制造此效果。

事件层的混沌只作用于事先定义且已完成灾难、末日两阶段的世界系统；可导致不可逆终局、地区毁灭或系统重组，必须明确当地生命、撤离、其它权柄干预与玩家可见风险。稳定世界不能因玩家输入一句“全世界混沌”被吞没。此限制来自S4的机理，范围和结算方式是候选。

### 原初与镜界权柄

`primordium`自保槽可替代普通贡献，把自己一项本场非权柄身体变形/石化恢复到开战已存在结构；m500可转合法盟友目标盘。它不是时间回溯，不补灵性、不清共用伤势死亡递增、不复活已最终死亡者。日常恢复历史物件或他人身体必须有实际模板与预写边界，不把“原初”解释为任意造物。

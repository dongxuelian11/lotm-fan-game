## 1. 体验与来源边界

深渊的成长线是：越界求利 → 冷血 → 仪式猎杀 → 恶魔化与危险预知 → 催生并引爆欲望 → 精神侵蚀 → 恶意寄生与血液复归 → 令环境本身成为深渊。它以别人的欲望和已经发动的恶意为突破口；被缚者则以自己的诅咒、容器、异化和克制为轴。两者不共用一条“邪恶值”。

玩家仍然选择行动与事件分支。魔药的冷血、恶意与失控危险通过已知风险、内心措辞、人物后果和具体诅咒呈现；不能自动提交谋杀、入会、背叛或永久改写玩家人格。拒绝恶行不保证能完成原著仪式；不把“保留选择”偷换为“任何善良行动都能消化全部魔药”。

## 3. 核心机制

### 3.1 特殊对抗与免疫

仅本途径明确需要对抗的能力使用候选式：

`p=clamp(5,95,50+0.08(M攻−M守)+0.04(X攻−X守)+0.8(P攻−P守)+条件修正)`。

M守为当前实际防御能力掌握度；无适用能力时取0并依然使用防御属性。精神、欲望、诅咒X=意志；危险辨识X攻=感知、X守=对手隐蔽所用的感知；物理破束X攻=体质、X守=束缚施加者对应属性；保护物读取内容给定的M/P/属性，不借物主最高值。条件修正只有本节列值，不由模型给分。无抵抗的非生命普通物体不转精神对抗。绝对免疫、联系断开、不可触及先判定，不能因5%下限穿透免疫。本式不是白塔或全22途径的新全局公式。

### 3.2 恶意危险感知：预警不等于全知

`abyss.danger-sense` 是被动预警加自保槽的战斗使用。事件只检查已发生的准备行为与已排期的直接致命威胁；厌恶、随口威胁、没有行动的想法不触发。预警输出“来源方向/已知对象/当前危险联系”，受信息可知层过滤；幕后真名没有可知依据时不显示。并非预测尚未抽取的随机数。

战斗中，敌人已经提交针对自己的致命或重伤型效果时建立一次可察觉联系。自保槽命中后对抗其遮蔽；成功令该来源下一次对自己有效贡献×0.50，使用后清除；失败只有失败回执。没有已提交威胁则作普通自保减势。最多保存每一来源一份保护，重复刷新，本回合末过期。净化或隐秘导致来源不可追索时保护仍可避险，但不能显露来源。

序列3后，对抗成功可按姿态选“避险”或“沿已验证联系回击”，后者以次攻预算的一半施加精神侵蚀，不再同时保护。不能隔空击中只有玩家读档才知道的敌人。区域灾难、无意事故或针对第三人的攻击没有恶意感知保证，仍使用一般敏锐与普通事件判定。

### 3.3 魔化、复合火毒与污秽之语

魔化由预备槽发动，持续本回合及下一回合；主攻贡献×1.25，普通物理对己贡献×0.75，二者是明确候选差异。破普通绳索自动，非凡束缚走体质对抗；失败保持束缚。状态不叠加，结束不补血、不清伤。翅膀开放遭遇中实际存在的空中位置与撤离路线，不能多转次数或飞出封印。

`infernal-spells` 共用一条掌握度：岩浆之剑主攻单体；火球次攻AOE；毒雾次攻AOE；火焰囚笼自保，抵御一次实体投射物，成功抵销该投射物对己的一份贡献，不能暂停整个回合。剑只读火/物理抗性，火球读取火与毒，毒雾读取毒；普通火球预算火70%/毒30%。序列1深渊火另为火40%/腐蚀30%/灵性污染30%，三份加总一次预算，不连续领取三次主攻。

`filthy-words` 控制槽等权抽合法词。缓慢：对抗成功，目标下一次尚未执行行动贡献×0.50，但仍结算自己的合法机制；堕落：下一次针对目标的精神对抗+10，随后消耗；死亡：本次改作一份主攻预算的精神打击，并建立仅本回合生效的“心脏/灵体受创”标签，只有目标成为败者后才提高后果风险（后果候选见第7节），不抽中即宣告死亡。所有词同名不叠，净化、隔绝言语联系或精神防护可解除。序列4“混乱/懒惰/亵渎”作为同一ID的高阶用法：混乱使下一次目标权重无偏向重算，懒惰沿用缓慢，亵渎破一次低于自身位格的言语类加护；同位格加护走对抗。它不是倒吊人的秽语整包复制。

### 3.4 欲望操纵：一份可解释触发，不建三层条

内部只保存 `desireOpening{target,source,expiry}`，不存“欲望值”。开战时可由事件中已确定且正在发生的强烈情绪生成；战斗中精神冲击、明确恐惧效果或本能力命中可生成。战败、挨打、玩家查看面板不会自动给开口，必须是内容或能力的真实效果。

序列5控制槽：已有开口时对抗成功可选“扩张”或“引爆准备”；前者令目标下一次贡献×0.75并保留开口至下回合末，后者把开口转成可引爆标签。没有开口则该次对抗只尝试诱发一个，不能同次引爆。主攻抽到引爆时消费标签，对抗成功主攻×1.75，失败为普通主攻×0.50。没有目标开口时主攻仍有继承攻击。连续开口不叠层；平静、净化、断联系能清除，受控者不会自动投降或加入阵营。

精神冲击是 `desire-control` 的独立原著招式记录 `mental-impact`：次攻槽命中，燃烧一只尚完整的角，无须情绪前置即可生成开口，仍受精神免疫。一次角的燃尽持续到战后修复事件；两只角都用尽则不能使用，不靠回合切换刷新。它不是灵性成本替代品。

序列4精神侵蚀控制命中后可以对没有开口者直接进行一次完整欲望对抗；成功同时建立可引爆标签，不额外扣一份E。AOE仍逐目标对抗且不随人数扩大预算；主攻一次只引爆目标盘选中的一个目标。无另行注明时，开口与引爆标签均在创建者下一回合结束时失效。被深渊影响的玩家仍保留显式行动/事件选择，临时精神控制仅影响本场盘面。

局部神话形态 `mythical-mutation` 自保命中后保留到下一次受到有效攻击；候选只将该次攻击的普通物理分量×0.50，消费后结束，不能再拿一份自保E。纯精神、净化、诅咒不受此甲影响。与魔化的物理×0.75取较强保护而不相乘；重复命中刷新同一个保护。事件中显露局部形态仍有见证者污染风险，不因熟练度500被删除。

欲望化身由自保槽启用，至下一次己方能力结束；纯实体物理对其无效，灵性、净化、心灵与能触及欲望的能力照常。不能因“变成液体”免疫一切或复制实体。序列5个体天赋在晋升事件中从实际种族/材料/心态对应的审核包选择一个：候选提供“阴影潜行”或“欲望共生”。前者只开放已有阴影路线；后者使用第3.6节的特定宿主锚，不默认兼得。天赋更换必须有来源事件，不能每回合重选。

### 3.5 投影与高位言语

序列7召唤为事件长时仪式，必须有响应者ID、实际约定、代价、持续与退出条件；不能战斗即时完成整场仪式。成功可带来一位已有资料的恶魔投影，也可只有知识/工具帮助，取决于响应内容。投影是外来有意志行动者：有独立次数盘与它自己的能力盘，按实际投影规格的U/P/能力结算，不能复制本体全部能力。若资料没有战斗规格，则其当前候选用途只限事件协助，不能凭空借本体数值。

序列4原ID升级允许预备槽通过已有响应联系即时请求投影：本回合落地，下一回合开始抽自己的盘，断召唤联系或违约时退出。没有硬性“至多一只”上限；数量由成功建立的不同响应关系、可承载联系和每次召唤行动决定，不能同一投影ID重复在场。更强响应者可拒绝、反噬或索取新条件。独立投影对主人的欲望与命令可反抗，不为本体加日常行动点。

呓语大师 `corrupting-speech` 控制模式对抗成功，立即移除目标一个当前有效的精神保护，或没有保护时抑制一个精神类主动模式至下回合末，重复刷新同一模式。攻击模式只领取次攻预算并带“沿联系可达”；音量、距离、联系与隔绝按遭遇数据判，不从声音自动获得目标情报。不能在控制与攻击模式同时领取效果。

### 3.6 鲜血复归、恶意锚与污秽

血液支配的主攻面对有可触及血液/体液者走意志特殊对抗；成功正常主攻并令其本回合末前一次身体类防护失效，代价为该次主攻×0.75；无血灵体只可选继承攻击。血源重组是生存接口：确实留下可接续灵魂/意志的血源、死亡原因只毁身体时，可以消费一个独立血源记录重组，身体改为重伤并退出当前遭遇，累计伤势/污染/历史不清零。火焰净化所有血源、灵体毁灭、终点或隔绝已切断联系时不能重组。分割同一滴不会生成无限独立记录；血源由一次真实分离/储备事件产生，搬运和保护存在世界后果，不设任意总上限。

恶意化身的控制槽对抗成功可在有心智目标中植入种子。该种子在本场只作为欲望开口；只有战后事件中它未被清除、目标确实实施了与种子相连的恶意行为，才成熟为跨场复归锚。系统不能替目标虚构恶行。成熟锚无固定数量上限，记录宿主、位置、联系、成熟事实。身体被毁且血源路线失效时可按预授权优先级借一个可达成熟锚复归：消费锚，目标承担事件预写的焚血/灵体后果，玩家转重伤退出战斗；若宿主有保护则先以原种子记录的M/P对抗守护，失败该锚破坏。此次失败不把所有剩余锚自动试遍；其余可达锚进入同一次复归目标盘，抽中一个后结束此次尝试。只有全部适用生存机制处理后确认死亡，才封存周目。

序列5欲望共生只允许一个实际绑定的特定欲望联系作为该个体天赋的身份，不等于序列2通用种子网络；宿主/欲望消亡即失效，不能临死从全城任选情绪替代。宿主选择与伤害必须是事件显式选择，不能通过永久人格修改把人当无风险存档点。

污秽领域序列1预备槽展开，至本回合末；重入只刷新。领域内每名未被屏蔽且没有对应净化保护者承受一次精神对抗，成功记录一个“受侵蚀保护ID”。下次对该保护的破防对抗+15，一次消费，不跨战斗。控制槽针对同一屏障连续两次成功可使其在本场失效，失败不累加；若屏障被重建则旧侵蚀对象ID失效。屏障可以靠净化、移动领域外或摧毁来源反制。普通防火只挡火分量，不能保护污秽、精神和腐蚀全部效果。

序列0深渊预备展开后持续本回合与下一回合，控制槽在“欲望催生/屏障侵蚀/深渊同化”合法模式中等权抽取。前二强化对应原机制：无需开口，或一次成功侵蚀同位格普通屏障；深渊同化对被本场污染过的敌人各转一次精神对抗，成功目标总计分担 `0.50×TierBase` 的敌方基础战势削减，整方本回合最多一次，不重复按人数加倍。同位格领域可对抗剥离，高位净化可以撤掉污染前置。该减势仍服从普通回合公式；显式不可达囚笼优先，不以“万物皆深渊”跨越门的已确认规则。

序列0事件处理地区/大陆深渊化与终局事实，不把神国AOE转盘当全世界NPC逐个参战。主游戏完成序列0晋升的即时事件后结算；上述战斗规格供该即时高潮、NPC和未来明确开放模式使用，不擅自增加序列0长期沙盒。

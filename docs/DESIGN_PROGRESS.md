## 本轮审计结论

- 事件内部已拆为当前阻塞、待办选择、计划事件和不可操作纪事四类；
- 原著关键人物采用手工阶段图，并只在审核过的合法行动中做效用评分；轻量角色不运行独立角色脑；
- 组织以聚合阶段图推进，地区只保存影响事件候选的少量标签；
- 最后一个行动产生阻塞卡时，先解决卡片，再执行完整周脉冲和推进日期；
- 连环案和人物事件使用纯数据图；参与者或条件失效时只能取消并记录、替换角色槽、进入审核分支或延期；
- 当前原型的待办最多3条、统一一周过期和固定触发概率均只是 fixture，不是产品决定。
- 正式设计改为：已生成待办必须全部处理后才能继续行动或结束本周；周脉冲展示全部可知更新；组织只保存综合关系阶段和一个当前议程。
- 轻量主动迁居可行：不做地图或路线，使用已解锁地点的情境行动与事件卡，消耗一次主要行动和明确旅费。
- 周目不设现实小时目标；行动点耗尽并处理完本批阻塞卡后立即推进一周。十次晋升仍必须保留配方、材料、调配、扮演、消化、适用仪式和失败后果，并随序列提升逐步减速；序列0结清即时后果后进入结构化总结与多轴评价，死亡或其它不可逆终局可提前结算。
- 战斗不设每局场次上限、下限或配额，只由事件卡事实与选择触发；每次能力仍完整转盘，快速模式只缩短动画。

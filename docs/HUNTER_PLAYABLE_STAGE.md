# 猎人：第二条可选途径

普通人可先了解两个渠道，但成功晋升后只能沿自己的途径成长。猎人导师索伦·里奇与货主米洛为原创人物，不要求加入组织。

## 本阶段玩法

- 导师保有三瓶独立成品药。先听用药说明，再付款取得原瓶；每瓶两次实际仓库劳务可抵600便士，仍付60便士。指导费120便士。三瓶全失败后，可花1行动申请下一批，经过下一真实周再收货登记三瓶，原价与劳务要求不变；旧瓶记录保留。不把用药说明称为完整配方。
- 四整周普通生活之后独立确认服药。指导下的失败会消耗该原瓶并造成排异，允许休养重筹；战斗仍可能最终死亡。
- 首案可以辨认实际轮印，也可以在锅炉房狭口用原绳与木桩布置陷阱。痕迹不揭示幕后身份；陷阱只有敌人真实接近打击才触发一次，不自动造成伤害。
- 六个有限实践涉及车印、走失猎犬、移位货箱、滚桶、转角与原绳检查。失败留下尝试，下一周可再做；已完成不重复发奖。
- 货道冲突可交涉或战斗。铜管箱始终属于原货主，不自动变成战利品。未触发陷阱能否回收取决于实际现场；撤离未清场不隔空收回。

## 资料与游戏设定

小说第一部《小丑》第200章提及追踪、陷阱、猎杀及猎人9→挑衅者8→纵火家7分层。第二部《无面人》第21章出现现成深红色猎人魔药，强调城市狩猎、武器与事先准备的陷阱。第三部《旅行家》第69–70章补充身体素质与挑衅者能力，后者未下放猎人。

本阶段未核实猎人魔药完整配方及剂量，因此不开放制造，不伪造未知材料清单。导师供货、费用、有限数量、各项增量、四档风险映射、战斗数值及故事均为本作游戏化设定。原作文本不随源码分发。

占卜家与小丑的现有材料渠道也采用相同的简明失败后补给规则：本轮三批全部调配并服用失败后，实际申请下一批，至少跨过一周再到货。配方、劳务、价格、调配和独立服药步骤均不改变，旧材料及药瓶的耗用记录保留。

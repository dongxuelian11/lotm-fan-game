## 日常能力的玩家体验

日常能力统一为**事件卡内的被动触发**。工作、学习、调查和休养先按正常流程生成/进入事件卡；事件实例的事实、参与者与基础选项确定后，系统自动检查角色当前拥有的能力。能力与事件标签匹配时自动生效，改变玩家能看见的信息、判定参数、选项资格、风险提示或后果保护。

硬边界：

1. 不增加第五个“施法”按钮，不在四个行动之后再询问“是否发动日常能力”；
2. 被动触发不消耗额外行动、灵性、金钱或材料，也不能产生玩家未同意的暴露/污染；带主动成本的能力使用属于事件主动选项或专门准备，不归入日常被动系统；
3. 能力只读取事件已声明的受控标签与玩家可知层，不能因为被动触发就泄露隐藏真相、配方、真名、人物动机或未来结果；
4. 每次触发必须在卡片上显示能力名、触发原因和具体影响，不能暗中修改概率；
5. 没有可信非战斗被动用途的能力显式写`NO_PASSIVE_DAILY_EFFECT`，不能为了填表硬造加成。

## 被动触发可以产生的五类效果

| 效果类型 | 卡片变化 | 示例边界 |
|---|---|---|
| `REVEAL` | 在基础卡片上额外显示一条事件已预写、角色有资格知道的信息 | 不能由模型生成新事实 |
| `MODIFY_CHECK` | 对事件已存在的普通判定应用明确修正并显示来源 | 不自动改变所有同类行动 |
| `UNLOCK_CHOICE` | 显示事件预先设计的能力专属选项 | 选项事实、成本和后果必须随卡审核 |
| `WARN_CONSEQUENCE` | 提前显示一种已声明风险类别或干扰状态 | 不泄露幕后来源和精确隐藏数值 |
| `GUARD_CONSEQUENCE` | 在事件结果阶段减轻/转向一项已声明后果 | 不能取消不可抗拒的位格、免疫或既成死亡因果 |

同一事件可以触发多个被动能力，但按卡片声明的固定阶段和优先级依次处理；效果不能互相生成新的事件钩子，禁止零成本循环。

## 四个行动与被动事件标签

| 行动来源 | 事件卡可提供的能力标签 | 被动能力可能改变的内容 |
|---|---|---|
| 工作 | 职业、身份、健康、情绪、危险、异常痕迹 | 额外信息、风险提示、专属处理选项；不永久增加全部工资 |
| 学习 | 资料来源、知识类别、矛盾、危险媒介、记忆 | 来源核对、知识判定修正、已知记录联结；不凭空学习秘密 |
| 调查 | 线索、痕迹、目标、危险、追踪、遮蔽 | 揭示、难度修正、能力选项与后果保护 |
| 休养 | 伤势、精神、灵性、污染、副作用、梦境 | 状态解释、风险提示或事件预写的恢复/控制分支；不统一增加恢复量 |

世界脉冲本身不临时触发日常能力；它只能根据之前事件已经记录的能力触发结果生成公开反馈或后续卡。

## 被动结算链

```text
行动确定事件候选并创建事件实例
  → 固定事实、基础选项、基础判定和后果引用
  → 读取角色已拥有的日常被动能力
  → 按事件标签匹配 passiveAbilityHooks[]
  → 依次执行 REVEAL → WARN → MODIFY/UNLOCK → 结果阶段 GUARD
  → 保存触发能力、版本、原始值、修正值与来源
  → 向玩家展示带能力徽记的最终事件卡
  → 玩家只选择事件选项，不选择是否发动被动
```

## 事件卡被动能力接口

事件定义在需要时提供`passiveAbilityHooks[]`：

| 字段 | 作用 |
|---|---|
| `abilityId`、`abilityVersion` | 引用稳定能力与规则版本 |
| `eventTags` | 允许触发的受控事件标签 |
| `phase`、`priority` | `REVEAL / WARN / MODIFY / UNLOCK / GUARD`及同阶段固定顺序 |
| `conditionRef` | 只读取事件实例、角色公开状态和能力掌握度的声明式条件 |
| `effectRef` | 引用本文件中预先审核的被动效果 |
| `sourceTextId` | 卡片上显示“哪项能力为何生效”的固定说明 |
| `stackRule` | 与其它被动效果叠加、取高、互斥或按序执行 |

事件卡仍使用既有`NONE/CHECK/COMBAT/TRADE`选项结算模式；被动钩子只派生最终公开卡片和结算参数，不另建牌组、手牌或第二套事件系统。

## 统一记录格式

每项日常能力必须使用以下字段；暂未决定的字段写 `PENDING`，不能留空或自行补值。

| 字段 | 说明 |
|---|---|
| `abilityId` | 稳定能力ID，跨版本不因文案变化而重用 |
| 途径/序列 | 所属途径和序列 |
| 名称 | 世界内显示名；原著名与适配名分开标注 |
| `passiveType` | `REVEAL / MODIFY_CHECK / UNLOCK_CHOICE / WARN_CONSEQUENCE / GUARD_CONSEQUENCE / NO_PASSIVE_DAILY_EFFECT` |
| `eventTags` | 允许该能力进入候选的受控场景标签 |
| `eventSources` | 工作、学习、调查、休养产生的哪些事件卡可触发 |
| `dailyUse` | 调查、学习、事件、身份/潜入、资源准备等用途 |
| `trigger` | 事件卡被动钩子的匹配条件、阶段和优先级 |
| `coreStat` | 使用的核心能力；无统一社交值 |
| `difficulty` | 基础难度或明确修正；未设计时 `PENDING` |
| `cost` | 日常被动固定为无额外硬成本；主动能力成本另记 |
| `prerequisite` | 已知知识、地点、目标、装备、关系和事件前置 |
| `success` | 普通成功的可观察结果 |
| `greatSuccess` | 大成功的可观察结果 |
| `failure` | 普通失败的结果或信息 |
| `greatFailure` | 大失败的戏剧性结果或代价；不强行等同固定惩罚 |
| `worldFeedback` | 立即结果条、纪事、周脉冲或事件后续的写入点 |
| `mastery` | 0—500掌握度对日常使用的变化；逐能力填写 |
| `knowledgeBoundary` | 能力能揭示的层级、不能揭示的秘密与干扰表现 |
| `actingOpportunity` | 可能构成的扮演证据，不直接赠送扮演进度 |
| `evidence` | 原著来源、受限推断或游戏适配证据 |
| `status` | `PENDING`、`USER_CONFIRMED_BASELINE` 或 `PUBLISHED` |

事件本身仍可使用普通四档判定；日常能力只是被动修改该事件的已声明信息、参数、选项或后果。运行时RAG/小模型只能润色已经确定的描述、传闻和对白，不能生成上述字段。

## 掌握度节点的日常设计顺序

每项能力仍在100/200/300/400/500设置专属节点，但不套用统一“成功率+X”模板。逐项优先从以下维度选择真正符合能力的提升：

1. 信息更清晰，而不是凭空知道更多秘密；
2. 目标、范围或适用情境更精确；
3. 被动触发的适用范围、优先级或干扰识别更可靠；
4. 失败时更容易识别干扰来源或保住已经确认的事实；
5. 高掌握度开放原著支持的高级用法，但不能跨越当前序列位格。

每个节点必须写明它改变哪个已有字段；如果原著与玩法都没有可靠提升，就强化控制或代价，不硬造新能力。

### 固定处理顺序

1. `REVEAL`：灵视、神秘学记忆先派生玩家有资格看到的信息；
2. `WARN`：灵性直觉依据完整事件危险差生成公开风险类别；
3. `MODIFY`：把灵视、神秘学记忆或已有预示的修正写入具体判定，并保留原值/修正值；
4. `UNLOCK`：前面已经公开的信息满足条件时，才显示事件预写的能力专属选项；
5. `GUARD`：玩家选择并结算后，再处理事件声明的后果保护。

同一能力在同一阶段默认只触发一次。同一判定存在多个`MODIFY_CHECK`时由卡片显式声明`ADD/HIGHEST/MUTEX`；未声明时按`HIGHEST`处理，不能默认全部叠加。

```text
  → 卡片出现“灵视已生效”来源徽记
  → 基础选项保持工作、询问、回避等事件预写选择
```

灵视不增加工资，也不直接断言同事是非凡者；后续是否调查仍由玩家选择。

### 学习样板｜互相矛盾的笔记

```text
学习行动生成资料事件卡
  → 卡含 KNOWN_MYSTIC_SOURCE + KNOWN_SOURCE_CONFLICT
  → 神秘学记忆被动 REVEAL/MODIFY
  → 自动调出一条已确认旧记录，显示来源冲突并给当前知识判定+3
  → 学习结果按原卡四档结算，成功再应用既有+2知识
```

能力只指出“存在冲突”，不能自动判断哪份资料为真。

### 调查样板｜被遮蔽的现场

```text
调查行动生成危险事件卡
  → 卡含 TRACE_SPIRITUAL_RESIDUE + DANGER_SPIRIT
  → 灵视先 REVEAL 可读残留或遮蔽状态
  → 灵性直觉再 WARN；危险差≥20时显示灵性危险并把第一次防御难度-5
  → 两项能力分别显示来源，不合并成“占卜家加成”
```

若事件没有预写残留或危险后果，两项能力都不得临场创造内容。

### 休养样板｜重复梦境

```text
休养行动生成梦境事件卡
  → 卡含 OMEN_MATCH，并引用一枚尚未消耗的已有预示
  → 预示被动 MODIFY 当前事件的主要判定-5并标记来源
  → 玩家仍只处理梦境事件的原有选项
  → 预示是否消耗、被干扰或保留按事件预写规则结算
```

主动创建预示不是日常被动；这里只验证已有预示如何在事件卡中自动生效。

## 占卜家序列9日常效果闭合候选

状态：`DIVINER_S9_DAILY_CANDIDATE_V1 / EXISTING_NUMBERS_UNCHANGED / PLAYER_REVIEW_PENDING / NOT_IMPLEMENTED`

以下只补此前缺失的失败边界与掌握度节点，不更改已经确认的基础数值。节点强化信息质量、控制和可解释性，不统一增加成功率，也不让序列9越权获得高序列答案。

### 灵性直觉｜阈值与掌握度

灵性直觉保持事件卡内的被动`THRESHOLD`结算，不生成普通成功/大成功/失败/大失败。事件实例生成后自动计算危险差；达到既有`≥20`门槛时对第一次防御判定应用`-5难度`，未达到时不向玩家泄露隐藏危险差，也不生成误导性提示。

| 节点 | 候选效果 |
|---|---|
| 100 | `DANGER_CLASS`：达到门槛时只显示身体、精神、灵性或社会暴露中的已声明危险类别。 |
| 200 | `DANGER_TIMING`：区分危险更偏向立即发生还是延迟后果，不给精确触发时间。 |
| 300 | `COST_SHAPE`：显示第一次防御失败主要威胁的代价类型，不显示隐藏数值或幕后来源。 |
| 400 | `COMPOUND_DANGER`：事件含多个已声明危险来源时，提示这是单一还是复合危险。 |
| 500 | `AVOIDANCE_EDGE`：若当前事件存在多个公开合法选项，可被动标出一个已声明为“直觉强烈反对”的选项；不说明原因，也不替玩家选择。 |

### 神秘学记忆｜事件结果与掌握度

| 项目 | 候选效果 |
|---|---|
| 事件失败 | 保留学习尝试和资料来源记录，但不获得额外`+2知识`；不会丢失此前已确认知识。 |
| 事件大失败 | 神秘学记忆被动本身不追加惩罚；危险资料只执行玩家所选事件选项已经预告的精神/污染等后果。错误摘录只能保存为`UNVERIFIED_NOTE`，绝不能进入已确认知识。 |
| 100 | `SOURCE_RECORD`：成功学习自动保存资料来源、取得时间和已知可信层级。 |
| 200 | `KNOWN_RECALL`：事件需要时可以调出一条已经确认且相关的旧知识记录，不生成新知识。 |
| 300 | `CROSS_REFERENCE`：成功时可把本资料与一条已知记录建立可复核关联。 |
| 400 | `CONFLICT_NOTICE`：两条已知记录存在已声明矛盾时提示冲突，但不自动判断哪条正确。 |
| 500 | `SYNTHESIS_LINK`：大成功且已有两条合格来源时建立一条综合线索，开放事件预先设计的学习/调查选项；不能由模型临场创造结论。 |

### 候选验收边界

- 四项能力均不增加全局工资、全局学习成功率、全局调查奖励或统一休养恢复；
- 掌握度节点只提高当前能力的精度、控制、信息结构或风险识别，不越过事件知识边界；
- 被动能力不单独制造失败或大失败；它只修改事件卡原有判定，事件失败不抹除行动基础结果，严重后果必须来自玩家所选事件选项已经预告的危险来源；
- 所有`UNVERIFIED`内容保持推测层，后续必须通过调查/学习核验才能升级；
- 本包必须按“事件卡内被动触发”重新审核后，才能据此制作事件标签、固定文本和序列8日常能力。

| 标签 | 能力面向 | 允许效果 | 禁止推导 |
|---|---|---|---|
| `MOTION_FINE_CONTROL` | 身体控制 | 修改一项需要精确协调的动作检定 | 增加纯力量、知识或所有手工职业收入 |
| `MOTION_UNSTABLE_FOOTING` | 平衡 | 对事件声明的滑倒、坠落或被迫失位后果应用一个`guardRef` | 免疫坠落、爆炸、毒素或超位格力量 |

| `SOCIAL_INVOLUNTARY_EXPRESSION` | 表情控制 | 修改“是否无意泄露反应”的事件检定 | 自动说谎成功、改变NPC态度、抵抗读心或替玩家决定台词 |

### 固定钩子顺序与叠加

1. `REVEAL`：先执行序列9灵视/神秘学记忆，建立玩家有资格看到的事实；
2. `WARN`：序列8危险预感读取完整事件危险，替换同源的序列9危险警告；
3. `MODIFY`：身体控制或表情控制修改一个明确`checkRef`，同一检定有多个动作面向时使用`HIGHEST`而非相加；
4. `UNLOCK`：危险预感或敏捷只能开放事件预写且前置已公开的选项；两者指向同一选项时只显示一次并列出两个来源；
5. `GUARD`：玩家结算所选路线后，平衡面向最多保护一个匹配`guardRef`；不能保护与身体失衡无关的精神、污染、关系或经济后果。

身体控制不能触发新的危险预感，危险预感也不能自动生成身体控制选项。所有钩子只消费事件实例已经写入的引用，禁止递归生成钩子。

### 失败保护与扮演证据

- 两项被动都不单独掷一次“能力骰”；它们只在事件已有检定、选项或后果上工作，避免一次事件反复掷骰；
- 表情控制只阻止非自愿表情泄露，不能撤回玩家已说出口的话、抹除行为证据或改变NPC已经知道的事实；
- 平衡保护只处理事件明确标记的失衡后果；健康已经归零、角色被完全控制或遭遇超出能力边界的力量时不生效；
- 危险预感可以被遮蔽、误导或位格压制，但内容必须提前声明干扰规则；失败时不得向玩家写入虚假“已确认危险”；
- 被动生效不自动增加扮演进度。只有玩家在事件中面对已经感知却无法完全控制的局势，仍主动选择并承担后果，同时维持自己选择的外在表达时，才可生成小丑扮演证据候选；
- 单纯微笑、撒谎、做杂技、压抑真实情绪或反复触发同一身体标签都不构成扮演证据。休养事件允许角色安全表达和处理情绪，不能把持续隐藏痛苦塑造成唯一正确玩法。

### 序列9→8阶段配速落点

旧`PACING_CANDIDATE_V2`的2—3周与现实分钟预算已经撤销。当前候选把序列9→8的最早成熟门槛设为6个游戏周；达到周数不自动晋升，且至少需要以下内容在不同事件情境中成立：

1. 至少1张事件让身体控制真正改变检定或后果；
2. 至少1张事件让危险预感开放新的反应窗口，而非只增加成功率；
3. 至少2次来自不同情境的扮演证据候选，其中一次可以来自工作、学习或休养，不强制全部来自调查；
4. 魔术师配方/材料/调配准备至少推进两条可解释依赖；
5. 一张晋升事件结清序列8的即时关系、状态或世界后果。

同一事件可以同时完成上述两项，但必须分别记录来源，且不能用同一模板的换文案变体冒充不同情境。序列8的体验验收拐点是：玩家第一次发现“同一张事件卡现在出现了普通人/占卜家没有的身体路线或危险反应窗口”，而不是只看到体魄数值变大。该路线只在精确途径/序列、能力与事件条件全部满足时出现；普通人和不匹配角色完全看不到该选项及其存在痕迹。

### 全途径事件结算顺序

```text
REVEAL已知事实
→ WARN临近风险
→ PREPARE读取既有道具/火焰/身份/历史/愿望/嫁接前提
→ PASSIVE_MODIFY应用不需玩家选择的被动
→ PRESENT_ACTIVE_CHOICE只展示事件预写且当前合法的主动能力
→ VALIDATE_AND_PAY原子校验目标、灵性、材料、次数与风险

→ SUBSTITUTE_OR_GUARD处理替身、转伤、复活等后果入口
→ WORLD_COMMIT写入事实、暴露、关系、历史与资源
→ ACTING_EVIDENCE根据玩家选择和已承担后果生成候选
```

同一能力不得同时以被动和主动再次作用于同一`checkRef/consequenceRef`。主动能力没有合法目标、准备或资源时直接不显示；不能先让玩家点击再临时生成目标。事件先来自当前精确序列的占卜家内容变体，再由该变体的`specialChoiceBindings[]`私有匹配更细的能力与资源条件；未匹配项不进入公开投影，不显示禁用态或解锁提示。模型只可为已结算结果改写叙述，不参与能力选择、目标验证或效果解释。

#### 宿主链统一状态与判定

- `hostPressure`为0—5整数，只表示当前反抗压力，不是人格或忠诚度；初始值由第五次寄生命中的结果质量确定：大成功0、成功1、失败不完成寄生、大失败清空本场进度并触发反制。
- `boundaryPactRefs[]`记录逐条同意的身体、身份、危险和通讯边界；违反一条已提交边界使`hostPressure +1`，同一事实只记一次。
- 需要争夺身体控制时使用普通判定，`effectiveAbility = 玩家意志 + floor(error.parasitism掌握度 / 10) + 已履行边界数×3`，`difficulty = 宿主意志 + hostPressure×10 + 有效外援数×8`，随后读取全局5%—95%公式。
- 灵性百分比成本均为`ceil(当前灵性上限×比例)`且最低1点，在选择前显示；透支仍按全局灵性归零规则处理，不能因为成功而免除。
- `hostPressure=5`不会自动让宿主消失或寄生结束，而是强制生成`break-or-release`并暂停使用宿主身体获得的新利益，直到该卡结算。

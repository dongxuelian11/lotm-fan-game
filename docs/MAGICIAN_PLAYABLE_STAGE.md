# 0.15 魔术师可玩阶段

延伸占卜家 → 小丑 → 魔术师。小丑追加两次不同的普通生活实践，接续已有68扮演；晋升后沿六个有限场景学习使用术式，并处理一场独立的剧场后巷争端。

## 来源与试玩数值

原著第二部《无面人》第38章《收获》给出魔术师配方：迷雾树人真实根茎1块、邪纹黑豹全部脊髓液；纯水60毫升、迷雾树人汁液30毫升、水形宝石粉末3克、迷幻草精油4滴。第82章《材料齐》实际先加入辅材，再脊髓液，最后根茎。两项主材不虚构克重。

第83章《魔术师》定义九种法术。新晋火焰跳跃/操纵火焰30米、水下空气细管约5米有原文依据。纸人必须预先准备，火焰跳跃须实际火源。第138章说明纸人与焰跳仍消耗灵性。第203章明确伤害转移可以触碰他人施用，但同一伤口只能在该受伤者本人体内转移一次。本阶段有实际自身伤口操作；没有虚构队友伤口的治疗菜单。

指导240便士，六料主材1800/辅材150/调配60，四次原劳动可抵主材；小丑消化100且度过8整周后可独立服药。所有价格、行动、属性增量、检定与伤势映射是试玩G。指导服药严重排异仍可恢复后重新筹备，三批失败可申请下周补货。

战斗沿既有已确认S7核心20/30/15/35，基础450、最大灵性60为本阶段G。九术不等于每一战都凭空有水、火或绳索。当前实火来自携带原油灯；点燃消耗实际灯油，转入其他事务或战斗结束后熄灭。纸人先消耗已剪原纸与灵性，再承受本次后果，不会复活已死亡角色。伤转保留原伤ID与健康值，重伤转轻伤只是本阶段风险分配映射。

先前机制草案中的二次火焰抽取、清除伤口等未作为本阶段规则。此处以已核原著边界与当前实际实现为准。

# 记录官6：亲见的一次能力

第五部68《成长的各自》明确初晋本人记录容量：低序列7—9共20个、效果接近原版；中序列5—6共8个、约原版一半；神性能力1个且极难记录。容量不赠送技能库。第五部155《特别的报酬》记载只记录一次旅行，使用后就没有返程记录，支持单份实际释放后耗尽。记录可持续保存，未设未经原文核定的每日自动失效。

第四部55《多里安的告诫》仅核主材料完整阿斯曼之脑和古老怨灵诅咒物，完整辅料与剂量未核，本段采用独立成品原瓶G。指导360便士、原瓶3320、五次劳务抵3000，前阶占星人消化100和12真实整周；指导四档排异可恢复，三瓶耗尽后跨周购入新批次。费用与判定均G。

当前实际可见来源仅两种：原导师诺拉·维恩的低强闪光、原创成年歌颂者萨芙·里恩自愿示范的有限鼓舞。每次亲访观看消耗1行动、示范者2灵性、玩家3灵性；知识14成功才留下独立原记录，失败成本不退。每种样本每真实周一次，教师有有限灵性池，后续亲访时才按实际经过周数恢复。不能从文字、空槽、敌方未施展能力或曾听过的名字补录。

练习分别是遮挡旁观者的空靶闪光、本人有限鼓舞与普通劳动、面对不存在的高阶示范选择核查和停止。能力实践耗一份对应原记录和2灵性，失败同样耗尽；普通方法可完成和平路线。每次接触明确结束再离开和报告。没有示范来源的中阶、神性记录保持空位。

可选弥尔教学室外院普通冲突：每回合默认保留记录，玩家可明确选择一份原记录。首次实际抽中释放槽且足够2灵性才释放，随后原份额耗尽；未触发或撤退则保留，下一回合重新选择。闪光有限减势、鼓舞有限增势，不直接产生身体伤害。继承有限戏法与原短棍，伤亡仍走实际战斗。

第五部的本人容量和威力不套用《莱曼诺的魔法书》的3/10/25或中阶70—80%。记录官可在真正记录别人旅行后使用那份能力，但本段没有该实际来源，也没有旅行家5自身随时传送或无形之手。所有教学人物、场景、成本、判定和效果数值为G；小说正文不入产品。

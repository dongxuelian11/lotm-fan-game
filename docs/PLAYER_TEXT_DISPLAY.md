2026-10-14 用户要求：玩家界面不展示 G、候选名称映射、原文核验状态等开发标记。来源证据与未知研究边界仍保存在开发文档和原始内容中。

`src/shared/player-text.ts` 是单一只读显示入口。它只处理已经确认的开发前后缀、精确句段和少数固定原人物名称；`player-text-copy.ts` 保存相应显示措辞。公共投影最终返回前调用此入口，界面静态文案及错误提示复用同一函数。历史幂等回执的返回副本也适配，数据库原回执、fingerprint、原状态、随机序列和命令保持不变。

范围包括晋升、配方/成品渠道、任务、能力、历史日志、战斗记录、当前资源及固定文本。149 个界面的 813 处静态展示片段已接入；96 处错误展示也复用同一入口。去掉四处直接公开原始 JSON 的开发详情，不影响存档或普通历史记录。

保留真实未完成条件、费用、风险与不可逆后果。尚未掌握完整配方的渠道仍说明只提供成品；三百年隔绝、六十年周期、半神仪式、三十名真实成员、万人共鸣、实际海啸、六种亲猎遗骸和祝福等条件不能因文字适配而减少。玩家自定义姓名、命令、标识符和随机数据不做通用替换。G1–G6 是实际小队编号，不是开发标记；未知箱主、未核实地点线索、梦中待核说法和“原文核对”等剧情含义也保留。

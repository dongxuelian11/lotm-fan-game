# 途径战斗机制

本文件是特殊机制的唯一入口。已确认机制与等待用户总审的完整途径候选必须显式区分；概率、胜势、配速和完整能力盘仍以[量化与配速](PATHWAY_QUANTITATIVE_DESIGN.md)为准。本文不授予运行时实现权限，也不把游戏适配内容冒充原著原文。

## 共同战斗规则

2026-09-07批量回答已落档：共用调度、死亡保命转盘、伤势、灵性和AOE按`COMBAT_ROULETTE.md`“批量设计确认”节执行；下面较早的未确认规则不覆盖本次决定。途径内具体更新见对应段落；未给出的成本数字不自动确认。

2026-09-07复核说明：五条候选的未闭合项见[当前设计推进](DESIGN_PROGRESS.md#本轮五条复核结论)。秘偶不增加周行动点、梦境塑形仅首次加2、时间回退每回合一次，以及错误分身`4n²`灵性成本均不得据此标为玩家已确认规则；相关候选保留供22条总审比较，不作为默认实施决定。

- 每回合顺序固定为“战术姿态 → 次数盘 → 双方实时能力盘/目标盘 → 双方都转完后回合胜负盘 → 败者后果盘”，不另抽先手。
- 攻击增加己方胜势；闪避、灵视、直觉、伤害转移等保护/干扰降低对方有效胜势；意外可以影响任一方。
- 回合胜负盘只判当前回合胜负；轻伤、重伤、生存、死亡、逃脱、俘虏、替死和复活走败者后果盘与独立因果规则。幸存且未退出的参战者保留状态进入下一回合。
- 后续序列继承前序能力；新增机制嵌入能力格或明确的特殊子盘，不凭“继承”自动新增数值。
- 高序列数量有限且相对恒定，不用随机匿名高序列者填充世界。
- 所有百分比、胜势、行动次数和位格压制值统一回到[量化与配速](PATHWAY_QUANTITATIVE_DESIGN.md)横向平衡；本文件不擅自补值。
- 秘偶、受控者、召唤物和投影不使用跨途径统一硬数量上限；具体能力可以声明自身限制，但公共框架主要通过灵性、精神负担、维护、距离、暴露和失控风险软限制规模。

## 占卜家→愚者途径

状态：`FOOL_PATHWAY_MECHANISM_CANDIDATE_V2 / EXISTING_CONFIRMED_RULES_PRESERVED / COMBAT_V3_NUMERIC_BINDING_READY / PLAYER_TOTAL_REVIEW_PENDING / NOT_IMPLEMENTED`

所有下列机制的普通贡献、秘偶削弱、时间回退、奇迹改写、嫁接和愚弄时序候选权重统一读取[占卜家→愚者COMBAT-V3数值闭合候选V1](PATHWAY_QUANTITATIVE_DESIGN.md#占卜家愚者combat-v3数值闭合候选v1)。本文只保存机制语义、合法对象和状态生命周期。

### 序列9：占卜家

- 占卜是战前能力，战斗开始前只转一次，不进入普通实时能力盘。
- 战前占卜产生本场征兆，并随晋升延续和增强；具体增强值待量化包。
- 灵性直觉是主动能力盘扇区，只有抽中才执行动作；危险差达到门槛时降低敌方有效胜势，不是常驻被动。
- 枪击、体术、闪避/掩体、灵视和观察/调整位置可以进入实时能力盘；枪击按子弹、目标和射击条件实时计算。

### 序列8：小丑

- 不新增独立大机制盘。
- 身体控制、平衡、敏捷和危险预感作为能力格参与实时盘；不设置“普通反应”被动、独立防守盘或不符合体质的高闪避占比。
- 继承并强化战前征兆、灵性直觉和普通战斗手段。

### 序列7：魔术师

- 火焰控制/火焰跳跃为两段式：本场第一次抽中只完成火焰预备，之后再次抽中才正常发动，预备状态持续本场。
- 火焰护甲不建立伤害值或护甲值；抽中后降低对方有效胜势。
- 伤害转移抽中后降低对方有效胜势；若产生“重伤后再战”，再战时清除一个重伤效果，不直接改写胜负或跳过生存判定。

### 序列6：无面人

- 体貌重塑日常用于身份、潜入、伪装和事件卡。
- 战斗中体貌重塑嵌入体术能力格，抽中时通过改变身体结构与动作增加己方胜势，不另开机制盘。

### 序列5：秘偶大师

- 对同一有效目标连续三次抽中并成功作用，普通目标可直接转化为秘偶；高序列或受位格保护的目标不能被该规则无条件斩杀。
- 获得秘偶后，从目标生前真实拥有的非凡能力中转三次保留盘，保留三个互不重复的实际能力；不足三项时保留全部，不补造能力。
- 秘偶相较生前受到削弱，削弱方式和幅度在量化阶段确定，不预套统一百分比。
- 秘偶拥有独立次数盘和能力盘；玩家可以本体与秘偶共同参战，也可以只派秘偶参战。
- 秘偶日常行动（21A、2026-09-08第63题A已确认）：按有效秘偶数量递减增加周代理机会，不是一偶一点；本体行动点决定周推进，不复制同一事件奖励。具体阶梯、任务队列按66A由助手设计候选后整包审核。没有非凡能力的秘偶仍能依生前状态和装备参战。

### 序列4：诡法师

- 多个秘偶组成队伍，每个秘偶继续使用独立次数盘与能力盘。
- 抽中行动调度时，可重新分配本回合所有秘偶尚未使用的行动次数，不限于两两交换。
- 本体可以不参战而只操纵秘偶队伍；本体不参战时不能把敌方转化为秘偶，本体参战时才可继续尝试灵体之线转化。

### 序列3：古代学者

- 战斗开始前，可从已调查、记录且与当前事件存在可信联系的历史对象中选择一个历史投影召唤。
- 历史投影是独立参与者，有自己的次数盘和能力盘，不套用秘偶的生前削弱规则。
- 本体可以不亲自参战，只操纵历史投影与秘偶队伍。
- 时间回退抽中后，重置己方所有战斗参与者本回合可用行动次数；已经结算的胜势、伤势和持续效果不回滚。第20题A已确认：每次抽中都能尝试，不采用每回合最多成功一次；必须支付不能由回退返还的明确真实代价，具体数值待定。新增次数按正常轮转，不立即抢连动。

### 序列2：奇迹师

- 回合胜负盘判定失败后、败者后果盘开始前，先进入一次奇迹改写盘；命中可在既定限制内改写当前回合胜负。
- 奇迹改写不能抹除已成立的生存判定、死亡因果、资源消耗或其它既定后果。
- 复活次数是有限资源；生存失败时可消耗一次复活机会并重新进行生存判定，耗尽后照常死亡。
- 奇迹改写失败后，才进入序列0继承机制“愚弄时序”的专用盘。

### 序列1：诡秘侍者

- 概念嫁接嵌入能力盘，抽中即随机执行，不要求二次选择。
- 合法对象为本体、当前秘偶和历史投影；独立分身不进入对象池。
- 同一时间只保留一条本场持续嫁接关系，再次抽中覆盖旧关系。
- 已确认结果包括：将秘偶设为本体替代点；把伤害/不利影响转给秘偶并降低对方有效胜势；在本体、秘偶和历史投影之间随机嫁接一项实际存在的能力。
- 生存失败将死时，若替代关系有效，可令对应秘偶死亡而本体继续存活；不能跳过胜负盘或一般生存流程。
- 抽中分身时生成受限独立分身；已有存活分身时不重复生成，分身被摧毁或战斗结束时消失。

### 序列0：愚者

- 进入回合胜负盘前，玩家可选择是否执行胜势对调，将双方当前胜势互换；不消耗行动次数，只改变当前回合胜负盘输入，不回滚已结算后果。
- 愚弄时序不进入普通能力盘，只有奇迹改写盘失败后才转专用盘。
- 愚弄时序命中后直接结算本场胜利；每场最多成功一次，生存与既定因果仍照常处理。
- “愚弄”的首版表现使用有限、可审核的效果目录，覆盖三类：改变本回合合法时序；在实际存在的目标与来源之间制造错置；在实际存在的条件与结果关系之间进行受限替换。
- 每个效果都必须预先声明合法对象、持续、覆盖顺序和失败结果，不接受玩家自由文本让模型解释，也不能创造不存在的事实/能力、抹除已经结算的死亡与资源消耗或绕过后果盘。

### 占卜家9—0复杂状态机总审候选

状态：`FOOL_PATHWAY_MECHANISM_CANDIDATE_V1 / USER_REVIEW_PENDING / EXISTING_CONFIRMED_RULES_PRESERVED / NOT_IMPLEMENTED`

以下只补齐此前机制中缺少的状态、合法对象和结束条件；上方已确认的战斗结论不被候选覆盖。所有资源变化和目标转换必须在同一事件/战斗回合事务中提交，不能留下已经扣除资源但没有对应结果的半状态。

#### 魔术师准备状态

| 状态 | 建立方式 | 消费/结束 | 不允许 |
|---|---|---|---|
| `preparedPropRefs[]` | 学习、工作、休养或事件明确准备纸人/纸张工具/随身小物 | 对应主动能力结算后按定义消费；损坏/丢失事件可移除 | 临场凭空生成昂贵或关键道具 |
| `flameAnchorRefs[]` | 场景已有火焰，或完全消化后用一次合法能力建立小型火种 | 火焰熄灭、超出范围、场景结束或能力使用后按定义更新 | 把未知地点当落点、把压缩火球混入本途径 |
| `attentionSetupRef` | 事件声明受众、注意对象和误导窗口 | 一次幻术/戏法路线结算或受众识破后结束 | 直接改写NPC信念或已知事实 |
| `paperSubstituteCharges` | 真实制作/取得纸人 | 每次替代消耗一件；没有合法`SUBSTITUTE_WINDOW`时不可用 | 自动无限补充、替代已结算死亡 |

事件主动能力先验证准备，再显示选择。战斗中的火焰两段式继续沿用既有确认规则；事件卡已有火焰锚点不等于战斗已经完成“火焰预备”，两者使用不同作用域。

#### 无面人身份状态

一个持续伪装必须保存：

```text
AssumedIdentity = {
  formRef,
  sourcePersonRef?,
  physicalCompatibility,
  learnedBehaviorRefs[],
  credentialRefs[],
  exposureState,
  knownByActorRefs[]
}
```

外形成功只解决`formRef`。语言、礼仪、关系史、证件和目标本人掌握的秘密分别验证；任一缺口都能触发独立破绽。解除外形不会抹除目击、犯罪、承诺、债务或关系后果。玩家主动伪装成原著人物时，必须重新校验该人物存活、所在地、公开行程和知情者，不能同时出现两个“唯一人物”而世界无反应。

#### 灵体之线与秘偶生命周期

| 阶段 | 状态 | 可打断条件 | 结果 |
|---|---|---|---|
| `VISIBLE` | 已感知目标灵体之线 | 遮蔽、脱离范围、位格反制 | 只知道可作用，不知道秘密 |
| `INITIAL_CONTROL` | 累积同一`targetRef`的有效控制进度 | 剧烈身心刺激、攻击者失能、断距、专门反制 | 目标迟缓但仍能行动/抵抗；中断后本次进度清除 |
| `FULL_CONTROL_READY` | 达到内容定义的完全控制门槛 | 高位保护、生存/剧情保护、非法目标 | 普通合法目标进入转化提交；不直接跳过高位因果 |
| `MARIONETTE` | 目标被登记为死亡并由玩家控制 | 本体死亡、断联超时、灵之虫/特性丢失、内容反制 | 保留真实身体、装备、语言和能力；生前隐私只随熟悉刺激有限显露 |

秘偶不进入普通NPC心理模拟，也不获得新成长或服药资格。普通秘偶可以聚合为`MarionetteGroup`用于周脉冲；具名秘偶、携带封印物者、非凡者以及当前事件关键参与者必须保持独立状态。进入战斗的秘偶各自转次数盘，但事件定义先决定谁实际在场，不能把整个世界的秘偶全部拖入同一战斗。

#### 灵之虫分配与诡法师网络

```text
WormAllocation = {
  wormRef,
  marionetteRef,
  grantedAbilityIds[],
  burdenTier,
  connectionState,
  recoverability
}
```

- 每只被分出的灵之虫属于一个且仅一个位置；回收、丢失、断联和损伤都要留下回执；
- 秘偶只有至少一只有效灵之虫时才能使用获赠的玩家能力；获赠能力仍读取玩家该能力的真实掌握度和秘偶自身灵性/场景条件；
- 超过稳定负担不使用统一硬上限，而逐级增加精神分裂、失控、断联和永久损失风险；风险等级必须在选择前显示；
- 位置交换先验证秘偶仍有效，再原子交换本体/外物状态；交换不能清除原位置已经成立的爆炸、目击或伤势事实。

#### 历史记录、投影与历史孔隙

历史能力只读取`HistoryRecord`：

```text
HistoryRecord = {
  recordId,
  subjectRef,
  timeRange,
  sourceRefs[],
  knowledgeTier,
  affinityTier,
  contradictionRefs[],
  usableAsProjection,
  usableAsVoidGap
}
```

- `UNVERIFIED`和存在关键矛盾的记录不能召唤高位对象，只能继续调查；
- 投影成功率、持续和可用能力由知识质量、相对位格与亲近/熟悉度共同决定；具体数值仍归量化文件；
- 投影是无独立新知识的执行者，不能回答召唤者未知问题；投影消散时，其临时物品、伤害承载和未提交任务一并按定义结束；
- 藏入历史孔隙必须使用`usableAsVoidGap=true`的记录，结束后回到同一现实位置；孔隙内仍支付灵性，并允许针对历史/命运的反制；
- 借取过去状态只借用已记录状态的能力或稳定性，不复制当时的库存、秘偶、已消耗复活次数或剧情资格。

#### 愿望账本、奇迹与复活

```text
WishLedgerEntry = {
  wishId,
  requesterRef,
  authoredWishRef,
  category,
  fulfillmentMethod,
  beneficiaryRefs[],
  scaleTier,
  fulfilledAt,
  repeatLockUntil?,
  consequenceRefs[]
}
```

`MiracleDefinition`必须预先声明`requiredCategories/requiredScale/targetRefs/area/duration/cost/distortionTable/counterTags/endState`。多个小愿望只增加匹配类别与规模积累，不兑换为通用货币；满足大量“同一句愿望”不能对刷。玩家为自己许愿时，只能选择当前已解锁且积累满足的定义。

愿望扭曲按以下顺序处理：先缩小/精确应用玩家已选的时间、空间、对象和持续限制；再读取目标位格与反制；仍超出能力时进入该定义的有限扭曲表；没有安全条目时拒绝提交，而不是让模型自由生成惩罚。

复活是独立、可见、有限的生命周期资源。死亡后依次验证：特性能否回到历史迷雾、尸体附近是否仍有合法重构点、是否仍在时限内、是否有剩余次数；成功也要提交已发生死亡、失去的关系/物品和复活后状态，不能把整场事件回滚成未发生。

#### 嫁接有限目录与诡秘之境

首版只允许以下`GraftDefinition`类型：

| 类型 | 必须存在的两端 | 可产生的结果 | 禁止结果 |
|---|---|---|---|
| `LOCATION_LINK` | 两个已定位现实/灵界区域 | 将入口或移动结果接到另一合法区域 | 定位未知地点、无限距离无准备传送 |
| `TARGET_SOURCE_SWAP` | 一个实际效果来源与两个合法目标 | 把尚未结算效果的目标/来源改接一次 | 转移已结算死亡、支付或世界事实 |
| `START_END_LOOP` | 同一流程的已知起点与终点 | 让下一次流程进入循环/短路 | 永久封死全世界规则 |
| `ABILITY_RESULT_LINK` | 已存在能力与合法承载者 | 让一次能力结果由另一对象承载 | 创造不存在的能力或让非法对象永久获得权能 |
| `ANCHOR_PRAYER_LINK` | 已建立锚/祈祷关系和合法承载点 | 临时改变响应位置或承载者 | 篡改未知信徒思想、凭空生成锚 |

同一场景默认只维持一条复杂嫁接关系；新关系覆盖旧关系时先结算解除后果。诡秘之境是场景容器而非“自动获胜”：每个领域定义必须列出隔离对象、出入口、内部规则、持续、维持代价、可知反馈和反制标签。领域关闭后仍保留已经提交的伤势、死亡、资源和外部世界变化。

#### 愚弄有限目录与终局校验

首版`FoolingDefinition`只接受：

1. `TIME_ORDER_CONFUSION`：让两个尚未结算、已经登记的时序节点错认先后或延迟其中一个；
2. `HISTORY_STATE_SWAP`：把玩家真实存在的一个过去状态与当前状态临时互换；
3. `FATE_TARGET_MISIDENTIFICATION`：让一条已经存在的命运关系短暂误认目标、来源或条件；
4. `ATTENTION_BLINDNESS`：让合法目标暂时忽略一个已存在的信息关系或降低分析能力；
5. `ANCHORED_FALSEHOOD_REALIZATION`：已有假象、现实锚点和明示持续时，让该假象短暂成为可结算事实。

## 错误途径机制：完整设计候选V1

状态：`ERROR_PATHWAY_FULL_DESIGN_CANDIDATE_V1 / USER_MECHANISM_CORE_CONFIRMED_V1 / USER_TOTAL_REVIEW_PENDING / NOT_IMPLEMENTED`

本节取代此前已经撤回的Agent提案。错误途径的核心战斗幻想确定为“工具劫持”：把敌人的物品、能力、次数、身份或规则位置转为自己的工具，而不是做成纯减益或高速刺杀。所有已知触发概率、反制、持续与失败后果在发动前公开；未知对象仍只按玩家已掌握的信息显示，不因此泄露未发现的事实。

### 贯穿序列的窃取合同

- 精度分三档：完全未知时在合法目标中随机；已观察时可选择类别；充分理解后才可精确指定。
- 基础窃取同时令原持有者暂时失去目标、玩家暂时获得目标，不再额外附送即时优势。
- 窃取到的能力以一个一次性临时扇区进入玩家能力盘，不自动立即释放，也不另开掉落盘。
- 被窃能力的本质和原始强度来自目标，但最高受玩家当前序列限制；玩家对自身窃取能力的掌握度决定精度、稳定、消耗与失控风险。
- 窃取失败使目标警觉并开启反制窗口；严重失败还会暴露窃取者身份。
- 普通战斗状态在战斗结束时清除；物品归属、寄生、身份、命运等永久变化必须由事件因果正式提交。

### 序列9：偷盗者

- 物品窃取成功后，目标物品进入玩家的临时物品区并从目标可用物品中移除；战后是否永久取得由事件因果决定。
- 价值感知只被动显示附近存在“有价值目标”和大致类别，不直接显示准确位置、用途或所有者。

### 序列8：诈骗师

- 误导成功后，目标下一次能力使用失效。
- 该机制为两段式命中：第一次转中进入准备阶段，准备持续本场战斗；第二次转中完成骗局，使敌方当前剩余次数减少并使我方当前剩余次数等量增加，同时令目标下一次能力失效。完成后清除准备，可以重新积累。
- 后续序列按[量化与配速](PATHWAY_QUANTITATIVE_DESIGN.md)提高每次完成可转移的次数，不取消两段式前置。

### 序列7：解密学者

- 一次成功解密即可解开当前事件已经定义、且目标允许解出的完整谜题，不再使用三档证据完整度门槛。
- 危险解密在尝试前显示模糊危险预警；失败可以触发注视、反向定位或污染，但必须由事件预先登记。

### 序列6：盗火人

- 能力窃取是贯穿后续全部序列的核心能力；在序列6时，成功后生成一次性临时能力扇区，同时让目标对应能力暂时失效。
- 后续序列持续强化可窃对象、精度、对抗和作用时机。已经发动的能力可以被中断并窃取，但这不是序列6能力；按用户确认结果，序列5正式解锁中断窃取。

### 序列5：窃梦家

- 序列5正式解锁对已经发动能力的中断窃取；序列6只能窃取尚未发动的合法能力。
- 主动进入“连续窃取对抗”后，该状态持续当前回合；目标本回合之后每次使用能力都会即时触发一次窃取判定。双方以精神强度和序列高低实时对抗，不读取固定成功轮盘；下一回合若要继续，必须重新抽中该能力。
- 抽中“防御性窃取”后开启防御状态：目标随后转出的第一个技能失去效果，并作为被窃能力进入窃取者的能力盘。
- 窃梦、储存/转移梦境或植入事件已经定义的场景只在事件卡中处理，不进入战斗能力盘；窃梦家不能借此进入梦境并自由塑形。

- 完成第五次寄生命中只提交寄生关系状态；控制方式、宿主反抗、求援、记忆冲突和关系后果由手工设计的特殊事件卡继续结算。事件卡事实、选项和后果不能由模型临场创造。

- 每个合法分身使用独立次数盘与能力盘。分身的能力盘由其实际携带的非凡特性、宿主能力和自身状态生成，不复制本体完整能力盘；分身仍承担灵性、同步、暴露和身份冲突等代价，但不消耗或增加周行动点。

### 数值接线前必须遵守的冲突消解

- 开门、旅行和连续闪现都属于“令敌方技能失效或增加其生效检定”的同一防御家族；同一次敌方技能只能被同源效果处理一次，不能连续套娃直至必定无效。
- 第9项只保护门途径玩家本人；第18项让队友取得相同的本次开门效果，因此只有实际被共同带过门的那一名队友在该次效果持续期内受到保护。
- 第19—20项取代原数值包中“战斗传送直接改变位置/目标合法性”的默认解释；位置变化可用于演出和因果，但战斗数值收益只结算已确认的技能无效化。
- 第27项放逐与第31项囚笼不能绕过回合胜负后的伤势、生存和世界因果；放逐不是击杀，囚笼100%只锁定漫游者与被囚目标之间的当前回合胜负。
- 第7项未决意味着现阶段不能靠灵性成本限制两段记录、连续闪现、象征化或门权柄；这些机制必须先靠盘面概率、阶段、容量、目标条件和反制窗口平衡。
- 下一步由设计任务自行完成扇区映射、记录容量、无效化数量、实时对抗公式、掌握度节点、日常事件模板和确定性模拟，再交付整包审查。

### 原批量问题与选项（历史，已回答）

### A. 记录与复制核心（D-DOOR-MECH1—8）

1. **记录能力的发动流程**
   - A（推荐）：两段式。第一次抽中“记录”进入准备并锁定目标，后续再次抽中才完成记录；给对手明确反制窗口。
   - B：一次抽中立即记录并可在本回合释放；节奏快，但爆发和滚雪球最强。
   - C：只能在战前或事件卡中记录，战斗中只负责释放；最轻量，但临场抄招特色弱。

2. **多项已记录能力如何进入能力盘**
   - A（推荐）：主盘只有一个“记录能力”扇区，命中后再转一次小型记录池轮盘；盘面不会被大量能力挤满。
   - B：每项记录能力各占主盘扇区；直观，但记录越多盘面越臃肿。
   - C：抽中后由玩家手动选择任一已记录能力；控制最强，但弱化转盘特色。

3. **记录容量采用什么限制**
   - A（推荐）：固定槽位，随序列提高逐步增加；最易理解和配平。
   - B：使用总权重预算，强能力占更多容量；更精细，但管理成本更高。
   - C：不设容量，只用灵性与失败风险限制；自由度高，但容易囤积和失衡。

4. **准备阶段成功后锁定哪项能力**
   - A（推荐）：锁定目标最近一次实际展示的合法能力；信息清楚、操作最轻。
   - B：玩家从目标本回合展示过的能力中选择；策略更强，但需额外界面。
   - C：玩家先秘密指定想记录的能力，再等待目标使用；博弈强，但容易出现空等。

5. **完成记录时如何判定成功**
   - A（推荐）：依据双方序列、相关掌握度和玩家已知情报进行实时对抗；强敌仍可冒险记录。
   - B：按能力品阶给固定成功率；透明但人物差异较弱。
   - C：只要目标合法且完成两段流程就必定成功；最简单，但缺少反制。

6. **记录能力释放时保留多少原能力强度**
   - A（推荐）：保留原能力性质，但效果上限受门途径玩家当前序列限制；不会借一次记录跨级碾压。
   - B：所有记录能力统一按固定比例削弱；配平容易，但不同能力手感趋同。
   - C：完整复制目标当时强度；还原感强，但极易越级失衡。

7. **记录能力的灵性成本在哪一步支付**
   - A（推荐）：记录和释放分别支付；强能力既有取得成本也有使用成本。
   - B：只在记录时支付，后续释放免费；鼓励准备，但囤积爆发强。
   - C：记录免费、释放时支付；操作轻，但战斗中试错成本过低。

8. **记录失败的主要后果**
   - A（推荐）：不获得记录，目标察觉并取得一次针对记录者的反制窗口；让失败直接改变战局。
   - B：得到一项错误或残缺记录，之后释放可能反噬；戏剧性强，但增加状态管理。
   - C：只承受灵性或精神反噬；数值直接，但互动性最低。

   - A（推荐）：两段式撤离进度；第一次建立出口，第二次结算前对手可追击、封锁或破坏。

   - A（推荐）：操纵场景物件、装备、机关或缴械，不直接凭空造成高额伤害。

29. **封印敌人或能力的战斗流程**
   - A（推荐）：累积封印进度，对手每阶段都有打断、转移或解除的反制机会。
   - B：一次命中后进行一次实时对抗，成功即完成封印；快，但高波动。
   - C：战斗中只能建立条件，完整封印必须由战后事件卡结算。

### G. 序列2：旅法师（D-DOOR-MECH34—37）

   - A（推荐）：九条不同的异界事件弧，每条要求留下可核验的见证、影响或证据。
   - B：用一张蒙太奇事件卡一次完成；节奏短，但失去序列2长期目标。
   - C：只累计旅行距离数值；最省内容，但无法体现“传说”。

### H. 序列1：星之钥（D-DOOR-MECH38—40）

38. **位置权柄在能力盘中的核心模式**
   - A（推荐）：命中后只选一种——定位目标、隐藏自身位置、扰乱目标位置；每次都有独立反制。
   - B：一次命中同时完成三种效果；权柄感强，但信息与战斗压制过高。
   - C：三种模式分别占主盘扇区；概率易读，但高序列盘面臃肿。

39. **重力与空间破碎如何选取多人目标**
   - A（推荐）：先转AOE数量盘，再转目标盘；未建立保护时友方也可能被选中。
   - B：玩家手动画定任意区域和目标；控制精确，但绕过已经锁定的AOE流程。
   - C：只能攻击一个目标；简洁但不符合高序列尺度。

40. **定位未知或远方目标的前置条件**
   - A（推荐）：必须先拥有神秘学联系、可信情报或可追踪痕迹；定位成功后仍需另行发动旅行。
   - B：定位成功即同步传送到目标身边；节奏快，但把两项权柄合并得过强。
   - C：只能得到随机线索，不能准确定位；保密性强，但权柄反馈不足。

## 观众途径

状态：`AUDIENCE_PATHWAY_MECHANISM_COMPLETE_CANDIDATE_V1 / USER_MECHANISM_SEMANTICS_PRESERVED / DREAM_AND_CONTROL_NUMERIC_BINDING_READY / PLAYER_TOTAL_REVIEW_PENDING / NOT_IMPLEMENTED`

梦境六盘、暗示乘区、虚拟人格削弱、受控者软负担、作家与空想领域的具体候选值统一读取[观众→空想家COMBAT-V3数值与机制接线候选V1](PATHWAY_QUANTITATIVE_DESIGN.md#观众空想家combat-v3数值与机制接线候选v1)。本节不重复保存数值，避免两处漂移。

### 贯穿规则

- 观众主要强项是心理、信息、梦境和支援，不设计成强直接伤害途径。
- 所有观众战斗能力都必须实际抽中才生效，不使用未抽中的“普通反应”常驻被动。
- 心理学隐身是主动能力盘扇区：抽中后进入回避回合，敌方直接打击不能生效，观众也不能直接打击，只能施加机制效果；精神、控制、领域或未知效果不因该扇区自动失效。
- 梦境中的半级位格压制只对比观众高一序列的目标生效；同序列无效，高两序列及以上无效，幅度沿相邻序列差值的一半（第22题A已确认）。

### 序列9：观众

- 战斗开始前有一次无行动消耗的观察盘，揭示一个角色能够知道的敌方倾向，并小幅降低第一轮敌方有效胜势；不生成永久标记。
- 日常观察、洞察和人物信息服务于调查与事件卡，字段进入[日常技能效果](PATHWAY_DAILY_EFFECTS.md)。

### 序列8：读心者

- 读心是二段式：第一次抽中读取目标，第二次抽中读心类扇区才降低敌方有效胜势；不要求两次扇区同名。
- 读心状态最多保留一层，持续到第二次成功或本场结束。

### 序列7：心理医生

- 心理暗示对每名敌人分别叠层，最高10层；每次抽中增加1层，持续本场，不在敌人之间转移。
- 叠层以乘法方式降低敌方有效胜势；即使达到10层，也只提供战斗加成，不直接操纵敌人。

### 序列6：催眠师

- 催眠命中后同时减少敌方本回合剩余出招次数1次，并使下一回合出招次数减少1次；可重复命中。
- 解锁心理学隐身主动扇区；序列6每次使用后下一回合不能再次使用，序列5仍保留限制，序列4起取消。

### 序列5：梦境行者

- 抽中进入梦境领域后消耗当前战斗行动，双方进入同一梦境空间；已有胜势、状态和效果延续。
- 进入后使用六类梦境特殊盘：`梦境塑形`、`梦境引导`、`梦境穿行`、`梦境压制`、`觉醒/退出`、`意外`。规范名称统一为“梦境塑形”；“梦境塑性”视为同一扇区的旧写法，不新增第七扇区。梦境盘沿用当前实时A/E能力池，不另造数值池。
- `梦境塑形`用于改变已存在的梦境条件；本次先消耗1次梦境额度，再在同一次效果内增加2次，净增1次（第23题A已确认），在本次效果结清后判断额度是否用尽，不在扣减与增加之间提前退出。每次有效塑形都如此处理，不设仅首次加2，也没有基础额度+2的总上限；增加的是可继续转动的额度，不是自动连转。觉醒与其他明确退出条件继续有效。
- `梦境引导`包含“高级心理暗示”效果，用于增加当前目标的暗示进度；`梦境穿行`负责位置、接近与回避；`梦境压制`削减敌方行动或有效胜势；`觉醒/退出`安全结束当前梦境；`意外`从有因果的混合后果表中抽取。六盘以心理、信息、控制和支援为主，不建立直接伤害主盘。
- 每次进入领域的梦境能力额度为1次；用尽立即退出，退出扇区和意外扇区不消耗额度。进入领域本身可在规则允许时重复且消耗当前行动。
- 梦境中心理暗示的叠层收益加倍，其他暗示规则不变。

### 序列4：操纵师

- 抽中后创建当前观众普通能力盘的削弱复制体；复制体有独立次数盘和能力盘，只在本场存在，不能带入下一场。
- 本场失败时复制体承受该次失败冲击，主角不因该次失败直接受影响；复制体被击溃后必须等待完整一回合，并再次消耗创建行动后才能重建。
- 在梦境中，观众可以避开直接参战，让复制体作为独立队友战斗；复制体不使用梦境特殊盘。
- 心理学隐身的下一回合禁用限制从序列4起取消；心理暗示达到10层可直接操纵目标。

### 序列3：织梦者

- 每次进入梦境领域可使用3次实际梦境能力，额度用尽立即退出。
- 心理暗示基础每次抽中增加3层，梦境中翻倍为6层；最高10层，达到10层立即操纵目标。
- 完整梦境迷宫留给序列2。

### 序列2：洞察者

- 解锁完整梦境迷宫：持续整个梦境领域实例；敌方本轮剩余出招次数大于1时降为1，已经0则保持0，不补发行动，且不能直接攻击观众（第24题A已确认）。
- 每次进入梦境可使用4次实际梦境能力，额度用尽立即退出。
- 洞悉抽中后选择敌方一项当前存在的能力，将其从本回合剩余能力盘移除，下一回合恢复。

### 序列1：作家

- 每次进入梦境领域可使用5次实际梦境能力，额度用尽立即退出。
- 所有行动完成、进入回合胜负盘前，若观众本回合有效胜势大于0，则把敌方有效胜势锁定为不超过观众本回合有效胜势的75%；观众有效胜势≤0时不生效。

### 序列0：空想家

- 领域升华为持续本场的空想领域并进入独立特殊轮盘。
- 每次抽中可改动一个当前条件或一个能力类别，作用于当前回合；不同类别可并存，同类别后来的改动覆盖先前改动。
- 空想领域仍进入回合胜负盘，不跳过回合胜负与败者后果结算。

### 完全操纵边界

- 心理暗示达到10层后立即建立操纵，不另开控制盘；目标剩余次数随控制权进入新阵营，不重抽次数。只有敌方已无抵抗者才结束战斗，不能控制多人中的一名就无条件全场胜利，也不把目标判为死亡（第6题A已确认）。
- 目标限有意识的活体心智。受控目标可跨战斗保留，作为类似秘偶的独立单位，不削弱其原有能力。
- 受控目标不设统一硬数量上限，由精神/灵性维护、距离、暴露、控制稳定性和失控事件形成软限制。维护公式与日常行动已经形成玩家总审候选；精确免疫名单、原著核验和运行时存档字段仍待完成。

## 太阳途径：简单机制完整候选V1

状态：`SUN_SIMPLE_MECHANISM_SET_USER_CONFIRMED_V1 / NO_SPECIAL_ROULETTE / NO_EXTRA_RESOURCE / COMBAT_V3_BOUND / SIMULATION_PENDING / NOT_IMPLEMENTED`

太阳途径故意不追求错误、门或观众那类复杂状态机。它只增加五个跨序列概念，且都复用普通六槽、目标盘、AOE盘和胜负盘：`太阳易伤`、`公证`、`直接净化`、`正义准则`、`神圣领域`。未写在下面的能力按普通胜势贡献结算。

### 贯穿规则：太阳易伤

- 事件或敌人模板可以预置`SUN_VULNERABLE`，适用于明确的亡灵、污秽、邪异、阴影或与太阳权能冲突的目标；标签必须由审核内容给出，不能由模型、技能名称或玩家自由文本临时判定。
- 太阳途径的直接攻击命中带该标签的目标时，本次正向贡献乘`1.25`。一个目标同时具有多个相关描述也只乘一次，不叠层、不增加行动次数、不跳过回合胜负盘。
- 对普通人、普通野兽、一般罪犯或仅仅敌对的角色没有易伤；“太阳”不等于道德阵营判定。

### 序列9—7：歌颂、祝福与神术

- 歌颂没有持续光环条、层数或独立资源。抽中次攻时表现为对己方下一次合法攻击的普通支援贡献；抽中自保/控制时表现为稳定士气或打断恐惧的普通减势，结算后结束。
- 祝福、恐惧抵御和太阳光环只在对应扇区抽中时结算当回合贡献；它们不提供永久免疫、额外行动或免费治疗。
- 恶意/邪异侦测在战斗中只识别事件已公开为可侦测的目标或伪装，不扫描未知秘密。圣光、光焰、净化斩击和神圣之水仍使用普通直接攻击、AOE或控制预算。

### 序列6：公证

- 公证抽中控制槽后，玩家只在当前合法选项中选择其一：`有效公证`使己方下一次合法能力的正向贡献乘`1.25`；`无效公证`使敌方下一次合法能力的正向贡献乘`0.75`。
- 公证只保存一个一次性标记，持续到本回合结束；新的同类公证覆盖旧标记，不相乘。没有合法后续能力时，本次改为普通控制贡献，避免空转。
- 战斗公证不创造契约、事实或法律，也不能把已结算能力改成未发生。长期契约、证言与违约放在事件卡中，并由手工条款决定。

### 序列5—4：强化净化与无暗

- 范围神圣之光和净化光环使用全局AOE数量盘、目标盘与分配规则；同一次命中不因目标数量增加总预算。
- 直接净化抽中控制槽后，在`移除目标一个明确标为可净化的有害状态`与`结算一次普通控制减势`之间二选一，不能同时领取两份收益。污染根源、永久创伤、伤势、死亡与已提交世界事实不在普通净化目录。
- 无暗领域或神圣装备抽中后只持续当前回合：解除事件允许解除的一项遮蔽，并让领域内符合内容标签的目标按`SUN_VULNERABLE`结算。它不是物理墙，也不让太阳途径免疫所有攻击。

### 序列3：正义准则

- 每个正义导师战斗事件最多提供一条可执行的`justiceCondition`，例如“本回合不得主动伤害撤离中的平民”或“不得使用已经被公证为禁用的能力”。条件必须在事件中预写、公开并能由确定性规则检查，模型不能判断玩家是否正义。
- 正义审判直接命中已被日志确认违反该条件的目标时，本次正向贡献乘`1.25`；没有确认违反时按普通贡献结算。
- 玩家违反自己选择的准则时，下一次正向贡献乘`0.75`，随后清除惩罚；严重叙事后果仍由事件卡提交。它不自动判负、扣命或替代败者伤势/死亡盘。

### 序列2：逐光者

- 光之化身、光矛、太阳使者与高位审判均落在普通主攻、次攻、自保和控制槽；不建立光速移动盘、形态生命值或第二行动队列。
- 范围光矛和城市级光照仍受合法目标、AOE总预算、友军波及与事件边界约束。光形态只能在对应自保槽命中后提供本回合普通减势。

### 序列1：神圣国度

- 神圣国度只在自保槽抽中后开启，持续当前回合；预备槽只建立领域锚且即时贡献为0。领域内事件声明可被光明揭露的遮蔽失效，己方首次恐惧类负面效果无效，带`SUN_VULNERABLE`目标仍只享受既有`1.25`易伤，不追加第二个倍率。
- 同名领域刷新持续时间但不叠加；同位格领域冲突进入普通控制对抗，不凭序列名自动覆盖。

### 序列0：太阳与不灭之光

- 太阳权柄、纯白之光和秩序压制继续使用高位H盘的主攻、次攻与控制预算；不得把“太阳”解释成无目标、无范围或无反制的自动胜利。
- 不灭之光在自保槽抽中后武装一次`inextinguishableLight`，持续本场战斗且最多保存一次。玩家随后第一次进入死亡结果时，消费该标记重转一次败者生存盘；第二次结果无论轻伤、重伤或死亡都照常提交，已发生的伤势、资源损失和世界后果不回滚。

### 明确不增加的机制

- 没有太阳能量、信仰点、歌声层数、净化值、光照计或独立灵性消耗表；战斗灵性体系仍是全局未设计项。
- 没有太阳专属子轮盘。公证、净化、领域与不灭之光都由现有六槽命中和一次性标记表达。
- 没有对“邪恶人格”的自动判定，没有永久洗脑、永久能力剥离或自动复活。

## 暴君途径：简单机制候选V1（已由V2取代）

## 白塔途径：事件知识与战斗知识分层已确认V3

状态：`WHITE_TOWER_MECHANISM_PACKAGE_USER_CONFIRMED_V3 / EVENT_AND_COMBAT_SEPARATED / KNOWLEDGE_ATTRIBUTE_PRIMARY / COMBAT_SELF_CONTAINED / NOT_IMPLEMENTED`

白塔同时拥有“知识型日常玩法”和“知识型战斗玩法”，但两者不能共用一条需要临场补叙事数据的流程。V3将二者拆开：事件卡负责获得、验证和使用具体知识；战斗盘只读取开战时已经形成的知识快照，并用知识属性直接结算能够在当前回合完成的能力。战斗不会临时侦破案件、研发秘术、查询世界历史或证明宇宙理论。

### 一、三种知识必须分开

| 层级 | 含义 | 能做什么 | 不能做什么 |
|---|---|---|---|
| `knowledge`核心属性 | 0—500的理解、学习、推演和信息处理能力 | 进入白塔基础战势加权，并作为特殊战斗检定的主要输入 | 不会凭空授予配方、真名、秘密或敌方未公开能力 |
| `knowledgeRecords[]` | 日常事件中取得的具体事实及其来源、可信度、污染和剧透层 | 解锁事件隐藏选项；在开战时匹配为有限熟悉度 | 不直接增加行动次数，不在战斗中临时改写真伪 |
| 能力掌握度 | 使用阅读、解析、模仿、秘术等能力的熟练程度 | 影响对应能力的稳定性、控制和效果上限 | 不替代知识属性，也不自动补齐缺失来源 |

知识属性是白塔的主属性。序列9—3的知识权重为40%，序列2为40%，序列1—0为45%；它已经通过核心加权进入`BaseBeforeRound`。白塔特殊战斗检定再让知识决定“能否理解并处理这个具体能力”，但不把知识值第二次直接加进普通胜势。

### 二、日常事件盘：负责获得知识和改变世界

以下内容完全留在事件卡和普通d100判定，不进入战斗六槽：

1. 阅读书籍、比较版本、学习语言、建立索引和获得具体知识记录；
2. 案件推理、证据排除、现场重构、人物动机与历史因果调查；
3. 秘术的构想—实验—验证、教学和长期入库；
4. 对社会事件、灾难和晋升的长期预言与分歧条件；
5. 洞悉城市、组织、仪式与世界结构中的规律支点；
6. 过去/现在/未来信息组查询、知识传播控制与序列0完整理论；
7. 因危险知识产生的污染、注视、关系变化、公开后果和周目结算。

事件隐藏选项由“精确序列/能力 + 知识难度 + 必需知识记录 + 当前状态”共同过滤。高知识可以提高理解和判定成功率，但缺少必需记录时仍看不到本不该知道的选项。事件结算可以提高知识属性、写入知识记录、验证秘术或生成战前准备资产；这些变化在事件结束后持久化。

### 三、从日常到战斗只通过一次只读快照

开战时系统自动把与敌人、地点、仪式和装备相关的`knowledgeRecords[]`匹配为`combatKnowledgeSnapshot`，不增加额外准备回合：

| 熟悉度 | 条件 | 战斗作用 |
|---|---|---|
| `NONE` | 没有匹配记录 | 可以使用白塔固有战斗能力，不获得来源修正 |
| `FAMILIAR` | 有一条相关且未验证为假的记录 | 白塔特殊战斗检定`+5` |
| `VERIFIED` | 有两条独立可靠来源，或亲自验证记录 | 白塔特殊战斗检定`+10` |

快照生成后保持到战斗结束。战斗内观察可以把某项敌方能力加入`observedAbilityIds[]`，但不能在战斗中把猜测写成永久知识；战后若事件卡允许复盘，才可能形成新的知识记录。这样日常准备有价值，但没有准备的白塔也能正常转完战斗盘。

### 四、知识主导的统一战斗检定

白塔的解析、模仿、战斗预见、弱点洞悉和全知处理统一使用：

```text
理解值 = 0.70 × 自身知识 + 0.30 × 对应白塔能力掌握度
复杂度 = 0.50 × 目标能力的主属性 + 0.50 × 目标能力掌握度

成功率 = clamp(10, 90,
  50
  + 8 × (白塔位格阶 - 目标位格阶)
  + 0.10 × (理解值 - 复杂度)
  + 熟悉度修正
)
```

目标能力必须声明自己的主属性与掌握度；未知NPC读取内容模板，不能默认成0。知识在理解值中占70%，因此同序列、同掌握度下，高知识白塔会稳定获得更强的解析与反制能力；位格和目标复杂度仍能阻止低序列仅靠堆知识破解高位权柄。

## 历史稿：白塔途径知识—解析—模仿机制候选V2（已由V3替代）

状态：`SUPERSEDED_BY_WHITE_TOWER_MECHANISM_PACKAGE_CANDIDATE_V3 / HISTORICAL_ONLY / DO_NOT_IMPLEMENT`

白塔的机制重点不是增加一个“知识点”资源，而是让来源可靠的知识改变玩家能看见、能分析、能模仿和能反制的内容。V2建立八个有限接口：知识依据、观察记录、解析标记、模仿检定、审核秘术、预言预提交、规律支点、智慧/全知/完整理论。所有接口都必须引用事件或战斗中真实存在的对象，不能由模型临场发明事实、弱点、法术或世界规则。

### 共用状态与结算顺序

| 状态/内容 | 建立方式 | 持续与消费 | 作用 |
|---|---|---|---|
| `knowledgeBasis` | 阅读、调查、导师、实验或已提交事实形成`NONE/PARTIAL/VERIFIED` | 绑定具体能力、谜题或理论来源；来源失效时保留错误记录 | 决定能否解析并提供有限修正，不是通用知识点 |
| `observedAbilityIds[]` | 敌方能力在本场实际使用并公开表现 | 当前战斗；战斗结束清空 | 提供解析目标，不暴露尚未使用的技能 |
| `analysisMark` | 序列6起解析成功 | 当前战斗；反制或模仿二选一消费；同能力刷新 | 将一次理解转化为削弱或模仿机会 |
| `verifiedMysticArtIds[]` | 序列5起完成构想—实验—验证事件链 | 持久内容记录；使用本身不删除 | 让审核秘术进入合法能力盘，不把内容写成自由文本 |
| `foreseenResponse` | 序列4起预言预提交成功 | 对应预测发生、偏离或目标离场时消费 | 显示未来并将一次有害贡献`×0.75` |
| `leveragePoint` | 序列3起洞悉真实规律支点成功 | 下一次严格匹配能力或本回合结束 | 将匹配贡献`×1.25`，不适配则自然过期 |
| `wisdomChoiceUsed` | 序列2每回合第一次使用智慧双候选 | 当前回合结束清空 | 两个合法候选中由玩家选一，不重转失败 |
| `provenTheorem` | 序列0成功解析、洞悉或全知观察 | 最多一个；理论结论盘消费；战斗/当前事件链结束清空 | 把已证明对象转化为反驳、演示或撬动之一 |

结算顺序固定为：六槽命中→合法对象/知识来源检查→目标或特殊子盘→实时对抗→普通贡献或模仿比例→状态建立/消费→意外、知识污染与世界后果。白塔不能先看结果再伪造知识依据，也不能同时把同一`analysisMark`用于反制和模仿。

### 共用知识依据

- 每个可解析能力或事件谜题可以声明`knowledgeBasis=NONE/PARTIAL/VERIFIED`。它来自已读资料、已完成调查、可靠导师、亲自实验或已提交世界事实，不是角色知识属性自动生成。
- `NONE`只允许观察公开表现和建立疑问，不能完成模仿；`PARTIAL`允许进入解析对抗；`VERIFIED`为解析对抗提供候选加成并允许战后形成长期知识记录。
- 来源失效、伪造或被污染时，事件必须保留原来源和错误后果。高知识不会自动把错误资料变真，小模型也不能把表现文本升级为知识依据。

### 序列9—7：阅读、推理与现场重构

- 阅读者的记忆、理解和仪式魔法落在普通事件被动与I盘六槽。战斗中的仪式必须由事件明确提供材料、时间和合法效果；没有准备时对应扇区回退为普通防护、道具或环境利用。
- 推理学员命中识破/控制槽时可以排除一个与已知证据直接矛盾的候选，不会自动指出真凶。错误前提进入意外槽，不能被高知识属性静默修正。
- 守知者的现场重构只读取事件保存的`traceFacts[]`，输出发生顺序、轨迹或缺口；不能生成现场没有留下的对白、动机或身份。战斗中以轨迹识破、武器攻击和仪式防护结算，不另开重构轮盘。

### 序列6：解析与模仿

1. 敌方能力实际使用后才进入本场`observedAbilityIds[]`；未展示能力、开发者秘密和目标隐藏技能不能被加入。
2. 博学者命中预备槽时，从已观察能力中按“基础10，同一能力本回合每多使用一次+5”生成解析目标轮盘。只有一个目标时仍显示100%结果和完整回执。
3. 目标具有`PARTIAL/VERIFIED`知识依据时进入实时解析对抗；`NONE`只显示公开标签，不建立解析标记。成功后为该能力建立一个一次性`analysisMark`，同能力刷新但不叠加。
4. `analysisMark`持续到当前战斗结束，只能二选一消费：目标下次使用该能力时贡献`×0.75`；或在己方抽中同类攻击/防御/控制槽时进入模仿检定。消费后清除。
5. 解析失败不产生错误“真相”；它进入明确的失败回执。意外槽可从内容预写的误判、奇异变形、精神冲击或暴露中结算。

解析成功率沿用双方序列与掌握度实时对抗，不设固定命中盘；`VERIFIED`知识只提供有限加成，不能让低序列稳定解析高位权柄。解析成功不等于模仿自动成功，两次判定分别表示“理解结构”和“以自身能力重建”。

模仿不是门途径记录：

- 门途径记录强调看见后保存一次原能力；白塔模仿必须拥有知识依据并成功解析，再用自身知识重建相似效果。
- 临时`analysisMark`形成的模仿只尝试一次；进入模仿实时对抗后立即消费。成功才按当前序列模仿比例结算，失败则本次能力贡献为0。
- 模仿失败幅度不足20点时只记录“重建失败”；失败幅度达到20点且知识依据仅为`PARTIAL`时，将“效果变形”以10点权重加入本次意外候选并重新归一化。`VERIFIED`依据不会完全保证成功，但不追加这项变形风险。
- 若要长期掌握相似效果，必须在战后通过学习/实验事件形成一个审核过的稳定秘术定义；临时模仿不能直接写入永久能力目录。
- 模仿只能复现能力效果，不能获得途径权柄、唯一性、象征、额外行动者、永久复活或自由存档改写。
- 模仿贡献取“目标原能力本次普通贡献×当前序列模仿率”，并以白塔当前序列同类槽最大贡献封顶，不能借高位目标突破自身位格预算。原能力需要独立行动者、召唤物、材料或环境时，模仿者仍须满足内容声明的替代条件。

### 序列5：审核秘术与法术创造

- 秘术导师可以长期掌握由内容数据定义的`mysticArtDefinition`。每条定义必须包括知识来源、合法槽位、对象、范围、失败后果、必要材料和反制标签；不能在战斗中输入自由文本创造法术。
- 新秘术采用“构想—实验—验证”三阶段事件链。构想只生成候选，实验可能失败或污染，验证成功后才进入稳定能力目录；模型只能改写表现文本。
- 一场战斗有多个合法秘术时，先由六槽决定攻击/防御/控制身份，再用秘术子盘从该槽当前合法定义中选择。基础权重10，每100掌握度+2；没有合法秘术时回退为仪式、武器或普通识破。
- 长期秘术不因使用而消耗记录，但材料、伤势、污染和暴露仍按事件定义结算。战斗灵性消耗尚未设计，不能在此私自补表。

### 序列4：预言预提交

- 预言命中预备槽后，从确定性随机源提前生成并保存目标下一次能力盘结果；玩家看见结果，但该行动尚未结算。
- 预言家同时获得一个`foreseenResponse`。预测结果实际发生时，其对预言家的有害贡献`×0.75`并消费标记；如果目标死亡、离场、能力被窃取或合法条件改变，预言显示“未来偏离”，不补抽、不转移到其它能力。
- 序列4预见一个能力类别；序列3额外看见目标；序列2预见连续两个结果与目标；序列1—0预见连续三个结果、目标及当前公开反制标签。
- 命运遮蔽、反预言或同位格干扰进入实时对抗。预言不读取未生成事件、不泄露玩家不可知世界秘密，也不能当作存档回滚。

### 序列3：洞悉与规律支点

- 洞悉者命中自保或预备槽时，从事件预写的`principleLevers[]`进入支点轮盘。支点必须是已存在的物理、仪式、组织、信息或行为规律，并声明适用能力和失效条件。
- 支点成功洞悉后获得一次`leveragePoint`：下一次严格匹配该规律的己方主攻、次攻或控制贡献`×1.25`，随后清除。用于日常事件时只解锁对应隐藏选项，不转换为战斗加成。
- 对活体敌人、隐秘仪式或高位规则的洞悉需要实时对抗；错误支点进入意外结果。不能用“移走一块石头”去崩塌没有相应结构事实的山。
- 洞悉者可以在`NONE`知识依据下尝试认知本质，但成功仍只建立当前对象的一次标记；不会自动写入永久知识库。

### 序列2：智慧选择

- 智天使每回合第一次进入一个至少有两个合法结果的解析、秘术或支点子盘时，可以生成两个不重复候选并由玩家选择其一；这不是额外行动，也不是失败重转。
- 两个候选都必须来自当前合法内容。若只有一个候选则正常结算，不凭空补出第二个；若双方拥有同位格智慧/欺瞒干预，先进行一次实时对抗。
- 智慧不会替玩家自动提交选项。非战斗事件只标注“依当前已知事实最稳妥的候选”和依据，玩家仍可选择风险路线。
- 完整神话生物形态不作为常驻被动。事件或自保槽允许显露`mythicalTower`至当前回合结束：来自低于自身位格的信息/精神过载贡献`×0.50`，实体、能量、规则、封印和同位格攻击正常结算；所有看见者、关系方和地点必须同时结算神话形态暴露、疯狂与污染后果。

### 序列1：全知之眼

- 全知之眼命中自保或预备槽后先转目标盘，再进入时间层盘：过去35、现在40、未来25。成功对抗后显示该层一个经过过滤的`informationFactGroup`；日常事件的隐藏选项可以选择一个合法时间层，但仍须承担同样的位格、污染和公开后果。
- “现在”可以显示目标能力构成和一次性状态；“未来”按预言规则预提交连续三个能力结果、目标和公开反制标签；“过去”只显示造成当前状态的一条已提交因果链，不补写未记录对白或动机。
- 过去、现在、未来的信息必须来自事件已经装载的`informationFacts[]`，并通过角色知识、剧透层级、污染和位格过滤；不允许扫描源码、数据库秘密或尚未生成的未来事件。
- 隐秘、错误、欺瞒和同位格遮蔽进入实时对抗。失败只显示无法穿透及公开原因，不生成貌似合理的假答案；内容明确声明欺骗结果时才可返回错误信息。

### 序列0：完整理论

- 白塔通过一次成功解析、洞悉或全知观察建立一个`provenTheorem`，最多保存一个，新的理论覆盖旧理论；它必须记录证明对象、来源和可反驳条件。
- 之后命中控制或预备槽时，消费理论并转动理论结论盘：`反驳40/演示35/撬动25`。反驳令对应能力下一次贡献`×0.50`；演示以100%效果比例使用该能力的一次非权柄效果，但仍受当前槽位和自身位格封顶；撬动令下一次严格匹配支点的己方贡献`×1.50`。序列2继承的智慧双候选可以作用于本回合第一次理论结论盘。
- 知识权柄命中控制槽时，可以在“将一个`PARTIAL`依据提升为本战斗`VERIFIED`”与普通控制减势之间二选一；提升必须引用已经存在的两个独立来源，战斗结束不写回永久知识。它不能把虚假来源变真，也不能删除已经公开的信息或人物记忆。
- 完整理论只能引用已解析能力或事件预写支点；不能用自由文本定义新规律。权柄、唯一性、象征和世界终局对象仍需同位格实时对抗，且即使成功也不能被模仿为自己的永久权柄。
- 序列0仍进入回合胜负、败者伤势/死亡和周目结算。“全知”不会自动解决所有事件，“全能”只是知识转化为审核过能力的设计方向，不是无条件效果。

### 明确不增加的机制

- 不建立可刷取的知识点、推理点、智慧值、预言次数或全知能量条。
- 不允许自由文本法术、模型生成弱点、无来源真相、任意读取NPC秘密或跨途径永久复制权柄。
- 不把白塔模仿做成门途径记录：前者知识优先、解析后重建，后者保留自身已确认的观察—记录机制。
- 所有战斗效果仍要先由六槽实际抽中；子盘、实时对抗和预提交只决定命中后的合法对象或有限结果。
- 不让智慧成为自动代打，不让全知读取源码/存档/未生成事实，不让完整理论由自由文本直接声明胜利。

## 倒吊人途径：呓语—血肉—牧羊—堕落机制已确认V1

倒吊人的事件玩法围绕秘密、信仰、污染、血肉来源、灵魂关系、罪与牺牲展开；战斗玩法围绕呓语结果、阴影控制、血肉储备、已牧放灵魂、堕落标记和代罪结算展开。事件中的秘密、教义、人格、罪责和世界希望不直接进入战斗盘；战斗观察也不会自动成为永久知识或灵魂资产。

### 日常事件盘

1. **秘祈与倾听**：事件卡预写可听内容、来源、可信度、污染、强制后果和可截断点。成功只能获得该卡已有的秘密，不能由模型创作新神名、启示或能力。
2. **阴影活动**：潜伏、追踪、藏匿、诅咒和召唤必须由地点光照、目标媒介、影界干扰和见证者字段约束。
3. **血肉魔法**：治疗、整形、藏身、制造血肉仆从和炸弹均需要合法血肉来源；来源可能来自自身、已授权对象、尸体或明确物品，并产生伦理、调查和污染后果。
4. **牧羊**：只在目标死亡、灵体脱离或事件明确提供合法灵魂时出现。玩家必须选择牧放、安抚、释放、拒绝或其它预写路线；活着的普通敌人不能因战斗中抽中能力便被直接收进名册。
5. **三位一体**：人格分化、身体分离和重新统一属于长期事件状态；失控人格不是战斗中临时生成的随机NPC。
6. **秽语与堕落**：事件中改变承诺、组织忠诚、传播和罪责，必须提交具体关系与世界后果；不能用一句自由文本命令改写任何人。
7. **代罪与牺牲**：必须明确被保护者、被承担的损失、牺牲内容和保证的有限希望。不能用“牺牲一点血”换取任意世界愿望。

## 黑暗途径：安眠—梦魇—灵体—隐秘机制已确认V1

状态：`DARKNESS_MECHANISM_PACKAGE_USER_CONFIRMED_V1 / EVENT_AND_COMBAT_SEPARATED / REPOSE_AND_HORROR_USER_CONFIRMED / SPIRIT_ROSTER_USER_CONFIRMED / CONCEALMENT_ESCAPE_USER_CONFIRMED / DARK_RETURN_USER_CONFIRMED / NOT_IMPLEMENTED`

黑暗途径的事件玩法负责夜间守望、梦境内容、灵魂关系、秘密是否应该隐藏、地区厄运和永眠选择；战斗玩法只处理当前光照、安眠层数、恐惧层数、已登记灵体、厄运检定、暂时隐秘和黑暗复归。梦中的秘密、被隐藏的世界事实和国家级厄运不能直接成为战斗数值。

### 日常事件盘

1. **夜间守望**：不眠、夜视和危险感知被动解锁夜班、长时跟踪、黑暗撤离和守护路线；少睡不增加每周行动点，只改变事件的疲劳与信息后果。
2. **午夜诗歌**：事件卡提供诗句主题、对象、语言、仪式背景和可能回应。小模型可以改写已审核诗句表现，不能用自由诗创造新神术、秘密或结果。
3. **梦境**：卡片预写梦主、可见梦段、梦与现实对应、允许提问、醒来条件和记忆污染。梦境塑形只能改变这些节点，不能把NPC未拥有的知识写进梦中。
4. **安魂**：安抚活人、灵体、亡灵或队友创伤时，必须记录被压下的情绪/欲望、治疗程度和是否只是暂时沉睡；安魂不等于观众途径的人格重写。
5. **役使灵体**：只有事件中实际遇到并成功封印、安抚或达成约定的灵体才能进入名册。每个灵体保留种类、来源、一项角色能力、服从度、磨损和释放条件。
6. **隐秘与厄运**：隐藏身份、联系、行动或地点必须指定对象和期限；厄运必须落到审核过的事故候选与因果链上，不能直接把任意人物写死或把未知事实删除。
7. **永眠**：序列0事件必须明确要令谁或什么沉睡、持续多久、由谁承担空缺及醒来条件；永眠不能成为删除所有冲突的通用按钮。

### 序列7：纵火家

> 2026-10-11重建0.16更新：根已按本次原文核查明确暂不接纵火家火焰跳跃，避免混入魔术师路线。当前可玩版本采用凝火/压缩火球/火焰长枪/有限火鸦，不包含无敌火甲。下面两段旧二段触发与火甲/焰跳记录保留为历史候选，不代表当前实现或原著已核能力。

- 压缩火球明确属于猎人途径，不属于占卜家或愚者；压缩火球作为直接攻击能力，不因猎人途径整体的机制收敛而删除。
- 火焰控制与火焰跳跃继续使用两段式触发：第一次只预备，第二次才发动。
- 火焰护甲抽中并生效后立即降低对方本回合剩余有效胜势；火焰跳跃成功发动后同样立即降低对方本回合剩余有效胜势。

### 序列6：阴谋家

- 误导命中后立即从对方本回合剩余攻击次数中移除1次，最低为0；不凭空增加己方次数，也不直接判定胜负。
- 火焰武器只有在角色实际持有可用武器时生效，并对武器攻击增加胜势；没有武器时不能把该加成转为徒手攻击加成。
- 误导与火焰武器的具体数值分别由对应能力字段填写，不在本节补写固定点数。

### 序列5：收割者

- 弱点攻击不另设独立特殊系统，直接复用通用两段式：第一次抽中无效果，第二次抽中才正常结算其胜势效果。
- 不把弱点攻击改写为直接死亡或跳过回合胜负盘与败者后果盘。

### 序列4：铁血骑士

- 镀钢与火焰化身在能力生效期间免疫物理伤害，免疫持续至本回合结束；它们不另造独立伤害值或护甲值。
- 链接号令可以链接同战场内所有满足条件的己方队友；链接成立后，已链接队友的全体攻击获得胜势加成，链接持续当前战斗。
- 链接号令不凭空创造队友、不增加行动次数。2026-09-08第65题A已确认：固定攻击贡献倍率作用于链接后每次真实攻击，即时结算，不使用回合末固定团队池分摊。具体倍率按66A量化后整包审核；普通AOE不额外扩大总预算。

### 序列3：战争主教

- 以战争号令、战歌、纯蓝火焰和战争支援等数值能力为主，不再追加超出数值基线的独立强力机制。
- 战斗中不设置独立枪械能力区；已有武器仍按全局枪械上限和可用条件处理。

### 序列2：天气术士

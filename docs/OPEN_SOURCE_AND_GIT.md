# 开源与 Git

## 内容边界

- 原创代码和原创工程文档使用根目录 MIT License；
- MIT 不授权《诡秘之主》题材、原著正文、插图、音乐或其他第三方内容；
- 仓库不得包含私人 RAG 语料、凭据、用户存档、运行数据库、生成缓存或来源不明素材；
- 参考项目只按 `docs/REFERENCE_REUSE.md` 的当前边界研究。

## 日常协作

- `main` 保存当前可工作的主线；功能较大时使用 `codex/<feature>` 或清晰命名的短期分支；
- 开始修改前查看实时分支、HEAD、工作树和现有差异；
- 保留他人的未提交改动，不批量格式化无关文件；
- 原子提交，只暂存当前功能涉及的文件；
- 禁止 force-push、破坏性 reset、重写他人历史或自动合并；
- 测试、浏览器试玩、桌面运行、打包与发布分别按实际结果说明。

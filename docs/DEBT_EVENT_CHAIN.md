## 1. 金额与时点

总额=开局明确承担的欠款＋已提交新增欠款－实际偿还。来源记录只用于说明欠谁、已付/未付和剧情，不产生多套独立利息模拟。约定周还款合计由来源明确数额相加；普通生活应付款每新增一笔固定周还30、医疗一笔12、O02初债30，最后一期取剩余本金。金额归零时该来源的周还款贡献归零；不再向已还清欠款收费。

本周新债下周才开始扣周还款，避免刚选择欠付又立即催同一笔款。周末先处理生活账单，再还本周到期债务；有钱则支付至多本期到期额，无钱则支付至多现有资金，未付本金不再加一遍到总债务。付款按来源成立先后分配，同日按稳定顺序；只为解释来源与结束对应贡献，不提供玩家套利调整顺序。

`missedWeeks`表示总债务连续未完成本期约定还款的周数。足额完成本期或总额清零则重置0。允许额外提前偿还，余额不足不能提交；本期已足额后不再重复扣。债务总额归零时清除催收状态，历史原因保留。

普通信用状态只有正常、催收、暂停新增信用三阶段，由连续欠付驱动，不新建万能社会信用分。暂停只影响本债务内容提供的新增赊账，不封锁工作、已有市场现金交易、调查或成长，更不能直接结束周目。

## 2. DEBT-NOTICE-01｜还款提醒

触发：连续未足额还款达到2周，当前为正常，普通人。一次转入催收；固定正文：“账目显示你连续两周未付足约定金额。对方要求你说明接下来的安排。”显示余额、本期未付、约定周还款和来源。

两项NONE、0AP：

- `.plan`“说明下周按约偿还”：只记录承诺，不扣未拥有的钱、不减债、不重置欠付周数；下周能否履行看实际入账。
- `.decline`“现在不作承诺”：记录拒绝；金额和欠付周数不变，不额外判死或扣属性。

下周有无履行改变该来源的近期关系原因；只是措辞不同不奖励扮演。已处于催收时不每周重复发这张卡。

## 3. DEBT-SETTLE-01｜给出处理办法

触发：连续未足额达到4周，尚未进入暂停信用，普通人。先把信用转为暂停，固定正文：“多次延期后，对方不愿继续增加赊账额度。你仍可以工作、调查和用现款交易，但这笔欠款需要实际处理。”

选择NONE、0AP：

- `.pay`“用现款偿还”：有现金时可选，支付min(现款,总债务)，扣多少减多少；全清则进入结清结果，未全清保留暂停。
- `.sell`“交付一件可转让物抵款”：仅确有本人所有、可转让且已有固定出售价格的普通物品时出现；先显示准确物品和抵款额，玩家确认目标后转移物品，减债min(固定价,余额)，固定价超过余额的部分以现金返还。借物、证物、家族资产、未定价物、未开放的市场渠道不构成可用目标；本节点使用预先登记的债权方收取规则，不临时发明买家。
- `.defer`“保留欠款，继续谋生”：不扣额外资源、不清欠款，保持暂停；当前卡结束，不立即重新排同一张卡。

没有资产和现金时仍能选择defer，不强制生成贷款或杀死玩家。暂停期间通过每周实际还款逐步还清；同一欠付周期不反复发第4周卡。暂停不是免费清债：余额、约定还款、未履行原因继续存在；本包不额外扣健康或AP制造死循环。

## 4. DEBT-CLEAR-01｜账目结清

任何真实付款使总额从正数变0时生成一次非阻塞纪事：“最后一笔应付款已经结清。旧记录仍保留，但这笔债务不再要求你还款。”清约定还款、欠付计数和本包信用暂停；不恢复已失去资产，不自动把受损人际关系变成友好，不发数值奖励。

部分来源先结清时只结束该来源收费，全部总额清零才产生本总债务结果。新债是新的真实欠款周期，不能重放旧结清领取任何资源。

## 5. 与生活、医疗相接

生活必需应付款可以如实累积，信用暂停不允许系统把未支付费用假装消失。`LIFE-BILL-01`在暂停期间不再生成同样选择卡：到期自动支付可支付部分、剩余如实记录欠款，沿用下周赤贫申请，仅显示本周纪事。它不是新的主动借款；玩家可通过工作和实际偿还退出，不全局停工。

`LIFE-CARE-01`的CREDIT只有信用未暂停时可选；暂停时仍可现金医疗或拒绝。8B确认：贫困医疗出路改为通过援助事件完成普通委托换处置，不设通用每周目免费次数。旧`CARE-AID-01`一次免费处置方案撤回，不能载入正式事件池。新委托必须明确真实需求、玩家可完成的普通任务、行动成本、失败/取消后果、不可重复兑付；具体节点仍待下一批制作，不能在未完成任务时直接治疗。换得处置后仍按7B完成后续一次休养与健康≥80%，不清旧债、不发现金或组织身份。

普通人之外不沿用本包阻塞卡；债务金额和还款仍是真实状态，高序列需已设计的关系/资产后果版本。缺版本时只结算已有金额和可知纪事，不在序列0弹普通催债卡；达到序列0即时结算时将未清债务写入卷宗。

# 战斗与转盘

`STATUS=PARTIALLY_LOCKED / SOURCE=D-COMBAT1..6K,D-COMBAT1D,D-COMBAT2C,D-COMBAT2D,D-COMBAT3D,D-COMBAT4C..4D,D-COMBAT5Q,D-COMBAT6G1..G1G,D-PLAYERDEATH1..1A`

## 结算顺序

1. 战斗由调查或其他事件触发；先检查能力成立条件、免疫、权柄阻断和客观不可行情况。
2. 双方分别生成本轮出招次数盘。次数由当前角色能力和效果生成，非均匀分布，不存在全局固定1—3或1—7边界。
3. 双方按各自次数转动能力盘。能力盘在回合开始按实时面板生成快照，本回合常规转动使用同一快照。
4. 能力盘自动收录当前可用、可触及的序列能力、普通技能、装备、道具和封印物；玩家不能战前删格子配牌。
5. 每次命中可以重复触发同一项目；是否叠加、刷新、一次性、耗充能或产生额外代价由项目自身声明。
6. 双方按各自次数完成本轮能力盘后，汇总基础战势、本轮技能胜势、状态和效果，生成并转动本轮最终胜负盘，只判定胜利/失败。
7. 胜负之后才结算伤势、死亡、逃脱、俘虏、污染、暴露、救援和战利品；若后果已唯一确定则不强行再转盘。

## 能力盘

每个项目的占比先由基础权重乘该项目掌握度曲线，再叠加当前明确修正，最后统一归一化（`D-COMBAT4C`）。双方能力盘完整公开项目、精确概率和主要权重来源；“未知情况”只隐藏具体内容，不隐藏占比。每场能力盘保留固定小底噪，战场、污染、封印物副作用等明确因果来源可以在其上追加权重（`D-COMBAT4D`）；底噪和追加量的具体数值后置。

能力命中后的胜率贡献和特殊效果不能被压成一个固定战斗力。技能、掌握度、装备、道具和封印物不进入基础战势，而是在战斗能力盘命中及其战斗专属效果阶段发挥作用。

- 回合快照项目临时失效保留原扇区并执行预声明结果：`D-COMBAT3D`（已锁定）。
- 双方本轮能力盘都转完后生成胜负盘：`D-COMBAT1D`（已锁定）。

- 未知情况区采用固定小底噪并允许明确因果来源追加：`D-COMBAT4D`（已锁定）。

第一版已确认能力命中后的胜势贡献和次数盘最低次数。一次性物品耗尽、先手数值修正和后果转盘公开层级不阻塞核心双转盘引擎，先使用简化兼容行为并标记为后续版本。

### `D-GRILLBATCH6` 已锁定

- 每次有效能力命中产生有方向胜势增量，同一方本轮全部命中增量逐项相加：`D-COMBAT5Q`。
- 正常可行动角色的次数盘最低值为1；昏迷、封锁、退出等失能条件走独立条件，不伪装成普通0次：`D-COMBAT2D`。

以下项目已延期，不在本批提问：

- 一次性物品耗尽：`D-COMBAT3E`，第一版沿用快照失效的预声明处理。
- 先手数值修正：`D-COMBAT5R`，第一版未声明时按0处理。
- 后果转盘公开层级：`D-COMBAT1E`，第一版结算页直接展示最终后果。

战斗转盘不调用普通能力的四档数值判定作为战斗胜负，也不复活已取代的 `D-ABILITYEFFECT1..4` 事务提案。战斗中的能力胜势、特殊效果、物品/封印物和资源处理沿用本文件及项目自身的战斗声明；若需要新增战斗规则，必须另立 `D-COMBAT*` Grill 题。

## 基础战势

基础战势只读取：序列/位格、四项核心能力、健康/精神/灵性及其他明确状态、先手。序列主导档位；核心能力只区分同档或相邻档位；状态和先手是临时修正。地形、关系和身份通过能力条件、特殊效果或后果因果进入，不直接塞入通用公式。

BaseBeforeState = TierBase + CoreBonus

### 状态修正

健康、精神、灵性按当前值/上限分档，分别扣减基础战势：76%—100%扣0%，51%—75%扣5%，26%—50%扣10%，1%—25%扣20%；三项相加总扣减最高40%。状态扣减作用于完整的“序列基础值＋核心能力加成”。同一原因不得同时通过资源下降和标签重复扣减。用户已锁定资源可透支为负值；负值进入战斗分档时按0处理，特殊能力必须显式声明例外（`D-RESOURCEOVERDRAFT1..3`）。

## 最终胜负盘与位格

双方有效胜势合并后按相对比例生成两块胜负盘：

```text
playerWin = playerEffectiveAdvantage /
             (playerEffectiveAdvantage + enemyEffectiveAdvantage)
```

不额外设置低位方胜率硬上限，也不乘统一的跨序列衰减倍率。序列差距通过基础值和真实能力效果体现。低序列允许在针对性准备、克制、封印物、环境优势或高序列严重负面状态下依靠转盘运气爆冷；熟练度本身不能越级。每套序列能力完成后要批量模拟，并由人工按原著复核。

## 健康归零、生死与终局

- 最终胜负盘不判定生死。
- 战斗中健康降至0时触发独立生存转盘；生存成功恢复到1点健康并进入濒死状态，失败即死亡。
- 生存概率复用 `clamp(5%, 95%, 50% + 2% × (EffectiveSurvival - InjuryDifficulty))`。普通人至序列7的生存位阶加成为+0/+5/+10/+15；伤势难度档为15/25/35/45；同场此前每次生存成功使后续难度+10。
- 玩家死亡立即结束当前游戏；死亡周目永久只读封存，不可回档或继续。
- 精神归零按具体原因结算，不使用统一精神归零转盘；NPC死亡后的持续效果另行处理。

## 仍未锁定

战斗失败会结束本次遭遇；必须由新的事件或条件重新建立交战（`D-COMBAT1C`）。胜负盘时机、次数盘组合、快照失效处理、能力盘组合、未知区底噪/因果追加、能力贡献合并和次数最低值均已锁定；一次性物品、先手数值、后果公开层级和其他复杂生命周期规则按台账的后置状态处理。

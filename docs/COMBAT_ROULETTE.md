# 战斗与转盘

## 首版内容覆盖边界

首版22条神之途径均需进入战斗内容。各途径序列9—0能力要逐项填写战斗权重、胜势贡献和命中效果，再接入本文件的转盘流程。封印物作为额外能力来源进入能力盘，但首版只有12件拥有完整规格。当前转盘引擎的自动收录、快照和归一化规则不因内容批量化而改变；尚未完成的能力或封印物记录不能被占位数据冒充为正式效果。

途径特殊机制的唯一编辑入口是[途径战斗机制](PATHWAY_MECHANISMS.md)；所有序列的数值、配速和实时能力盘唯一记录在[途径量化与配速](PATHWAY_QUANTITATIVE_DESIGN.md)。愚者/观众旧文件仅作历史镜像。其中的特殊处理仍须接入本文件的统一次数盘、实时能力盘和胜负盘，不能绕过胜负后果与生存规则。

## 结算顺序

1. 战斗由调查或其他事件触发；先检查能力成立条件、免疫、权柄阻断和客观不可行情况。
2. 每个可控制阵营选择一项本轮战术姿态。姿态只调整已经合法的能力权重或后果倾向，不能删除固有能力、凭空增加能力或直接指定命中结果。
3. 双方分别生成本轮出招次数盘。次数由当前角色能力和效果生成，非均匀分布，不存在全局固定1—3或1—7边界。
4. 单挑逐次交替；多人战按下方玩家确认的“小轮”轮流行动：本方所有仍有次数的行动者各执行一次，再换对方，同一方不会先耗完所有人的本轮次数。每次能力即时结算。能力盘在回合开始按实时面板生成快照，本回合常规转动使用同一快照。
5. 能力盘自动收录当前可用、可触及的序列能力、装备、道具和封印物；玩家不能战前删除固有能力。消耗品只有在玩家预先授权本场可使用时才进入盘面，抽中并实际生效后按声明消耗。
6. 能力命中多个可能目标时，继续转动受该能力约束的目标盘：先决定AOE实际命中数量，再从所有合法目标中决定具体对象；不能选中无效、不可触及或不满足能力条件的目标。队友、秘偶、投影和受控者使用各自独立转盘，玩家最多指定其大体姿态，不能逐项指定能力和目标。
7. 每次命中可以重复触发同一项目；是否叠加、刷新、一次性、耗充能或产生额外代价由项目自身声明。
8. 双方按各自次数完成本轮能力盘后，汇总基础战势、本轮技能胜势、状态和效果，生成并转动回合胜负盘，只判定当前回合哪一方胜、哪一方败。
9. 败者进入独立后果盘，至少覆盖轻伤、重伤、死亡分支，并按场景加入逃脱、俘虏、救援或特殊机制。若败者仍能行动且遭遇尚未结束，保留全部伤势、资源和持续效果进入下一回合。

### 逐次交替：2026-09-07玩家确认

- 单挑示例：甲本轮3次、乙2次，若本轮甲先行动，则为`甲① → 乙① → 甲② → 乙② → 甲③ → 回合胜负盘`。一方次数耗尽后，另一方完成其仍合法的剩余行动；若特殊机制已经结束遭遇，则不再机械补转。
- 每次能力即时处理效果，已经开启的窃取、开门等机制按各自已确认触发条件介入；打断在被作用能力完成前处理，不等到双方全转完再追溯取消。
- 第2题玩家确认：首回合由事件中明确的战斗发起方先行动，没有明确发起方时玩家方先行动；后续每回合交换先行动方。不额外抽先手盘，也不新增速度属性。这里确定的是阵营先后，多实体内部排序仍待设计。
- 后续多人排序、加次和拦截规则按下方批量回答细化；实体内部具体先后尚未确定，不由此擅自授予玩家逐技能控制。

### 批量设计确认：2026-09-07第3—19、30题

本节是用户最新明确选择。与旧候选不同的以本节为准；方向确认不等于所有数值与边界都已完成。完整题目和答案见`COMBAT_DESIGN_QUESTIONS.md`。

- **多人小轮（3B）**：轮到本方时，本方所有仍有行动次数的行动者各动一次，再换对方所有行动者各动一次，循环到本回合结束。每个身体保持自己的次数盘/能力盘，不共享次数或分摊其单体预算。已确认的逐次交替在单挑时原样成立，多人时按此细化。
- **召唤与加次（4A、5A）**：本回合新召出的独立实体从下回合开始使用自己的轮盘，明确即时行动的能力除外。增加本回合次数只增加剩余次数，不插入立即连动，继续按正常小轮轮转。错误次数银行仍按专属规则延至下回合。
- **控制权（6A）**：观众完成操纵/错误完成第五次寄生后，宿主尚未执行的次数随控制权转移，按新阵营排队，不重新发次数；只有敌方已无抵抗者才结束战斗。不能在同一小轮借换阵营重复兑现已经使用的行动。宿主人格及后续反抗仍按专属事件处理。
- **交战小组与后果对象（7A、8B）**：正常互相交战者按交战小组判回合胜负；空间囚笼等隔离关系单独处理。败方本轮确实承受有效威胁的所有角色，各自进入后果盘，不再抽一次受创人数。不可触及、无实际致伤来源不能凭普通物理胜势制造对应死亡。交战小组随隔离/脱离变化的细节待补，不把门对一人的100%扩张为全场100%。
- **强制胜负冲突（9A）**：只有两项强制效果真正作用于同一对抗且冲突时，按来源位格、掌握度进行实时对抗，胜出效果成立；不把没有冲突时的已确认100%改成普通胜率。
- **拦截顺序（10A）**：施放打断→目标转移→命中防护。同一阶段按状态建立先后处理；原能力已被取消则不继续消费后续拦截。绝对相同建立时刻的稳定排序细节待补。
- **死亡保命转盘（11自定义）**：不由玩家事先排保命优先级。进入死亡分支，若有多种当前有效保命能力，则转盘决定执行哪项；之后再死亡仍从当时可用能力中继续转，直到没有可用保命能力。每项是否消耗、失效、冷却或还能再用取决于自身已确认规则，不把所有能力强行改成一次性；有效封锁/终点会影响合法候选。转盘精确权重，以及一次尝试失败后仍处死亡分支的继续触发细节需补，不能悄悄恢复旧预设顺序。只有最终死亡成立才周目结算。
- **伤势起始值（12A、13A、14A）**：普通无伤首次战败候选为轻伤65/重伤30/死亡5；带伤再败每次将10个百分点移入死亡，先扣轻伤、不足再扣重伤，最高100。这是玩家选定的试玩起始值，不是已经平衡。所有伤势真正痊愈后清除累计带伤再败风险，明确不可治愈的后遗症单独保留；战斗中的临时稳定不清除。专属致命效果仍是例外。65/30/5决定的是进入死亡分支，不是最终死亡率。
- **灵性方向（15A）**：普通能力不逐次扣灵性；召唤/分身维持与特殊权柄才有明确成本。具体适用清单、计费节点与数字待量化；旧`4n²`等值不因此自动确认，也不能把未填成本按免费运行。普通技能不因旧草稿统一百分比成本被收费。
- **AOE与群控（16B、17A）**：普通AOE始终使用一份总胜势预算，在命中者之间分配，不再采用随人数提高总额的140/165/180%默认表。每个通过独立检定的群控目标承受完整控制，只有普通胜势部分分摊。独立实体仍各自拥有自己的预算；明确专属例外不被普通规则抹去。
- **倍率叠加（18A）**：未另行确认的同类普通增/减倍率只取最强；明确不同机制分别生效，已确认的组合奖励保留。
- **普通撤退（19B）**：本回合全部行动用于撤退，失败后仍承受本轮后果，不兼得正常攻击行动；门的两段开出口撤离保持专属规则。普通撤退检定具体位置和公式待补。
- **候选两段准备（30A）**：尚未确认的两段能力，准备默认保留到成功使用、被反制或战斗结束；已经确认的专属持续时间不自动延长。

这套结构借鉴此前审计的“咒术转盘特别篇”连续转盘与状态累积思路，只借鉴“次数→能力→胜负→后果/机制”的玩法方法，不复制其中技能名、数字、轮盘视觉、文案、素材或事件。

38—66题及42/49补充均已回答，原文见《战斗与途径机制收尾》。以下明确规则覆盖9月7日同段候选；具体费用表、子盘与普通模板按66A由助手继续设计、整包交用户审核。不再等待这两项澄清。

### 小轮与控制转移（38C、39A）

1. 每完整回合抽完次数后，本方按各实体抽到的本回合次数从多到少固定排序，同次数沿用出场序。不新增速度/先手属性，也不每消耗一次就重新排序。阵营先后仍按已确认规则交换。
2. 一个小轮为先行动方各动一次，再后行动方各动一次。每实体同一小轮最多一次常规行动；专属明确即时行动例外保留。
3. 控制转移时，未在本小轮行动且新阵营阶段尚未结束者排入新阵营未执行队列；否则等下一小轮。未用次数转移，已用次数不返还、不重新发次数。插入同序细节由稳定排序处理，不给重复行动。
4. 加次只加剩余次数、不立即连动；本回合新召唤实体下回合才领独立次数。三位一体、秘偶等已有实体各自转盘。
5. 保命成功不重开回合或重抽次数，依真实身体状态返回剩余轮转；明确延迟复归的能力仍按自身时间条件。
6. 排序算例：甲方甲抽2、乙抽4、丙抽4，则本回合为乙→丙→甲（乙先出场）；耗次不会使甲中途跑到前面。若转移一个本小轮已动过的敌人，不能立即再动。

### 小组划分与威胁（40A）

- 按真实交战空间分组，不把混战拆成每次攻击的两人组。每个实际身体基础战势只归一个普通交战组。
- 隔离即时改变后续合法目标；此前已结伤势、消耗不撤回，未结普通技能贡献随受影响对象归入其回合末所在组，施放者基础战势不随之复制。
- 跨组支援须有能力明确允许，一次贡献仅归受作用组。门对囚笼目标的100%按已确认特殊关系处理，不扩张为全场必胜。
- 本轮确受有效致伤威胁的败方角色各判普通后果；不可触及、只有观察或攻击已全部无效化，不凭普通胜势创造伤害。纯隔离无内部敌人不自动判伤。
- 拦截仍为施放打断→目标转移→命中防护；同阶段按建立顺序，绝对同刻以实体稳定出场序和能力项目序处理，不新增随机盘。

### 保命与死亡：41A、42自定义

- 已确认：各项合法保命能力等权；第37题取消通用生存判定，不恢复人人可抽的普通求生。
- 用户第42题原话：“抽到保命能力不会失败，抽到死亡进入死亡，如果没有队友救就死了。”
- 因此删除旧“抽到能力后再判普通成功率，失败换下一项”的默认流程。抽中合法保命能力直接执行其救命结果与真实代价，不追加通用失败盘。
- 死亡结果仍保留队友救援可能；不是把“没有自身保命能力”直接等同“立即封存”。队友必须真实存在并具有可适用救援，不能凭队伍中有人就无条件复活。
- **42补充已确认**：进入死亡流程后，保命选择盘同时包含真实可用保命能力与“死亡”。抽中合法能力直接执行救命效果；抽中死亡只检查队友实际救援，没有有效救援才最终死亡，不继续把剩余自身保命逐个试完。只有一项自身保命时仍与死亡一起抽，不能免转必救；没有自身保命时走死亡/队友救援流程。保命能力之间等权，死亡项权重按66A由助手量化。既有封锁/终点在入盘前的资格与对抗接线由助手细化，不能重新增加抽中后的失败判定，也不整体删除反制。
- 只有实际保命/救援流程结束后最终死亡才封存周目；每项真实费用、媒介及可重复性仍按自身规则，不自动全变一次性。

### 资源、费用与伤势（43—48）

- 43A混合计价：召唤按实体实际位格定固定费用，回退/重启按本人灵性上限比例；不继续把9月7日“主人上限×2%×位格比”当召唤定稿公式。
- 44A：收费特殊机制须付得起全额才可用，不允许借公共透支规则无限使用；不删除其他来源已允许的透支。
- 45A：真实施放开始即付全额，被打断/对抗失败不退，已付费用不可回退。42的合法保命命中必成例外不能被“统一失败收费”反向改掉。
- 46A：灵性不够支付所有维持时，按战前/上回合配置的简短保留顺序处理，不逐项弹窗；结束的是维持关系，自主盟友不凭缺费被杀。
- 47A：普通轻伤扣健康上限10%，普通重伤扣30%；65/30/5与带伤再败+10保持，专属伤害例外另列。健康降至0仍进入死亡流程，不能只写轻伤就绕过。
- 48自定义：每完整战斗回合恢复10%灵性，可再由已有能力/物品补给。不是每个行动或多人小轮都回10%。实施候选以灵性上限为基数、回合边界恢复且上限封顶；边界先后由后续费用表说明，不给开战前/死亡中插入免费恢复。
- 普通施法仍无逐次灵性费。不新增专属能量条。旧费用表全部仅为历史试算，当前不把15%回退、5%不死等旧候选数字冒充本批已确认值；按66A结合10%恢复重新定价。

### 普通撤退（49自定义、50A、51A）

- 单独撤退，不把队友自动一起移出战场。撤退者本回合全部行动用于撤退，第一次轮到时判一次；成功脱离，失败耗尽本回合行动且仍承受后果。门的两段出口保持例外。
- 检定读取真实出口、封锁、移动能力与双方位格，不直接拿当轮胜势代替逃脱判定，不新增速度属性。
- 玩家要求：“单独撤退，战斗立刻结算结果，告诉玩家哪方赢了。”
- **49补充已确认**：玩家成功单独撤退后，系统根据双方实力简单、快速、直接给出战斗结果，不继续播放或后台展开完整多回合战斗，也不默认玩家方失败。简易结算读取真实留场阵容及已有伤势/状态，已经安全撤离的玩家不再作为在场战力，也不因留场方后续失败被重新判伤。具体实力换算、是否有一次轻量随机、留场角色后果映射由助手按66A写成候选；不把未结算的队友伤亡冒充已经发生。

### AOE与姿态（52A、53A）

- AOE人数按锥形、爆炸、扩散等能力形态逐项设计；人数盘→无放回目标盘不变，普通总预算一份，群控成功目标各承受完整控制。
- 姿态偏好类别基础权重×1.25，其余不变，再统一归一化。不可删固有能力、手选抽取结果或复制普通胜势预算。

### 本次针对性算例与未完项

- 队内次数2/4/4产生4/4/2顺序；正常轻伤/重伤在健康上限100时分别扣10/30。带伤再败k=0/1/6/7的分支仍为65/30/5、55/30/15、5/30/65、0/25/75。
- 灵性上限100且剩40，完整回合一次恢复后为50；多人每侧3个身体也不是恢复6次。恢复不撤销回退已付的费用；真正跨过新的回合边界才可能有新恢复。
- 第66题A授权助手自行完成剩余数值、子盘、普通亡灵模板与算例后整包审核，不等于数值已平衡。42/49结构已确认，不再追问；精确计费/恢复边界、死亡项权重、救援接线与实力简易结算公式由助手继续细化。没有产品测试、实现或试玩结论。

## 战斗触发与播放

- 战斗没有每局场次数值上限、下限或配额，只能由事件卡的事实、冲突和玩家选择触发；不能为了凑战斗数量强行插入遭遇。
- 每次能力抽取都播放一轮完整转盘，不合并同类结果；玩家可以启用快速转动/快速停盘。
- 快速模式只缩短动画，不跳过独立随机、AOE数量盘、目标盘、资源消耗、机制触发、伤势或逐项回执。
- 队友、秘偶、投影和多目标让总转盘数量增长时仍遵守完整抽取；玩家可快速转完或展开查看逐项回执，不得为了压缩现实时间暗中删除合法行动。

## 能力盘

每个项目的占比先由基础权重乘该项目掌握度曲线，再叠加当前明确修正，最后统一归一化。双方能力盘完整公开项目、精确概率和主要权重来源；“未知情况”只隐藏具体内容，不隐藏占比。每场能力盘保留固定小底噪，战场、污染、封印物副作用等明确因果来源可以在其上追加权重；底噪和追加量的具体数值后置。

能力命中后的胜率贡献和特殊效果不能被压成一个固定战斗力。技能、掌握度、装备、道具和封印物不进入基础战势，而是在战斗能力盘命中及其战斗专属效果阶段发挥作用。

### 战术姿态与目标盘

- 战术姿态必须来自短小白名单，例如进攻、防守、控制或脱离；每项姿态的权重变化在转盘前完整显示。
- 姿态调整后仍对当前合法项目重新归一化，不允许把某个不喜欢的固有能力权重直接改成0。
- 单体能力的目标盘在合法候选中抽取1个目标；AOE能力先抽取合法命中数量，再无放回抽取对应数量的目标。能力内容必须声明最小/最大命中数、敌我阵营、重复目标和无足够目标时的处理。
- 玩家、队友和敌人遵守同一目标盘规则；AI只能决定姿态和是否撤退，不能暗中指定转盘结果。

### 占卜家序列9：持枪能力盘基准

下面是用户确认的基准盘面，但运行时尚未实现。基准条件为无封印物、持有可用枪械、弹药充足且未受伤；实际盘面仍按当前面板、装备、弹药、战场条件和可用性实时重算。

| 扇区 | 基准盘面概率 | 转中后的量化结果 |
|---|---:|---|
| 枪击 | 36% | 不再使用固定优势值；按子弹、目标和射击条件实时计算。普通子弹对无防护普通目标约 `+45优势`，对有非凡体质目标约 `+25~30`，对灵体/特殊抗性目标约 `+5` 或无效。 |
| 体术 | 14% | 基准 `+22优势`；身体状态差时仍可转中，但命中效果按当前体魄和伤势降低。 |
| 闪避/掩体 | 10% | 占卜家不以身体闪避见长；命中后使敌方有效优势基准 `-20`，具体掩体/地形可继续修正。 |
| 灵视 | 8% | 基准 `+5优势`，同序列约提升0.6个百分点；主要揭示敌方状态，不造成直接伤害。 |
| 灵性直觉 | 10% | 只有转中才执行动作。危险差 `≥20` 时敌方有效优势 `-25`；未达到阈值则不获得胜势修正。 |
| 观察/调整位置 | 14% | 用于建立射界、拉开距离或寻找可用位置；不作为占卜家的固定战斗强化，实际效果由战场条件声明。 |
| 未知/失误 | 8% | 保留小概率的已登记未知结果。 |

盘面概率与胜率贡献是两个不同字段：

```text
显示盘面概率 = 当前扇区权重 ÷ 当前全部可用权重 × 100%
枪击优势 = 子弹基础值 × 目标抗性 × 射击条件
最终胜率 = 玩家有效优势 ÷ (玩家有效优势 + 敌方有效优势)
```

枪械不可用时，枪击扇区移除，剩余扇区重新归一化，不把枪击概率伪装成空转。以同序列基础优势200对200为例，枪击 `+45` 约使胜率从50%到55.1%；同一枪击若因目标抗性只剩 `+27`，约为53.1%。对序列8等高位格目标，百分比提升会进一步被其更高基础优势稀释。

- 回合快照项目临时失效时保留原扇区并执行预声明结果。
- 双方本轮能力盘都转完后生成胜负盘。
- 能力盘按基础权重×掌握度曲线，再加当前效果后归一化。
- 未知情况区采用固定小底噪，并允许明确因果来源追加。

## 回合胜负盘与位格

双方有效胜势合并后按相对比例生成两块胜负盘：

```text
playerWin = playerEffectiveAdvantage /
             (playerEffectiveAdvantage + enemyEffectiveAdvantage)
```

COMBAT-V3候选以`TierBase=10×U`生成序列6—0基础战势，并对普通能力削减后的有效优势设置本序列基础值10%的保底；这只避免仍可行动者被普通加减法压成零或负数，不覆盖显式失能与特殊终结机制。旧COMBAT-V2线性`50+0.05×胜势差+位格压制差`因高序列固定种子筛查大量撞到5%/95%而退出活动候选。`P`不再自动加入普通回合胜负率，只能由明确声明的特殊位格对抗读取。完整公式、固定种子结果和候选边界见[途径量化与配速](PATHWAY_QUANTITATIVE_DESIGN.md#统一胜负换算候选v3与固定种子复算)。

不额外设置低位方胜率硬上限，也不乘统一的跨序列衰减倍率。序列差距通过基础值和真实能力效果体现。低序列允许在针对性准备、克制、封印物、环境优势或高序列严重负面状态下依靠转盘运气爆冷；熟练度本身不能越级。每套序列能力完成后要批量模拟，并由人工按原著复核。

回合胜负不自动结束战斗。后果盘或具体能力可以令一方死亡、失能、逃脱、投降、被俘或通过特殊机制直接结束遭遇；否则进入下一回合。只要因果上存在撤退或投降路线，角色就可以在新回合开始前选择尝试，并在可知范围内看到风险；逃脱本身可以使用能力盘、目标盘或事件声明的专用转盘。

## 伤势模式、生死与终局

- 回合胜负盘不判定生死；败者后果盘才决定轻伤、重伤、死亡分支或当前场景允许的其它后果。
- 轻伤和重伤都进入持久伤势记录并立即启用受伤模式。伤势会降低后续回合的实际能力效果或基础状态，具体来源不能重复扣减。
- 处于受伤模式时再次输掉回合，按用户确认的65/30/5与每次带伤再败转入死亡10个百分点处理；先扣轻伤再扣重伤，真正痊愈才清累计风险。普通轻伤扣健康上限10%、重伤扣30%已由47A确认，不能把分支权重误作健康损失；战后治疗候选见[LIFE_AND_RECOVERY.md](LIFE_AND_RECOVERY.md)。
- 死亡分支按用户确认的当前有效保命能力转盘处理。第37题A已取消通用生存公式及其难度累加，不再把它放在保命机制之前、之后或当作保命选项；具体能力本身的合法实时对抗不受影响。
- 健康降至0时至少强制进入死亡分支，不能只以普通轻伤结束；具体能力可以提前直接触发伤势或死亡分支，但不能把死亡写进回合胜负盘。
- 玩家最终死亡成立后立即结束当前游戏；保命处理尚未完成时不封存。死亡周目永久只读封存，不可回档或继续。
- 精神归零按具体原因结算，不使用统一精神归零转盘；NPC死亡后的持续效果另行处理。

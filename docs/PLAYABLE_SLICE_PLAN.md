# 第一份可玩版：从普通生活到首案收尾

## 1. 一个可验收目标

玩家能创建一名普通人，在贝克兰德靠工作、学习、调查和休养过完一周，完成“沉默的夜班”三阶段调查并看到真实选择后果；关闭游戏再打开仍能继续。第一周是学习生活的单位，整条案件通常跨2—4周，不强塞进一周，不设现实时间目标。

成功完成首案、主动放弃首案或最终死亡，都有明确收尾。前两种显示“本次试玩内容已完成”，提供“查看卷宗 / 返回标题”两个操作，保存可续接状态，不冒充角色已成神或整个周目自然终结；死亡遵守既有最终死亡封存。后续版本可从幸存存档接占卜家成长，不自动赠魔药。

## 2. 包含与暂缓

包含：
- 原六步创角，10出身、12职业及120兼容格、20人格卡、学历与资金候选；不压成一个预设角色。可提供一个可编辑推荐组合，不隐藏自由选择。
- 四行动、3AP普通周基准、工资/生活费/债务、普通休养和伤势处置；贫困援助仍走已写委托，不免费洗掉伤势。
- 10张出身首卡与已写核实结果；首案公共线索入口；A/B/C、举报、危机放弃和四轴纪事。
- 普通人追击战，双方次数盘、能力盘、回合胜负与伤势/死亡后果；不删死亡、不保证首战必胜，不扩成22途径战斗工程。
- 一名关键人物奥黛丽（默认中间人）、梅芙、责任人槽、值夜者聚合状态；可见信息与秘密分离。
- 单张阻塞卡、紧凑纪事、固定回退文案；离线可玩。
- 基础桌面存档：新建/继续/查看封存，滚动自动档、系统恢复备份与重启恢复。

暂缓：主动跨城迁居入口（没有第二城市正式事件池）；污染旧物支线抽取；魔药服用与序列9能力；市场实际商品/拍卖/产业经营；12件正式封印物；117定义全部制作；全NPC长期世界与序列0终局。已有规则、目录和候选保留，暂缓不等于删除。首案首版没有污染数值新增，铃声精神损失不假扮污染；旧物闭环另见风险文档，供下一小包。

## 3. 新玩家看见什么

主面只保留人物状态、当前日期、剩余行动、四个行动和最近结果。学习/调查各展开最多3个已知目标，选一个即执行；不足3项不编目标、不补空槽。事件正文依次回答“发生什么、可确认什么、现在选什么”，最多3个明确选择；不可见能力分支不显示锁头。

初始已知“街区夜班工钱告示”和普通诊疗告示，均是原创普通信息，无神秘知识。首案入口见普通生活文档；无论出身或拒绝家庭线索都能主动查首案。推荐首周“工作→调查告示→休养”，仅提示，不自动操作。每次结果最多突出一个主要变化，详细因果留纪事；不能为视觉简洁截断真实周末消息。

危险选择先展示已知检定、现金/AP、可能受伤/死亡；未知秘密不剧透。追击选项明确“可能进入多回合战斗，可能死亡”。转盘保留完整规则，快速播放只缩短动画。结果页告诉玩家下一步是“等下一周”“调查锅炉房”或“休养/处理伤口”，不新增多层任务菜单。

## 4. 失败也能继续

- A检定失败仍保留已写最小线索；B拒绝合作仍进C，不强迫组织身份。
- C救人/取证失败按结果表收尾，不强制切战斗；追击回合败北不直接判整案失败。
- 无钱采用欠款/降档候选；不能用钱不足或资源≤0制造全灰死局。休养和不需身体操作的退出始终有合法入口。
- 同一意图双击、读档、动画重播只复用原回执；不重领工资、委托金，不重掷结果。
- 异常物毁坏、转移、负责人失效先检查事实，再装载第16节替代卡；不复活人、不复制物、不靠模型补怪。
- 尚未制作的远迁/旧物情况以专门设计情景检查，不假称首版能自然玩到所有组合。

## 5. 存档选择与交付边界

本方案选择：浏览器内存版用于中途玩法审核；第一份交付可玩版包含Electron + SQLite基础存档。不开第二套浏览器本地存档作为正式权威，也不把网页刷新不丢数据当作桌面完成。本次方案确认包含这一交付边界；拟定交付目标为Windows桌面试玩版（待本方案整体确认），与现有Windows项目背景一致。云端可做开发、规则测试与构建准备；若没有可用Windows执行环境，实际启动/重启/打包验证需要接入Windows测试环境或用户配合，届时明确报告阻塞。Linux或浏览器验证不能替代Windows成功，不承诺在缺少环境时已完成该项。

按技术架构保存纯数据、内容版本、随机流位置、当前卡与待办、周末执行阶段、案件/人物/物品事实；行动、事件选择、交易及完整战斗回合在原子提交后自动保存。动画未完成不影响已提交结果；退出再进继续同一结果/待选卡，不回到上一次可重掷选择。保存失败时不显示成功、不推进新意图；保留最后有效档并提示重试。

启动校验主档：合法则载入；损坏时保留损坏文件，校验备份后提示“恢复最近有效进度”；高于程序支持的版本拒绝载入且不覆盖；旧版本仅按明确迁移转换。恢复只为故障处理，不提供玩家任选历史节点。最终死亡原子写入后槽位只读，不能用继续按钮复活。用户可另开新周目，只有档案信息跨周目。

## 6. 完成标准

以下均要在实现后的对应环境实际验证；现在全部未运行。

1. 六步创建可回退修改，资金/属性预览等于最终值；禁止职业不能付钱解锁，10出身入口可达。
2. 四行动各走通；0/1/2次工作只结0/1/1份工资；第三行动耗尽先清待办再结一周，日期只推进7天。
3. 学习有具体已知主题和成功/失败，调查无目标不扣AP；休养封顶、医疗和真正痊愈分离。
4. 主路径从任一出身到A→B→C→四轴结果；拒绝出身线索、拒绝委托、举报及时/未及时、W3放弃均不死锁。
5. A三选项四档、C非战斗两选项四档逐项覆盖；追击至少两回合带伤继续、逃脱/投降/死亡的实际结果正确。
6. k=0/1/2时死亡权重5/15/25%，伤势未真正痊愈不清k；最终死亡才封存。
7. 四类连续性情景逐项检查，尤其已销毁物不写逃逸、他人取得不写玩家获得、替代者不继承秘密、远方不弹现场卡。
8. 一次只开一张卡；键盘可完成选择，背景不可点，返回不绕过待办；普通人看不到序列9隐藏能力信息。
9. 从待选卡、周末账单、战斗完整回合、首案结案四个提交点退出桌面进程再启动，金钱/AP/日期/随机/人物/物品均一致，无重复领取。
10. 验证损坏主档恢复、无效备份不覆盖、旧版本迁移/高版本拒绝、写入失败提示；离线关闭模型仍走通。
11. 至少一个正常结案、一个主动放弃和一个最终死亡的真实试玩记录；通过相关自动测试、类型检查、构建和目标平台重启/打包检查后才算交付完成。浏览器通过不替代桌面验证。

## 已实现范围

原六步创建；10出身、12职业、120兼容关系、55项条件经历、12特质与8缺陷、学历与资金计算、8款纯外观肖像。四行动与3AP周循环、一次工资、生活账单/欠款、学习/调查、普通休养/处置/医疗援助。10出身首卡、公共首案入口、A/B/C与举报/危机/放弃、四轴收尾。普通人独立次数盘和能力盘、多回合伤势与最终死亡。存档保存完整创建输入与来源、随机位置、当前卡、待办、周脉冲、人物/物品事实及战斗历史。

界面采用原创蚀刻与清爽卷宗；正文使用本地打包、OFL许可的中文无衬线字体。所有运行文本由界面显示，不使用图中文字。

## 架构与存档

纯TypeScript领域模块独立于React/Electron/SQLite。浏览器内存与正式Main/SQLite共用应用编排器，Renderer只接收显式公开投影；私人事实与随机种子不发送给界面。一次意图包含唯一编号与期望revision；快照与回执同一事务提交，重复只返回原回执。桌面桥未载入时拒绝降级为内存模式。

SQLite滚动主档、最近有效恢复备份、损坏原始记录保留、未来版本拒绝、明确v1→v2存储结构迁移、死亡只读。迁移测试使用定义明确的存储v1合成档；不声称自动兼容旧原型里具有不同规则的私人游戏档。用户上传的runtime-data未读取或打包。正式新切片使用独立playable-slice.sqlite。

故障注入发现并修复了“最终死亡事务失败时侧边封存标记未回滚”的问题；回滚现在恢复原标记，故障后仍可恢复最后有效存档。

## 实际验证

- npm run check：PASS。21个测试文件、279个测试全部通过；主进程和界面TypeScript检查通过，生产构建通过。保留原型安全、确定性与持久化回归，并追加切片覆盖。
- 真实Chromium：六步创建、普通生活、正常结案、W3主动放弃均PASS。自然随机追击终检累计11回合触发已受伤后的最终死亡，死亡卷宗只读；不是由界面注入死亡状态。
- 战斗风险：受伤后再输回合即增加k；无有效打击威胁时不转后果盘、不扣健康、不直接死亡。成功撤退、重复意图与重播不重复增加。风险及结果跨SQLite重启保持一致。
- 界面：1600×900与1280×720默认文字下四行动可见；1280×720首案卡完整显示三个选项与成本。创角下一步固定可见，选项区可滚动；390px窄屏无横向溢出。大字、纪事与长内容可滚动。中文字体已按真实截图核对，无方框缺字；浏览器控制台错误为0。
- Linux Electron 44.0.0：PASS。正式安全窗口、preload、IPC、SQLite运行于本地file页面，四个独立进程检查创建/同意图回放/重启/四种提交边界；待选卡、周账单、完整战斗回合、结案的公开投影一致。故障、损坏、迁移、秘密隔离另有自动测试。
- 实际production main入口：PASS。使用便携包内resources/app搭配Linux Electron，界面完整六步创建→工作→退出程序→重新启动→选择存档，公开状态逐项一致。测试只使用新建临时用户数据目录；这验证了应用封装和正式入口，不是Windows运行证明。
- npm run smoke:electron现指向当前切片smoke:slice。旧原型Electron harness作为历史回归资料保留，不作为新版界面验收入口。
- Windows x64：仅完成官方运行时与构建产物的便携封装和压缩包结构检查；本机运行NOT_RUN。两个ZIP的CRC和所需文件检查通过；源码不含node_modules/dist，全部交付均排除runtime-data、测试输出及数据库。

## 明确限制

- 制作环境是Linux。Windows x64便携包使用官方Electron44.0.0及已构建游戏，原运行时由官方辅助工具校验上游SHA256；Windows本机启动、重启、系统兼容性与杀毒/签名行为未验证（NOT_RUN）。Linux与浏览器成功不能替代Windows验收。
- 不包含正式签名安装程序、自动更新或对外发布。
- 普通首案试玩，不包含非凡晋升、全22途径可玩成长链、市场商品与产业、跨城迁居、完整117事件或高位终局。
- 目前数字为用户接受的试玩候选；自动测试证明规则一致，不等于已经平衡。
- 正常/放弃收尾保留幸存者真实资源和伤势供未来续接，本切片此处只提供卷宗与标题。负资源的非战斗撤离不虚构死亡，也不承诺现在可从结尾继续休养。
- 普通五槽未定义控制/准备分类，因此本切片只开放进攻、防守、撤退。没有删除未来途径的其他姿态。

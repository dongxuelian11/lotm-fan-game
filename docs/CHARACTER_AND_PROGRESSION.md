# 角色创建与成长

## 第一版捏人流程

参考《汴京梦华》的短流程节奏，但不复制代码、文案或素材：

1. 基础身份：姓名、性别、18—45岁年龄、鲁恩境内出生地、受控外貌标签与可选简短自由描述；不再选择肖像。
2. 出身：从10个整合出身中选择1个；五层社会阶层各有2个，由它派生阶层、家庭基线、社会环境和默认学历；经历可信时出身/职业步骤可选择至多一个带明确家庭或经济代价的条件替代学历。
3. 当前职业：只显示所选出身下当前能够实际确认的职业；禁止组合隐藏，条件组合仅在完整条件接受流程已实现时显示。职业决定工作报酬、开局核心能力加成方向和一次性初始个人资金。低出身有更多灰色职业选择，高出身主要获得经济优势；转职只改变后续工作报酬，不重新结算开局属性或初始资金。
4. 人格：恰好选择2个性格特质，并另行选择1个真实缺陷；缺陷不计入这2个特质，也不给额外属性点。
5. 只读开局摘要：系统确定性派生四项核心能力、独立学历、主要关系、初始资源与事件入口并展示关键倾向和后果；如已选择条件替代学历，在此只读展示结果与代价，不再要求普通技能或自由专精输入。
6. 玩家确认后以普通人开始；角色创建阶段不提供魔药或序列能力。

属性不使用手动点数购买界面。六步捏人始终显示四项核心能力的实时总值与来源变化；所有会改变数值的卡片必须在选择前显示有符号增减。出身、职业、年龄、特质和缺陷的结果必须可复现，并在确认前解释冲突和关键后果。人格步骤必须精确校验2个互不重复、组合合法的性格特质和1个真实缺陷；第5步只读摘要不接受普通技能或自由专精输入。性别可通过社会事件影响玩法，但不直接修改基础属性。第一版取消肖像选择；外貌输入采用可组合的受控标签，并允许玩家补充一段可选短文本，不引入实时图像生成、外貌数值或自由文本规则解析。出生地保留独立选择，正式清单为贝克兰德、廷根市、康斯顿市、普利兹港；它影响履历、迁入原因、少量对白和事件入口，不直接增加属性。所有角色开局当前居住地固定为贝克兰德，之后可以通过已解锁的轻量迁居事件改变。

人格特质可以改变少量克制的内心叙述措辞，但不能替玩家决定行动。人物关系记录关系类型、定性态度和近期原因，不用一个万能好感数值概括全部互动。玩家默认没有正式组织归属；组织只能通过事件卡供玩家选择加入，同一时间最多一个主要正式组织，途径不会自动或强制赋予组织身份。第一版不制作恋爱系统，关系内容集中于家人、同伴、雇佣、组织、债务、信任、敌意和利用。

人格数值只作轻量微调：每个性格特质使一项核心能力 `+1`，每个真实缺陷使一项核心能力 `-1`。第一版正式卡池为12个特质与8个缺陷，四项核心能力严格各分配3个特质与2个缺陷。人格卡最多带1个可见情境标签，不能额外修改数值、成本或行动；逐卡名称、能力映射、互斥关系和情境效果仍未完成。

## 出身、阶层和职业

社会阶层采用五层社会生态分组；第一版10个整合出身按每层2个均匀覆盖。同层两个出身必须具有可解释的家庭或社会差异。贫民层采用“无依街巷长大”和“负债失业家庭”，区分弱家庭支持/街巷求生与家庭关系/债务义务；劳工层采用“工厂工资家庭”和“雇主依附的服务家庭”，区分工业雇佣/工友网络与雇主依附/声誉义务；小市民层采用“自营小店/小作坊家庭”和“受教育的基层职员家庭”，区分经营资产/市井网络与教育/机构网络；中上层采用“高等教育专业人士家庭”和“中型商贸/产业经营家庭”，区分教育/专业声望与经营资产/商业信用；上流层采用“贵族家系”和“获社会承认的实业/金融精英家庭”，区分世袭身份/家名网络与资本经营/社会承认。上述原型都只是家庭成长背景，不替代当前职业，也不自动赋予玩家本人资格、职位、无限资金、组织权限、魔药、序列能力或秘密知识。贵族家系不保证玩家持有爵位或继承权，非贵族精英不具有世袭贵族特权。所有正式显示名称、数值和具体内容仍待后续设计。阶层影响强且可变化，不是一劳永逸的数值标签。家庭营生记录“一个主要营生＋可选第二营生”；具体选项优先使用软约束、情境和成本处理，低优先级细节暂不展开。

出身开局包采用统一基线 + 出身修正；每张出身有1项主优势、1项次优势、1项真实短板和1项中性，并提供1个支持关系槽、1个义务/风险关系槽、家庭经济基线、至少1个专属开局事件和2类复用事件钩子。出身修正幅度采用`+2/+1/-1/0`。第一版不建立普通技能体系。学历另设独立记录，使用无正式学历、基础教育、中等/职业教育、高等教育四档；无正式学历不自动等于文盲。出身给默认档，可信时出身/职业步骤可选择至多一个带明确家庭或经济代价的条件替代档。学历按表固定增加开局知识，并在成功学习时增加固定额外知识；可通过付费多周进修与里程碑事件升档。职业可变且不建立关系、义务/风险或访问入口附加包；职业采用`+2/+1/0/0`能力模板，并以低/中/高档决定工作报酬和一次性初始个人资金。转职只改变后续工作报酬，不重新结算开局属性或初始资金。关系槽首版开局只保留抽象标签，第一周保证出身专属事件且不额外消耗行动。

## 第一版途径范围

第一版目标让标准22条神之途径全部进入可玩范围，并为每条途径建立序列9—0的成长、能力、材料、配方与晋升仪式内容。占卜家（占卜家→小丑→魔术师）、观众（观众→读心者→心理医生）和猎人（猎人→挑衅者→纵火家）是先行核对内容，不是首版唯一选择。

全部途径仍从普通人开始；每个序列按原著变化独立设计，不套“每升一级固定加X”的统一模板。一个周目只随机开放部分早期途径机会，不保证同时遇见全部22条；玩家一旦沿某条机会追查，每个关键配方、材料或接触门槛都必须至少有一条可确定追踪的路线，不能被纯随机永久卡死。专注推进的玩家取得第一份序列9魔药的目标节奏为约4—8个游戏周。22条途径的正式名册、逐序列能力效果、解锁事件与原著来源仍须逐项设计和核验，当前不把占位内容冒充为已完成内容。

## 属性与序列成长

四项核心能力为体魄、感知、意志、知识，统一0—500；普通人通常10—20，训练软上限20，少数专业例外可到25。序列1锚定500，序列0以权柄和神性规则表达。

晋升只提高与途径和该序列变化相符的核心能力、状态上限和具体能力，不让四项属性整齐上涨。每个序列包必须记录能力变化、健康/精神/灵性上限、消耗、扮演入口和失控/污染风险。相邻途径允许通过正确材料、仪式和高风险事件进行转换；具体可转换关系必须逐项对照原著。晋升随序列提升总体减速，高序列通过更长游戏内成熟期、条件和因果形成差异，不用多年重复刷取或现实小时上限约束周目。具体增量、材料、配方、转换条件和晋升难度仍按逐途径候选和已确认范围分别处理。

## 扮演、消化与风险

扮演进度向玩家显示明确数值，魔药消化以可解释的定性阶段显示；能力掌握度仍是第三条独立成长轴，三者不能互相按比例自动兑换。工作、学习、调查、休养四个行动都可能通过事件产生扮演证据：工作体现身份与处世，学习形成理解，调查承担实践和风险，休养承载反思、自控与能力后果。只有事件中实际完成且符合当前扮演原则的行为才增加进度，按钮本身不赠送进度；同类低风险机械重复收益递减，调查在同等契合度和风险下通常收益更高。

晋升不是普通技能树加点：外来力量、排异、精神风险、失控、污染和身份后果必须同时进入能力和事件设计。成长链覆盖配方/知识入口、魔药材料收集、调配与服用，并为原著中适用的晋升阶段承载仪式；第一版最终范围覆盖22条途径序列9—0，而非只覆盖先行三条。已知晋升条件全部满足时，系统自动生成可回应的晋升事件，不要求玩家另找一个隐藏的“升级按钮”。普通调配或仪式失败以轻量、可重试后果为主；晋升失败会降低当前扮演进度，只有重新补满后才能再次尝试。只有逐项审核且在选择前明确告知的特殊仪式才能附加致命风险。正式仪式加入后，临时晋升的整次重算延迟到玩家下一次调配或晋升时执行。背包与事件系统需要能追踪材料、成品和仪式条件；逐序列材料、配方、具体仪式、失控阈值和高序列边界仍待后续批量设计，工程实现状态保持独立记账。

每种非凡材料必须声明经审查的固定来源池，玩家只看到当前知识和权限允许的渠道。调配采用“校验配方/材料/适用序列、消耗材料、执行一次可记录调配判定”的轻量两阶段交互。晋升仪式失败默认不致死，只有已审核且在选择前明示致命风险的仪式才进入生存/死亡规则。具体材料、配方、数值、风险和文本仍待逐包确认。

## 普通人到序列0的递减晋升节奏

状态：`PACING_DIRECTION_V3 / PLAYER_DIRECTION_CONFIRMED / EXACT_WEEK_FLOORS_CANDIDATE / NOT_PLAYTESTED`

周是唯一正式时间单位，不再把任何阶段换算成现实分钟或固定周目小时。玩家每周拥有动态行动点；行动点耗尽、且该行动产生和本批排队的阻塞事件全部解决后，立即执行周脉冲并推进一周。阅读速度、快速转盘、是否绕路、是否连续调查、失败次数和玩家主动停留共同决定现实游玩时长。

晋升速度必须随序列提升总体递减。较高序列需要更长的游戏内成熟期、更多不同情境的扮演证据、更复杂的知识/材料/仪式准备和更广的世界因果；不能再用连续2—3周晋升承载序列9—0，也不能用重复等待、空按钮或拉长动画伪造慢成长。首次达到下表周数不自动晋升，所有准备线仍须成立；超过候选门槛也没有强制晋升或最长周数。

### 最早成熟周数候选

| 阶段 | 最早成熟周数候选 | 最少差异化扮演情境候选 | 本阶段必须被玩家感知的变化 |
|---|---:|---:|---|
| 普通人→序列9 | 4周 | 不适用 | 接触一条途径，取得并核验配方/材料，完成调配与首次服用 |
| 序列9→8 | 6周 | 3类 | 日常被动第一次改变事件信息、隐藏选项或后果 |
| 序列8→7 | 8周 | 4类 | 新能力在不同日常情境中形成稳定而非偶发的解法 |
| 序列7→6 | 12周 | 5类 | 能力组合形成途径身份，人物开始辨认并回应这种行为模式 |
| 序列6→5 | 18周 | 6类 | 身份与势力压力进入前台，但组织加入仍完全自愿 |
| 序列5→4 | 26周 | 8类 | 中盘位格转折对人物、地区与既有因果产生持续影响 |
| 序列4→3 | 40周准备期 | 10类 | 高序列能力改变事件参与者和作用范围；特殊仪式另按原著时间执行 |
| 序列3→2 | 60周 | 12类 | 处理途径级重大因果、历史断层、关键敌对或势力重排 |
| 序列2→1 | 90周 | 15类 | 多条长期事件链共同构成终局准备，不由单一卡片跳级 |
| 序列1→0 | 140周 | 18类 | 最高层级晋升必须由整局积累、世界状态与终局事件共同成立 |

这些数字是为事件内容排产和试玩建立的第一版下限候选，不是玩家已经确认的最终平衡。锁定的是单调减速方向、取消2—3周连续晋升和取消现实小时目标；精确周数必须在事件库达到覆盖要求后用真实游玩调整。占卜家序列3的“三百年隔绝”属于仪式事实，不被40周准备期替代或压缩。

### 每次晋升的三条并行准备线

序列9的首次服用只要求接触/知识材料线、调配风险线和首次服用后果线；从序列9晋升序列8直到序列1晋升序列0，每一阶段同时推进以下三条线：

1. **身份线**：在工作、学习、调查、休养事件中产生2—4次有差异的扮演证据，并把消化推进到该序列要求的阶段；
2. **知识与资源线**：取得并核验下一序列配方、固定来源材料和必要条件；至少一项关键依赖必须可定向追查，不能靠纯随机等货；
3. **风险与因果线**：处理调配、适用仪式、污染/暴露、人物或组织反应，并留下至少一个会进入纪事或后续事件的选择后果。

一张事件卡可以在事实确实支持时同时推进两条或三条线，例如调查材料来源时既取得材料线索，也因符合扮演原则产生身份证据，并让相关组织提高警觉。系统必须分别写出每条推进的来源，不能用一个“晋升经验+X”合并。反过来，同一低风险模板换八种文案仍只算同类证据，受重复衰减。

### 周推进与内容密度

本项目借鉴《汴京梦华》的“有限行动后自动推进周期、到期连环事件优先、同一时刻只处理一张选择卡、结果回写日志”，不借用它的每月两次行动、官场成长数值或现实阅读时长。

- 每周行动点耗尽后不再出现额外“结束本周”操作；若有已生成阻塞卡，先逐张处理，随后立即周脉冲；
- 普通人每周1—2张、非凡者每周2—3张阻塞卡仍只是密度观察值，不是配额；事件可以稀疏或集中，只要来源和因果成立；
- 普通生活、材料追查、扮演实践和世界反应先按精确序列进入不同事件包；同一序列可让22条途径复用审核模板骨架，但各途径必须拥有不同切入、能力路线与后果，换能力名或换文案不算新情境；
- 越接近高序列，非凡事件、长期链和世界反应逐步增多，但身份、关系、经济和人性代价不能消失；
- 第一条贝克兰德调查弧如果已经提供某条准备线或扮演证据，后续不得以换皮卡强迫玩家重复完成同一工作。

### 失败与防拖延

- 晋升失败照常扣减扮演进度并要求重新补满，不设置必定成功保底，也不因现实游玩过久而自动降低要求；
- 材料损失、精神/灵性变化、污染与关系后果按对应内容包处理，重试不能把失败回滚成“什么都没发生”；
- 同一关键依赖连续多周没有新进展时，世界必须提供一条已有知识可解释的定向追查入口、替代来源或明确的失败原因；具体触发周数随序列和依赖类型调整，不赠送材料，只防止无信息等待；
- 玩家主动改变目标、迁居、拒绝高效但高代价路线或经历多场战斗时，游戏内周数可以持续增加，结算评价应如实记录这些选择；
- 精确扮演阈值、材料价格、晋升成功率和每条途径的事件分布仍须逐途径设计与模拟，本候选不替它们定值。

### 后续试玩必须回答

1. 玩家是否能在每次晋升前说清自己还缺身份、知识资源或风险因果中的哪一项；
2. 行动点耗尽、阻塞卡清空和周脉冲的顺序是否清楚且无多余确认；
3. 同卡推进多条线时，玩家是否觉得因果自然，而不是一次塞满奖励；
4. 一次普通晋升失败后是否仍有真实代价，同时始终有可理解的恢复推进路线；
5. 序列9→0的每次晋升是否都有可感知变化，并至少形成五次明显的“新被动改变事件读法、选项、参与者或后果”的体验拐点；
6. 序列4之后的高序列阶段是否仍有真实选择和风险，而不是四次连续晋升动画。

## 终局

玩家死亡立即结束本局，死亡周目永久只读封存、不可回档。游戏提供多个由人物、组织、途径和世界分支共同形成的非死亡结局；达到序列0拥有最高位阶终局，但不是唯一可成立的结局。非死亡终局只解锁结束选择，玩家可以结束或继续；周目持续时间完全由实际游玩决定。终局不设统一总分，生成多维非凡者生涯卷宗，包含终局事实、身份/最高序列、能力成长、组织与关键关系、资产/道具/封印物、重大事件时间线、结局称号和传记摘要。跨周目只继承档案、结局和图鉴记录，不提供机械加成。

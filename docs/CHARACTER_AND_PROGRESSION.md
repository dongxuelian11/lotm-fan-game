## 第一版捏人流程

参考《汴京梦华》的短流程节奏，但不复制代码、文案或素材：

1. 基础身份：姓名、性别、18—45岁年龄、鲁恩境内出生地、预设头像。
2. 出身：选择一个整合出身，由它派生阶层、家庭基线和社会环境。
3. 当前职业：选择一个职业，作为收入、身份、人脉、义务和机会入口。
4. 人格：选择少量性格特质，并选择一个真实缺陷；缺陷不给额外属性点。
5. 自动摘要：系统确定性派生四项核心能力、普通技能、主要关系和初始资源，并展示关键倾向和后果。
6. 玩家确认后以普通人开始；角色创建阶段不提供魔药或序列能力。

属性不使用手动点数购买界面。出身、职业、年龄、特质和缺陷的结果必须可复现，并在确认前解释冲突和关键后果。性别可通过社会事件影响玩法，但不直接修改基础属性。头像使用带结构化外貌标签的预设资源，第一版不做实时生成或细粒度拼装。

## 出身、阶层和职业

社会阶层采用五层社会生态分组；玩家可选贵族出身，但阶层影响强且可变化，不是一劳永逸的数值标签。家庭营生记录“一个主要营生＋可选第二营生”；具体选项优先使用软约束、情境和成本处理，低优先级细节暂不展开。

普通职业不是完整职业技能树，而是长期有效的身份、收入、关系和事件入口。初始普通技能来自背景基线，再加一次有限的自由专长。普通技能与非凡能力共用熟练度候选池，但职业本身不直接改战斗位格。

## 第一版途径范围

- 占卜家：序列9占卜家 → 序列8小丑 → 序列7魔术师。
- 观众：序列9观众 → 序列8读心者 → 序列7心理医生。
- 猎人：序列9猎人 → 序列8挑衅者 → 序列7纵火家。

三条途径都从普通人开始；序列6及以上可以存在于 NPC、组织和世界规则中，但不是第一版玩家持续晋升范围。每个序列都要按原著具体变化独立设计，不套“每升一级固定加X”的统一模板。

## 属性与序列成长

四项核心能力为体魄、感知、意志、知识，统一0—500；普通人通常10—20，训练软上限20，少数专业例外可到25。序列1锚定500，序列0以权柄和神性规则表达。

晋升只提高与途径和该序列变化相符的核心能力、状态上限和具体能力，不让四项属性整齐上涨。每个序列包必须记录能力变化、健康/精神/灵性上限、消耗、扮演入口和失控/污染风险。具体增量、材料、配方、转途径和晋升难度仍未锁定。

## 扮演、消化与风险

符合当前魔药扮演原则的行动才能产生扮演进度；调查在同等契合度和风险下收益更高。扮演进度、能力掌握度和魔药消化度是三条不同成长轴，不能互相按比例自动兑换。

晋升不是普通技能树加点：外来力量、排异、精神风险、失控、污染和身份后果必须同时进入能力和事件设计。第一份魔药的获得/选择、消化规则、晋升材料、失控阈值和高序列边界仍由后续底层 Grill 锁定。

## 终局

玩家死亡立即结束本局，死亡周目永久只读封存、不可回档。非死亡终局只解锁结束选择，玩家可以结束或继续。终局不设统一总分，生成多维非凡者生涯卷宗，包含终局事实、身份/最高序列、能力成长、组织与关键关系、资产/道具/封印物、重大事件时间线、结局称号和传记摘要。

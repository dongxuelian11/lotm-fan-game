## 第一版捏人流程

参考《汴京梦华》的短流程节奏，但不复制代码、文案或素材：

1. 基础身份：姓名、性别、18—45岁年龄、鲁恩境内出生地、预设头像。
2. 出身：从10个整合出身中选择1个；五层社会阶层各有2个，由它派生阶层、家庭基线和社会环境。
3. 当前职业：从12个职业中选择1个，作为收入、身份、人脉、义务和机会入口。
4. 人格：恰好选择2个性格特质，并另行选择1个真实缺陷；缺陷不计入这2个特质，也不给额外属性点。
5. 自动摘要与专精：系统确定性派生四项核心能力、基础普通技能、主要关系和初始资源；玩家再从按背景与前置条件过滤的候选中选择恰好1项普通技能专精，摘要即时展示关键倾向和后果。
6. 玩家确认后以普通人开始；角色创建阶段不提供魔药或序列能力。

属性不使用手动点数购买界面。出身、职业、年龄、特质、缺陷和自由专精的结果必须可复现，并在确认前解释冲突和关键后果。人格步骤必须精确校验2个互不重复、组合合法的性格特质和1个真实缺陷；摘要页必须精确校验1项通过背景过滤的普通技能专精，任一输入少选或多选均不能确认。性别可通过社会事件影响玩法，但不直接修改基础属性。头像使用带结构化外貌标签的预设资源，第一版不做实时生成或细粒度拼装。

## 出身、阶层和职业

社会阶层采用五层社会生态分组；第一版10个整合出身按每层2个均匀覆盖。同层两个出身必须具有可解释的家庭或社会差异，上流层至少分别覆盖贵族与获得充分社会承认的非贵族精英；贵族出身按既有决定属于标准新游戏可选项，本题不新增其他局外解锁规则。贫民层两张卡的核心原型锁定为“无依街巷长大”和“负债失业家庭”：前者突出弱家庭支持、街巷关系与求生经验，后者突出仍存在的家庭关系、债务与长期义务；正式名称、数值和具体内容仍待后续设计。阶层影响强且可变化，不是一劳永逸的数值标签。家庭营生记录“一个主要营生＋可选第二营生”；具体选项优先使用软约束、情境和成本处理，低优先级细节暂不展开。

第一版提供12个当前职业，与10个整合出身保持独立选择。普通职业不是完整职业技能树，而是长期有效的身份、收入、关系和事件入口；12个职业必须在这些入口上形成真实差异，并进入出身兼容、冲突解释、存档重放和内容验证矩阵。每组出身×职业组合采用 `DIRECT`、`CONDITIONAL`、`FORBIDDEN` 三级互斥状态：条件组合须在确认前展示可信解释和明确代价、义务或家境变化，禁止组合不能确认并显示不泄密的世界内理由，直接组合不需要额外背景补丁。初始普通技能来自背景基线，再在自动摘要页选择恰好1项背景过滤的自由专精；它不新增独立步骤，且不能绕过世界内前置条件。普通技能与非凡能力共用熟练度候选池，但职业本身不直接改战斗位格。具体职业名称、120组兼容状态、门槛、条件代价、收入、技能、义务、事件和转职规则仍待后续设计。

## 第一版途径范围

- 占卜家：序列9占卜家 → 序列8小丑 → 序列7魔术师。
- 观众：序列9观众 → 序列8读心者 → 序列7心理医生。
- 猎人：序列9猎人 → 序列8挑衅者 → 序列7纵火家。

三条途径都从普通人开始；序列6及以上可以存在于 NPC、组织和世界规则中，但不是第一版玩家持续晋升范围。每个序列都要按原著具体变化独立设计，不套“每升一级固定加X”的统一模板。

## 属性与序列成长

四项核心能力为体魄、感知、意志、知识，统一0—500；普通人通常10—20，训练软上限20，少数专业例外可到25。序列1锚定500，序列0以权柄和神性规则表达。

晋升只提高与途径和该序列变化相符的核心能力、状态上限和具体能力，不让四项属性整齐上涨。每个序列包必须记录能力变化、健康/精神/灵性上限、消耗、扮演入口和失控/污染风险。具体增量、材料、配方、转途径和晋升难度仍未锁定。

## 扮演、消化与风险

符合当前魔药扮演原则的行动才能产生扮演进度；调查在同等契合度和风险下收益更高。扮演进度、能力掌握度和魔药消化度是三条不同成长轴，不能互相按比例自动兑换。

晋升不是普通技能树加点：外来力量、排异、精神风险、失控、污染和身份后果必须同时进入能力和事件设计。第一份魔药的获得/选择、消化规则、晋升材料、失控阈值和高序列边界仍由后续底层 Grill 锁定。

## 终局

玩家死亡立即结束本局，死亡周目永久只读封存、不可回档。非死亡终局只解锁结束选择，玩家可以结束或继续。终局不设统一总分，生成多维非凡者生涯卷宗，包含终局事实、身份/最高序列、能力成长、组织与关键关系、资产/道具/封印物、重大事件时间线、结局称号和传记摘要。
